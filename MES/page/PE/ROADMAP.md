# บันทึกแผนงานระบบความปลอดภัยเครื่องจักร (Safety System)

## ✅ ระยะที่ 1: แจ้งเหตุและบอร์ดหน้าเครื่อง (เสร็จสมบูรณ์)
- [x] เพิ่มตัวเลือก "ความปลอดภัย (Safety/Hazard)" ในระบบแจ้งซ่อม
- [x] ทำหน้าเว็บ Quick Hazard Report สำหรับมือถือ (ไม่ต้องล็อกอินเข้าใช้งาน สแกน QR Code แล้วแจ้งได้ทันที)
- [x] บังคับถ่ายรูปจุดเกิดเหตุตอนแจ้งปัญหา
- [x] ตั้งค่าความสำคัญเป็นงานด่วนสุด (Critical) อัตโนมัติ เพื่อให้ จป. และทีมช่างเข้าตรวจสอบ
- [x] ทำบอร์ดสถานะหน้าเครื่อง (Visual Board):
  - แปะ QR Code ประจำเครื่องสำหรับสแกนแจ้งเหตุ
  - ทำช่องเสียบบัตรสถานะเครื่อง (เขียว/เหลือง/แดง)
  - ทำช่องเสียบบัตรประจำตัวพนักงานที่คุมเครื่อง
  - ทำช่องเสียบบัตรช่าง เพื่อแสดงสถานะว่ากำลังเข้าซ่อม
- [x] **[อัปเดตล่าสุด]** รีแฟกเตอร์สถาปัตยกรรมการพิมพ์ (Safety Print Center)
  - แยก Data Selection ออกจากหน้า Print Rendering อย่างเด็ดขาด (ลดภาระเบราว์เซอร์และแก้ปัญหาเลย์เอาต์พัง)
  - สร้าง Data Grid และระบบ Queue สำหรับเลือกการ์ดและบอร์ดที่ต้องการพิมพ์
  - เชื่อมโยงข้อมูลผ่าน LocalStorage และเปิดแท็บใหม่ (New Tab) เพื่อสั่งพิมพ์อัตโนมัติ 

---

## 🚧 ระยะที่ 2: ระบบ LOTO และเซนเซอร์ (แผนงานปัจจุบัน/ถัดไป)
- [x] **ระบบ E-LOTO บนเว็บ:**
  - [x] ช่างต้องกดล็อกในระบบก่อนเข้าซ่อมเครื่องที่อันตราย
  - [x] บังคับให้หัวหน้างาน/วิศวกร กดยืนยันปลดล็อก (Sign-off) เมื่อซ่อมเสร็จและจ่ายไฟกลับ
  - [x] ซิงค์สถานะ LOTO ในระบบเข้ากับสถานะการแสดงผลหน้า Dashboard หลัก
- [x] **การเชื่อมโยงและแจ้งเตือนเซนเซอร์เครื่องจักร (IoT):** *(ข้ามไปก่อน เนื่องจากระบบมีแค่บนหน้า 2D Map)*
  - [-] รับข้อมูลสถานะการทำงานของเซนเซอร์ความปลอดภัยที่เครื่องจักร (เช่น Safety Light Curtain)
  - [-] สร้างระบบแจ้งเตือนหัวหน้างานทันที หากพบว่าเซนเซอร์ถูกบายพาส (Bypass) หรือปิดการทำงานขณะเครื่องกำลังเดิน

---

## ✅ ระยะที่ 3: เช็คลิสต์และแดชบอร์ด (เสร็จสมบูรณ์)
- [x] **เช็คลิสต์ก่อนเริ่มงาน (Pre-Op Audit):** 
  - สร้างแบบฟอร์มตรวจสอบแบบ Dynamic ตามประเภทเครื่องจักร (Dynamic Checklists)
  - บันทึกชื่อผู้ตรวจแบบ Auto-Fill
  - เก็บผลตรวจสอบแบบ JSON สำหรับการติดตามย้อนหลัง
- [x] **แดชบอร์ดความปลอดภัย (Safety Dashboard):** 
  - ทำหน้า Dashboard แสดงผล Pre-Op Audit และ Hazard Incidents
  - รวมฟังก์ชัน Checklist Manager สำหรับสร้าง/แก้คำถามแบบฟอร์มได้เอง
