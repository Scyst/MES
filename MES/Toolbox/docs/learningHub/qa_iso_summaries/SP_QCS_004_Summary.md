# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การจัดการสิ่งที่ไม่เป็นไปตามข้อกำหนด (Control of Nonconforming Product)
**รหัสเอกสาร:** SP-QCS-004 (Rev.03)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อป้องกันไม่ให้ชิ้นงานหรือผลิตภัณฑ์ที่ไม่ได้คุณภาพ (NG) หลุดเข้าไปในกระบวนการผลิตหรือส่งมอบให้ลูกค้า ทั้งที่ตั้งใจและไม่ตั้งใจ
- **ขอบเขต:** ครอบคลุมตั้งแต่การออกเอกสาร NCR, การคัดแยกวัตถุดิบ, งานระหว่างผลิต, สินค้าสำเร็จรูป, บรรจุภัณฑ์ ไปจนถึงทรัพย์สินของลูกค้า

## 2. คำจำกัดความ (Definitions)
- **ผลิตภัณฑ์ที่ไม่เป็นไปตามข้อกำหนด (Nonconforming):** สภาพความบกพร่อง หรือไม่สอดคล้องกับข้อกำหนดของลูกค้า/มาตรฐานบริษัท
- **ใบ NCR:** ใบรายงานผลิตภัณฑ์ที่ไม่เป็นไปตามข้อกำหนด
- **ป้ายแสดงสถานะ (Tag):** ป้ายสีหรือสติ๊กเกอร์ใช้ระบุสถานะชิ้นงานหลังการตรวจสอบ

## 3. การจัดการเมื่อพบปัญหา
เมื่อพบชิ้นงานผิดปกติ ไม่ว่าจะพบโดยพนักงานผลิต (Self Inspection), QC ตรวจพบ (Inspection), Supplier แจ้งมา หรือลูกค้าเคลมเข้ามา จะต้องมีการออก **ใบรายงานสิ่งที่ไม่เป็นไปตามข้อกำหนด (FM-QCS-009)** แจ้งไปยังแผนกที่เกี่ยวข้องเสมอ (กรณีลูกค้าเคลมด่วนต้องตอบกลับภายใน 3 วัน, ปกติ 7 วัน)

## 4. การตัดสินใจและแนวทางแก้ไข
หัวหน้า QC หรือผู้จัดการฝ่ายประกันคุณภาพ จะพิจารณาและตัดสินใจเลือก 4 แนวทาง:
1. **ACCEPT:** ยอมรับให้ใช้งานได้เป็นกรณีพิเศษ (Concession Request) 
2. **REJECT:** ส่งคืน Supplier หรือนำกลับไปผลิตใหม่
3. **REWORK:** นำกลับไปซ่อมแซม (ต้องมีการทวนสอบซ้ำเสมอหลังซ่อม)
4. **SCRAP:** นำไปทำลายทิ้ง *(หมายเหตุ: หากมูลค่าของเสียเกิน 10,000 บาท ต้องให้ Director เป็นผู้อนุมัติทำลาย)*

## 5. การคัดแยกและชี้บ่ง (Segregation & Tagging)
- ชิ้นงาน NG ต้องถูกแยกออกไปยังพื้นที่ที่กำหนด (Repair Area / NG Box / Holding Box)
- **Tag HOLD (สีเหลือง):** ชิ้นงานรอการพิจารณา
- **Tag SCRAP (สีแดง):** ชิ้นงานของเสีย รอทำลาย

## 6. การป้องกันปัญหาเกิดซ้ำ (Corrective Action)
- ปัญหาที่ร้ายแรง (Rank A) หรือได้รับข้อร้องเรียนจากลูกค้า ต้องออก **Corrective Action Report (CAR)** หรือทำ **5P Report** เพื่อวิเคราะห์รากเหง้าปัญหา (Root Cause) และกำหนดมาตรการป้องกันการเกิดซ้ำ (Preventive Action)
- หากต้องใช้ชิ้นงานกรณีพิเศษที่ผิดสเปคแต่ไม่กระทบการใช้งาน ต้องขออนุมัติ "Repair Record [Concession Request]" จากผู้จัดการคุณภาพก่อนนำไปใช้

## 7. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ตลอดอายุการใช้งาน (Lifetime)
