# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมการเปลี่ยนแปลงทางวิศวกรรม (Engineering Change Control Procedure)
**รหัสเอกสาร:** SP-RDD-005 (Rev.01)
**วันที่ประกาศใช้:** 15/08/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้ในการควบคุมและร้องขอการเปลี่ยนแปลงเกี่ยวกับเอกสารทางวิศวกรรมและตัวผลิตภัณฑ์ที่มีการเปลี่ยนแปลง
- **ขอบเขต:** ครอบคลุมขั้นตอนการปฏิบัติงานเพื่อเปลี่ยนแปลงข้อมูลทั้งภายในและภายนอกบริษัท

## 2. คำจำกัดความ (Definitions)
- **เอกสารการเปลี่ยนแปลง:** หมายถึง เอกสารที่ใช้ในการร้องขอเปลี่ยนแปลงภายในบริษัท เช่น BOM (Bill of Materials), DRAWING (แบบแปลน), WORK INSTRUCTION (WI), SPEC PRODUCT และกระบวนการทำงานต่างๆ

## 3. ความรับผิดชอบหลัก
- **Manager & Engineer (ฝ่ายวิศวกรรม):** ติดต่อประสานงานกับหน่วยงานที่เกี่ยวข้อง เมื่อมีการเปลี่ยนแปลงและเป็นผู้ร้องขอการเปลี่ยนแปลง
- **ฝ่ายจัดซื้อ (PU):** จัดหาวัตถุดิบเพื่อนำมาใช้ในการผลิตชิ้นงานตั้งแต่ช่วงเริ่มต้นจนถึงการผลิตจริง (Mass Production)
- **ฝ่ายควบคุมคุณภาพ (QA/QC):** ประกันคุณภาพของสินค้าให้ได้ตามมาตรฐานก่อนส่งมอบ
- **ฝ่ายผลิต (PD):** ทำการผลิตสินค้าให้เป็นไปตามรูปแบบที่ได้รับการออกแบบและอนุมัติแล้ว

## 4. ขั้นตอนการดำเนินงาน (Engineering Change Process Flow)
1. **การรับความต้องการ:** ฝ่ายการตลาดรับความต้องการสินค้าใหม่หรือการปรับปรุงจากลูกค้า และส่งให้ฝ่ายวิศวกรรมประเมินความเป็นไปได้ (Able to Develop)
2. **การออกแบบและประเมินต้นทุน:** 
   - วิศวกรรมทำการออกแบบ (Drawing, BOM, Spec) 
   - ทำการวิเคราะห์ต้นทุน (Cost Analysis) เพื่อเสนอราคา (Quotation) ให้ลูกค้าอนุมัติ
3. **การสร้างตัวอย่าง (Prototype):** เมื่อลูกค้าตกลงเรื่องราคา จะทำการสร้าง Prototype และทดสอบ (Evaluation Testing)
4. **การเตรียมการผลิต (Pre-Production):**
   - จัดประชุมร่วมกันระหว่างแผนก (BOM, กำหนดการผลิต, จัดส่ง)
   - สรุปชิ้นส่วนวัตถุดิบ (Approve Part) และออกแบบกระบวนการผลิต (WI, Control Plan, FMEA)
5. **การทดลองผลิต (Trial Production):** ทำการทดลองผลิตและประเมินผล (Trial Result)
6. **การอนุมัติและการผลิตจริง:** QA ประเมินและอนุมัติ Lot หากผ่านจึงจะเข้าสู่กระบวนการผลิตจริง (Mass Production)

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบแจ้งการเปลี่ยนแปลงทางวิศวกรรม (ECN - Engineering Change Notification) และแบบคำร้องขอเปลี่ยนแปลง 4M (4M Change Request Sheet)
