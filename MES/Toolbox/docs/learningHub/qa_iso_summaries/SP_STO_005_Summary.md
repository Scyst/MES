# สรุประเบียบปฏิบัติ (Standard Procedure) - [เอกสารยกเลิก/สำหรับอ้างอิง]
**ชื่อเอกสาร:** มาตรการการจัดการการเรียกคืนผลิตภัณฑ์ (Product Recall Management Measures)
**รหัสเอกสาร:** SP-STO-005 (Rev.00)
**วันที่ประกาศใช้:** 07/11/2022
*(หมายเหตุ: เอกสารฉบับนี้ถูกระบุสถานะ "ยกเลิก" ในระบบไฟล์ปัจจุบัน แต่ถูกนำมาสรุปเพื่อเป็นกรณีศึกษาและอ้างอิง)*

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนการเรียกคืนผลิตภัณฑ์ (Recall) เมื่อเกิดปัญหาด้านคุณภาพร้ายแรง อันตรายต่อความปลอดภัย หรือขัดต่อกฎหมาย/นโยบายของประเทศปลายทาง
- **ขอบเขต:** ครอบคลุมผลิตภัณฑ์เครื่องปรับอากาศที่ส่งออกต่างประเทศและขายในประเทศทั้งหมด

## 2. เงื่อนไขที่ต้องทำการเรียกคืนผลิตภัณฑ์ (Conditions for Recall)
ผลิตภัณฑ์จะต้องถูกเรียกคืน (โดยต้องได้รับการอนุมัติจากผู้บริหาร) เมื่อเข้าข่ายดังนี้:
1. เป็นภัยคุกคามต่อร่างกายหรือทรัพย์สินของผู้ใช้งาน
2. ไม่เป็นไปตามมาตรฐานความปลอดภัย หรือมีปัญหาคุณภาพร้ายแรง
3. ขัดต่อกฎหมาย ข้อบังคับ หรือมาตรฐานของประเทศ/ภูมิภาคที่ส่งออก
4. การออกแบบขัดต่อวัฒนธรรมหรือศีลธรรมของท้องถิ่นนั้นๆ
5. กรณีพิเศษที่ต้องหลีกเลี่ยงผลกระทบเชิงลบต่อภาพลักษณ์ของแบรนด์ (Brand Image)

## 3. ความรับผิดชอบและขั้นตอนการเรียกคืน (Workflow)
1. **รับเรื่องและวิเคราะห์:**
   - **ฝ่ายการตลาด (ในประเทศ/ต่างประเทศ):** รับเรื่องปัญหาจากตลาด และส่งข้อมูลให้แผนกคุณภาพ (QA/QC)
   - **แผนกคุณภาพ:** วิเคราะห์ปัญหาเชิงลึก นำเสนอแนวทางแก้ไข และทำรายงานขออนุมัติเรียกคืนจากผู้บริหาร
2. **การสั่งการเรียกคืน:**
   - เมื่อผู้บริหารอนุมัติ แผนกคุณภาพจะออกเอกสาร "จดหมายติดต่อทางธุรกิจ" แจ้งฝ่ายการตลาดและฝ่ายปฏิบัติการ
   - ฝ่ายปฏิบัติการเช็คสต๊อก ฝ่ายการตลาดเช็คข้อมูลลูกค้าที่ซื้อไป เพื่อตีกรอบขอบเขตการเรียกคืน และลงมือเรียกคืนสินค้าจากตลาด
3. **การจัดการสินค้าที่เรียกคืนมาแล้ว:**
   - สินค้าจะถูกส่งมาเก็บที่ **ฝ่ายจัดการการผลิต**
   - **ศูนย์พัฒนา (R&D / Technology):** ออกแบบแผนทางเทคนิคและกระบวนการบรรจุหีบห่อใหม่เพื่อแก้ปัญหา
   - **ฝ่ายผลิต:** ทำการปรับปรุงหรือบรรจุหีบห่อใหม่ตามแผนงานที่ศูนย์พัฒนากำหนด
4. **การตรวจสอบและขายซ้ำ:**
   - **แผนกคุณภาพ (QC):** ทำการสุ่มตรวจสอบสินค้าที่ผ่านการแก้ไขแล้ว หากผลผ่านเกณฑ์มาตรฐาน สินค้านั้นจะสามารถนำกลับไปขายได้อีกครั้ง
5. **การป้องกันซ้ำ:** แผนกคุณภาพต้องตรวจสอบรากเหง้าของปัญหา (Root Cause) และจัดการแก้ไขปัญหาคุณภาพแบบครบวงจร
