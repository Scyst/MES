# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การวัดความพึงพอใจของลูกค้า (Customer Survey)
**รหัสเอกสาร:** SP-QCS-010 (Rev.01)
**วันที่ประกาศใช้:** 28/09/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อสำรวจระดับความพึงพอใจของลูกค้า และนำข้อมูลที่ได้มามุ่งเน้นปรับปรุงพื้นที่หรือกระบวนการที่ยังมีปัญหา
- **ขอบเขต:** ขั้นตอนการสำรวจความพึงพอใจนี้ใช้สำหรับลูกค้าของบริษัท SCAN

## 2. ความรับผิดชอบ
- **MINI MD / Manager:** รับผิดชอบหลักในการออกแบบแบบสำรวจ, วิเคราะห์ข้อมูล และรายงานผลต่อผู้บริหาร

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การออกแบบและกำหนดความถี่:**
   - MINI MD / Manager ออกแบบฟอร์มการสำรวจ (FM-QCS-015) 
   - กำหนดให้มีการประเมินผล **1 ครั้งต่อปี**
2. **การแจกจ่ายและรวบรวมข้อมูล:**
   - แจกจ่ายแบบสำรวจให้กับลูกค้า
   - รวบรวมข้อมูลกลับมา หากลูกค้าไม่ตอบกลับ ให้ทำการติดตามผล (Follow-up) **2 ครั้ง** หากยังไม่ได้รับผล จะถือว่าแบบสำรวจนั้นใช้งานไม่ได้
3. **การวิเคราะห์ผลการสำรวจ:**
   - วิเคราะห์หาแนวโน้มความพึงพอใจของลูกค้า (Trend)
   - วิเคราะห์เรื่องที่ไม่พึงประสงค์ของลูกค้า (Unpleasant issues)
   - เปรียบเทียบเป้าหมายกับคู่แข่ง
   - **กรณีที่ผลลัพธ์ไม่ตรงตามเป้าหมาย:** MINI MD / Manager จะติดต่อไปยังแผนกที่เกี่ยวข้อง เพื่อให้จัดทำแผนการดำเนินงานแก้ไขปรับปรุง
4. **การรายงานผล:**
   - รายงานผลการดำเนินงานทั้งหมดให้ผู้บริหารระดับสูงรับทราบ

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** แบบสำรวจความพึงพอใจ และผลการวิเคราะห์ เก็บรักษาไว้เป็นเวลา **5 ปี**
