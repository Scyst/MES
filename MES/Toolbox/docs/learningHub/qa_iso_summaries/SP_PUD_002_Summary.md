# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** กระบวนการสั่งซื้อวัตถุดิบ (Raw Material Purchase)
**รหัสเอกสาร:** SP-PUD-002 (Rev.01)
**วันที่ประกาศใช้:** 13/10/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางการสั่งซื้อวัตถุดิบและชิ้นส่วนในประเทศ ให้สอดคล้องกับแผนการผลิต และรักษาระดับสต๊อกตามนโยบาย (Stock Ratio Policy)
- **ขอบเขต:** ครอบคลุมตั้งแต่การคำนวณการสั่งซื้อ การออกใบสั่งซื้อ (PO) การติดตามการส่งมอบ จนถึงการรับของ

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการแผนกจัดซื้อ:** จัดทำและพิจารณารายชื่อผู้ขายที่ได้รับการอนุมัติ (Approved Supplier List)
- **พนักงานจัดซื้อ:** ดำเนินการออกใบสั่งซื้อ โดยต้องสั่งซื้อจากร้านค้าที่อยู่ใน Approved Supplier List เท่านั้น

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การตรวจสอบความต้องการ (PR):**
   - นำข้อมูลแผนการผลิตมาประมวลผล (RUN MRP) ในระบบ SAP เพื่อหาความต้องการซื้อ (Purchase Request - P/R)
   - จัดซื้อตรวจสอบความถูกต้องของ P/R (เช่น Part Name, DWG No., จำนวน, ราคา, วันที่ต้องการ) หากข้อมูลไม่ครบให้ตีกลับ
2. **การออกใบสั่งซื้อ (PO):**
   - จัดซื้อเปลี่ยน P/R เป็นใบสั่งซื้อ (PO) ในระบบ SAP
   - PO ต้องได้รับการอนุมัติตามลำดับขั้น (Manager และ MD)
   - ส่ง PO ให้ผู้ขาย และผู้ขายต้องเซ็นรับทราบ (Supplier Acknowledgement) กลับมาเป็นหลักฐาน
3. **การควบคุมพิเศษ (สารเคมี):** 
   - หากสั่งซื้อสารเคมีต้องห้าม จัดซื้อจะต้องร้องขอเอกสาร **RoHS, Test Report, และ MSDS** จากผู้ขายเสมอ
4. **การติดตามการส่งมอบ (Follow Up):**
   - จัดซื้อต้องติดตามการส่งมอบล่วงหน้า **5 วัน** ก่อนถึงกำหนด (Due Date)
   - **กรณีผู้ขายส่งของไม่ทัน:** ต้องเช็คกับฝ่ายผลิตว่าปรับแผนได้หรือไม่ หากปรับไม่ได้ต้องเร่งรัดผู้ขาย หรือจัดประชุมด่วนเพื่อหาทางออก
5. **การรับสินค้า:**
   - ผู้ขายต้องแนบสำเนา PO มากับใบกำกับภาษีทุกครั้ง
   - หากสินค้ามีปัญหาด้านคุณภาพ แผนกคลังสินค้า (Store) จะแจ้ง QC ตรวจสอบ และแจ้งจัดซื้อเพื่อเคลมกับ Supplier ต่อไป

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ใบสั่งซื้อ (Purchase Order) เก็บรักษาไว้เป็นเวลา **1 ปี** หรือตามที่ลูกค้าต้องการ
