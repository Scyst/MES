# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การตรวจสอบเครื่องจักรและอุปกรณ์ (Machine & Equipment Check)
**รหัสเอกสาร:** SP-PDD-005 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการตรวจสอบเครื่องจักรและอุปกรณ์ (เช่น Jig) ภายในโรงงาน ให้ทำงานได้อย่างมีประสิทธิภาพและมีความปลอดภัยในการใช้งาน
- **ขอบเขต:** ครอบคลุมเครื่องจักรและอุปกรณ์ทั้งหมดที่ใช้ผลิตชิ้นงานภายในแผนกผลิต

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการฝ่ายผลิต / พนักงานฝ่ายผลิต:** รับผิดชอบตรวจสอบการทำงานของเครื่องจักรและ Jig ในสายการผลิต **ทุกวัน** ตามใบตรวจสอบ (Check Sheet)
- **แผนกซ่อมบำรุง (Maintenance):** ตรวจเช็คเครื่องจักรตามแผนงานซ่อมบำรุงประจำปี (PM) และทำการซ่อมแซมบำรุงรักษาเมื่อเครื่องจักรมีปัญหา

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การตรวจสอบประจำวัน (Daily Check):** 
   - ฝ่ายผลิตต้องทำการตรวจสอบเครื่องจักรและอุปกรณ์ทุกวันก่อนเริ่มงาน โดยบันทึกผลลงใน "ใบตรวจสอบเครื่องจักร (FM-PDD-023)" และ "ใบตรวจสอบ JIG (FM-PDD-024)"
2. **การจัดการเมื่อพบความผิดปกติ:** 
   - หากพบข้อบกพร่อง **ต้องหยุดใช้เครื่องจักรทันที**
   - แจ้งให้หัวหน้างานและแผนกซ่อมบำรุงรับทราบ เพื่อเข้าดำเนินการแก้ไขปรับปรุงให้เครื่องจักรกลับมาใช้งานได้อย่างปลอดภัย

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ใบตรวจสอบเครื่องจักร, ใบตรวจสอบ JIG และใบเก็บประวัติการแก้ไขเครื่องจักรอุปกรณ์ เก็บรักษาไว้เป็นเวลา **5 ปี**
