# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** ขั้นตอนจัดทำ (WI) การผลิต (Work Instruction Preparation)
**รหัสเอกสาร:** SP-PDD-009 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นมาตรฐานการทำงานให้พนักงานฝ่ายผลิตและประกอบสามารถปฏิบัติงานได้อย่างถูกต้อง และยืนยันคุณภาพในแต่ละขั้นตอน
- **ขอบเขต:** ครอบคลุมการจัดทำเอกสารขั้นตอนการปฏิบัติงาน (Work Instruction - WI) ของฝ่ายผลิต

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการฝ่ายผลิต:** ติดตามความคืบหน้าของการจัดทำเอกสารตามแผนงาน
- **ผู้จัดการฝ่ายควบคุมคุณภาพ (QA):** แจ้งข้อมูลการเปลี่ยนแปลงจากลูกค้า และจัดทำมาตรฐานการตรวจสอบชิ้นงานประกอบลงใน WI
- **Supervisor:** เป็นผู้รับผิดชอบหลักในการจัดทำเอกสาร WI รวมถึงรวบรวมข้อมูลปัญหาคุณภาพในแต่ละอดีตมาปรับปรุงวิธีการทำงานใน WI

## 3. หลักเกณฑ์การจัดทำขั้นตอนการปฏิบัติงาน (WI)
เอกสาร WI ที่ดีจะต้องประกอบด้วยหัวข้อบังคับ ดังต่อไปนี้:
1. **ข้อมูลทั่วไป:** รหัส/ชื่อกระบวนการผลิต, เลขที่ควบคุมเอกสาร, แผนก/สายการผลิต
2. **รูปภาพประกอบ:** ต้องมีภาพถ่ายหรือภาพวาดประกอบขั้นตอนการปฏิบัติงานให้เห็นชัดเจน
3. **ลำดับวิธีการทำงาน:** เขียนอธิบายวิธีการปฏิบัติงานเรียงตามลำดับ 1, 2, 3... จนจบขั้นตอน
4. **ข้อกำหนดด้านคุณภาพ (Quality Requirement):** ระบุรายละเอียดที่สำคัญ เช่น ความกว้าง ความยาว ความสูง
5. **วิธีการตรวจสอบ (Inspection Method):** ระบุว่าพนักงานต้องตรวจสอบชิ้นงานอย่างไร เช่น ตรวจด้วยสายตา หรือใช้เครื่องมือวัด
6. **ความถี่ในการตรวจสอบ:** ระบุว่าต้องตรวจบ่อยแค่ไหน (เช่น ทุกชิ้น, ทุก 2 ชั่วโมง)
7. **ข้อควรระวังและอุปกรณ์ป้องกัน (Safety & Precaution):** ระบุข้อควรระวังที่อาจส่งผลกระทบต่อชิ้นงาน และต้องระบุ **อุปกรณ์ป้องกันภัยส่วนบุคคล (PPE)** ที่พนักงานต้องสวมใส่ระหว่างทำงาน

*หมายเหตุ:* หากมีการแก้ไข WI จะต้องใส่สัญลักษณ์รูปสามเหลี่ยม $\triangle$ พร้อมระบุครั้งที่แก้ไข (Rev. No.) กำกับไว้ที่หน้าข้อความนั้น

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารขั้นตอนปฏิบัติงาน (WI) จัดเก็บรักษาไว้เป็นเวลา **5 ปี**
