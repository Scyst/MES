# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การบำรุงรักษาเครื่องจักรเชิงป้องกัน (Preventive Maintenance - PM)
**รหัสเอกสาร:** SP-MTD-001 (Rev.00)
**วันที่ประกาศใช้:** 26/07/2016

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าเครื่องจักรและอุปกรณ์ทั้งหมดในโรงงานที่ส่งผลกระทบต่อคุณภาพสินค้า จะได้รับการตรวจเช็ค ดูแล และบำรุงรักษาตามรอบเวลาที่กำหนด เพื่อให้เครื่องจักรทำงานได้อย่างมีประสิทธิภาพและต่อเนื่อง
- **ขอบเขต:** ครอบคลุมกิจกรรมการซ่อมบำรุงรักษาเชิงป้องกัน (PM) สำหรับเครื่องจักรและอุปกรณ์ทั้งหมดภายในบริษัทที่มีรายชื่ออยู่ในทะเบียนเครื่องจักร

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการโรงงาน:** รวบรวมและขึ้นทะเบียนเครื่องจักร (Machine List)
- **หัวหน้าแผนกซ่อมบำรุง (Maintenance):** จัดทำแผน PM ประจำปี/ประจำเดือน และควบคุมการปฏิบัติงานซ่อมบำรุง
- **ช่างซ่อมบำรุง:** ปฏิบัติงานบำรุงรักษาและซ่อมเครื่องจักรตามแผนที่กำหนด
- **หัวหน้าแผนกที่เกี่ยวข้อง (เช่น ฝ่ายผลิต):** ตรวจเช็คเครื่องมือ/เครื่องจักรก่อนการใช้งานประจำวัน (Daily Check) และแจ้งซ่อมเมื่อพบความผิดปกติ

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การขึ้นทะเบียนเครื่องจักร:** แผนกซ่อมบำรุงจัดทำรายชื่อเครื่องจักรและอุปกรณ์ (Machine List) ที่จำเป็นต้องนำมาทำ PM
2. **การจัดทำแผน PM:** 
   - กำหนดความถี่ในการซ่อมบำรุงโดยอ้างอิงจากคู่มือเครื่องจักร (Machine Manual)
   - จัดทำแผน PM ประจำปี (Yearly Plan) และแผน PM ประจำเดือน (Monthly Plan) พร้อมเสนอให้ผู้บังคับบัญชาอนุมัติ
3. **การแจกจ่ายแผนงาน:** ส่งสำเนาแผน PM ให้แผนกที่เกี่ยวข้อง (เช่น ฝ่ายผลิต) รับทราบ เพื่อเตรียมความพร้อมในการหยุดเครื่องจักร
4. **การดำเนินการ PM:**
   - ช่างซ่อมบำรุงเข้าดำเนินการตรวจเช็คตามรอบเวลา โดยใช้แบบฟอร์ม **PM Check Sheet**
   - *กรณีเครื่องจักรไม่พร้อมให้หยุด:* แผนกซ่อมบำรุงจะออกใบแจ้งเลื่อนการซ่อมบำรุง และให้ผู้จัดการแผนกซ่อมบำรุงและฝ่ายผลิตเซ็นอนุมัติการเลื่อน
5. **การตรวจสอบและบันทึกผล:**
   - หัวหน้าแผนกซ่อมบำรุงตรวจสอบผลการทำ PM 
   - เก็บบันทึกข้อมูลลงในประวัติเครื่องจักร เพื่อใช้เป็นฐานข้อมูลในการวางแผนปีถัดไป
   - *กรณีจ้างผู้รับเหมาภายนอก (Supplier) มาทำ PM:* ต้องเก็บประวัติและเอกสารการบริการของผู้รับเหมาไว้ด้วย
6. **การสรุปผล:** สรุปผลการปฏิบัติงานซ่อมบำรุงเชิงป้องกันเป็นรายงาน (Maintenance Report) เสนอต่อผู้บริหาร

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** Machine List, PM Yearly Plan, PM Monthly Plan, และ Daily Check Sheet ของแต่ละแผนก
- **ระยะเวลาการจัดเก็บ:** แผน PM รายปี/รายเดือน เก็บรักษาไว้ **1 ปี**, ส่วนใบแจ้งซ่อมและประวัติเครื่องจักรจะถูกเก็บไว้ **ตลอดไป**
