# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** ขั้นตอนทำตารางควบคุมคุณภาพในกรรมวิธี (Process Quality Control Table - PQCT)
**รหัสเอกสาร:** SP-PDD-008 (Rev.00)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้ยืนยันคุณภาพในแต่ละขั้นตอนการผลิต โดยจัดทำ "ตารางควบคุมคุณภาพในกรรมวิธี (PQCT)" เพื่อแสดงเงื่อนไขและข้อกำหนดที่ต้องควบคุมให้ชัดเจน และใช้เป็นมาตรฐานหากพบปัญหา
- **ขอบเขต:** ใช้จัดทำตารางควบคุมคุณภาพในกรรมวิธีที่ (1) และ (2) โดยอ้างอิงรูปแบบตามที่ลูกค้ากำหนด (เช่น มาตรฐานของ Honda)

## 2. ความรับผิดชอบหลัก
- **พนักงาน (Staff):** ผู้จัดทำเอกสารเพื่อขออนุมัติ
- **หัวหน้างาน (Supervisor):** ทบทวนความถูกต้องของเอกสาร
- **ผู้จัดการแผนก (Manager):** รับรองและพิจารณาเอกสาร
- **ผู้อำนวยการ (Director):** มีอำนาจตัดสินใจลงนามอนุมัติเพื่อยื่นเสนอให้กับลูกค้า

## 3. หลักเกณฑ์การจัดทำ (Procedure)
ผู้จัดทำจะต้องนำ **Drawing** และ **หนังสือ Spec** จากลูกค้ามาเป็นเกณฑ์ในการกรอกรายละเอียดลงในแบบฟอร์ม Process Quality Control Table โดยมีจุดควบคุมที่สำคัญดังนี้:

### ระดับความสำคัญของชิ้นส่วน (Design Rank)
ต้องระบุสัญลักษณ์ระดับความสำคัญตาม Drawing ได้แก่:
- **HS:** ชิ้นส่วนสำคัญยิ่งยวด หากสูญเสียการควบคุมจะเกิดผลฉับพลัน (เกี่ยวข้องกับความปลอดภัย เช่น การหยุด, บังคับเลี้ยว, เพลิงไหม้)
- **HA:** ชิ้นส่วนสำคัญมาก หากสูญเสียการควบคุมจะเกิดผลฉับพลัน (คล้าย HS)
- **HB:** ชิ้นส่วนที่แสดงปัญหาให้เห็นได้ทันที (ไม่เกี่ยวกับความปลอดภัย แต่กระทบภาพพจน์ผลิตภัณฑ์)
- **HC:** ชิ้นส่วนที่ผู้จัดการกำหนดขึ้นมาควบคุมเอง นอกเหนือจาก Drawing
- **N (NH, NF):** คุณลักษณะที่ถูกควบคุมด้วยข้อกฎหมาย

### การกำหนดเงื่อนไขและคุณลักษณะ (Control Items)
- **เงื่อนไขกระบวนการ (Manufacturing Condition):** เช่น การควบคุมความดัน, แรงดันไฟฟ้า, อุณหภูมิ
- **คุณลักษณะทางคุณภาพ (Quality Characteristic):** เช่น การควบคุมความกว้าง, ความยาว, ความสูง

## 4. การนำไปใช้งานและการเก็บบันทึก
- การบังคับใช้ PQCT จะต้องดำเนินตาม **Process Quality Control Operation Flowchart** ซึ่งต้องผ่านการอนุมัติจากลูกค้าก่อนเริ่มการผลิตจริง
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารตารางควบคุมคุณภาพ เก็บรักษาไว้เป็นเวลา **15 ปี หลังจากการแจ้งยุติการผลิต** (End of Life)
