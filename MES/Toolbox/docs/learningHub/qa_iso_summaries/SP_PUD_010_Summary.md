# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การคัดเลือกและประเมินผู้ขายและผู้รับเหมาช่วง (Supplier and Subcontractor Evaluation Procedure)
**รหัสเอกสาร:** SP-PUD-010 (Rev.02)
**วันที่ประกาศใช้:** 19/08/2019

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการพิจารณาคัดเลือก, ตรวจประเมินศักยภาพ, และพัฒนา **ผู้ขาย (Vendor)** และ **ผู้รับเหมาช่วง (Subcontractor)** อย่างต่อเนื่อง
- **ขอบเขต:** ครอบคลุมตั้งแต่กระบวนการติดต่อ คัดเลือก ตรวจประเมิน และพัฒนาผู้ขาย/ผู้รับเหมาช่วงทั้งในและต่างประเทศ

## 2. คำจำกัดความ (Definitions)
- **Subcontractor (ผู้รับจ้างช่วง):** หมายถึง ผู้รับจ้างผลิตชิ้นส่วนที่มีความสำคัญต่อระบบคุณภาพ เช่น งานชุบ, งานปั๊ม, หรืองานฉีดพลาสติก (Injection) เป็นต้น

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
ขั้นตอนหลักจะคล้ายคลึงกับกระบวนการประเมินผู้ขายทั่วไป (SP-PUD-003) แต่มีการเน้นย้ำความครอบคลุมถึงงานจ้างเหมาช่วง:
1. **การลงทะเบียนและคัดเลือก:** ตรวจสอบประวัติผ่านเอกสาร Vendor Register Sheet
2. **การเข้าตรวจประเมิน (Audit):** ออดิทระบบคุณภาพตามมาตรฐาน ISO9001/ISO14001 โดยทีมประเมิน (QA, จัดซื้อ, ผลิต, วิศวกรรม)
3. **เกณฑ์การตัดสิน:** 
   - ผ่าน: นำรายชื่อเข้าสู่ Approved Vendor List (AVL)
   - ไม่ผ่าน (< 70%): ผู้รับจ้างช่วงต้องทำแผนปรับปรุง (Improvement Schedule) และรอประเมินซ้ำ
4. **การประเมินรายเดือนและตัดเกรด 6 เดือน:** ประเมิน 3 ด้าน (Quality, Cost, Delivery) หากได้เกรด C ต้องทำแผนปรับปรุง หากได้เกรด F ติดต่อกัน 2 ครั้งจะถูกตัดออกจาก AVL และบล็อกในระบบ SAP

## 4. ข้อกำหนดเฉพาะของลูกค้า (Customer Specific Requirements)
- **ลูกค้า GEELONG:** กำหนดให้ต้องจัดทำแผนการตรวจติดตามผู้จำหน่าย 3 ประเภท **ทุกปี** ได้แก่:
  1. ประเภท สี
  2. ประเภท กล่องกระดาษ
  3. ประเภท ไม้
- สำหรับลูกค้า GEELONG หากเป็นการส่งผลการ Audit ผู้ขายวัตถุดิบ (Supply Mat'l) ให้ทางบริษัท SCAN ทราบทุกครั้งที่มีการ Audit

## 5. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** แผนและผลการ Audit เก็บตลอดไป, ใบขอเปลี่ยนแปลง (VCR), และใบประเมินรายเดือน/รายครึ่งปี เก็บรักษาไว้ **1 ปี**
