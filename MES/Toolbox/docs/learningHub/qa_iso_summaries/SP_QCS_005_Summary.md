# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การรับรองวัตถุดิบและ Part ใหม่ (Approve New Material & Part)
**รหัสเอกสาร:** SP-QCS-005 (Rev.01)
**วันที่ประกาศใช้:** 20/09/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่ากระบวนการรับรองวัตถุดิบและชิ้นส่วน (Part) ใหม่ของบริษัท มีการตรวจสอบและทดสอบคุณภาพที่ได้มาตรฐานตรงตามที่ลูกค้าต้องการ
- **ขอบเขต:** ครอบคลุมตั้งแต่การกำหนดหัวข้อตรวจสอบ, การตรวจสอบ, ทดสอบ, ทดลองใช้งาน ไปจนถึงการออกใบรับรอง (Approval) ให้แก่วัตถุดิบและ Part ใหม่

## 2. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การกำหนดความต้องการ (Requirement):**
   - ฝ่ายวิจัยและพัฒนา (R&D) มีความต้องการใช้วัตถุดิบหรือชิ้นส่วนใหม่ จึงจัดทำฉบับร่าง Drawing & Spec และส่งให้ฝ่ายจัดซื้อ (Purchasing) ดำเนินการสรรหา
2. **การจัดหาและส่งมอบ (Sourcing & Delivery):**
   - ฝ่ายจัดซื้อจัดหาจาก Supplier ใน AVL (Approved Vendor List) หรือหาแหล่งใหม่
   - Supplier ดำเนินการผลิตและส่งมอบตัวอย่างมาที่บริษัท โดยต้องติดป้ายชี้บ่งชัดเจน
3. **การตรวจสอบและทดสอบ (Inspection & Testing):**
   - R&D จัดทำร่าง Check Sheet เตรียมตรวจสอบตาม Spec 
   - ฝ่ายทดสอบดำเนินการตรวจสอบ/ทดสอบชิ้นงาน (ด้วยเครื่องมือที่ผ่านการสอบเทียบ) และออกรายงานผลการทดสอบ (Certificates) ส่งให้ R&D พิจารณา
4. **การอนุมัติ (Approval / Decision):**
   - **กรณีผ่าน (Accept):** R&D แจ้งฝ่ายจัดซื้อ และออก "ใบรับรองวัตถุดิบ" ให้แก่ Supplier
   - **กรณีไม่ผ่าน (Reject):** แจ้งผลและจุดที่เป็นปัญหาให้ Supplier นำไปแก้ไขปรับปรุงและส่งมาใหม่
5. **การขึ้นทะเบียนเอกสาร (Document Control):**
   - R&D นำ Drawing และ Spec ที่ผ่านการอนุมัติ เข้าสู่ระบบลงทะเบียนเอกสารกลาง และทำสำเนาแจกจ่ายให้หน่วยงานที่เกี่ยวข้อง

## 3. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** Drawing และ Check Sheet ของชิ้นส่วนใหม่ เก็บรักษาไว้เป็นเวลา **5 ปี**
