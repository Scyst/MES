# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** ขั้นตอนการเปลี่ยน PASSWORD และการเบิกใช้ PASSWORD ขั้นสูง
**รหัสเอกสาร:** SP-MIS-002 (Rev.00)
**วันที่ประกาศใช้:** 09/12/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อควบคุมขั้นตอนการเปลี่ยนและเบิกใช้รหัสผ่าน (Password) ขั้นสูงให้มีความมั่นคงปลอดภัย มีการจัดเก็บประวัติที่ตรวจสอบได้ และป้องกันพนักงานที่พ้นสภาพจากการเข้าถึงระบบ
- **ขอบเขต:** ครอบคลุมการเปลี่ยนและเบิกใช้รหัสผ่านขั้นสูงของบริษัทในเครือทั้งหมด

## 2. คำจำกัดความ (Definitions)
- **PASSWORD ขั้นสูง (Privileged Account):** หมายถึง บัญชีผู้ดูแลระบบที่มีสิทธิ์สูงสุด (Administrator) เช่น Domain Admin, Email-Admin, Firewall, Database, และ SAP BASIS

## 3. ความรับผิดชอบหลัก
- **กรรมการบริหาร (MD):** เป็นผู้อนุมัติการเบิกใช้รหัสผ่านขั้นสูง
- **ผู้จัดการแผนกสารสนเทศ (IT Manager) / Application Manager:** เป็นผู้เปลี่ยนและสมุดบันทึกการใช้รหัสผ่านขั้นสูง
- **ผู้ใช้งานระบบขั้นสูง (System Admin, ERP Specialist, Cyber Security):** เป็นผู้เบิกใช้และปฏิบัติตามมาตรการอย่างเคร่งครัด

## 4. นโยบายการบริหารบัญชีผู้มีสิทธิ์สูง (Privileged Account Management)
- **จำกัดสิทธิ์:** ให้ใช้งานบัญชีผู้มีสิทธิ์สูงให้น้อยที่สุดและเท่าที่จำเป็นเท่านั้น
- **ห้ามใช้ร่วมกัน:** ไม่ควรใช้บัญชี `Root` หรือ `Administrator` ร่วมกันหลายคน (Share Password) เพราะจะทำให้ไม่สามารถตรวจสอบย้อนหลังได้ว่าใครเป็นผู้กระทำการหากเกิดปัญหาหรือการโจมตี
- **ลดความเสี่ยง:** บัญชีเหล่านี้สามารถเข้าถึงข้อมูลสำคัญและสร้างความเสียหายแก่ระบบได้สูงมาก จึงต้องควบคุมการเบิกจ่ายอย่างเข้มงวด

## 5. มาตรฐานการตั้งรหัสผ่าน (Password Security)
- มีความยาว **ไม่น้อยกว่า 8 ตัวอักษร**
- ประกอบด้วยอักษรตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์พิเศษผสมกัน
- **ข้อห้าม:** 
  - ห้ามใช้ข้อมูลส่วนตัว (ชื่อ, วันเกิด, เบอร์โทร) หรือคำที่มีความหมายในพจนานุกรม
  - ห้ามใช้ตัวเลขเรียงกัน (1234) หรือซ้ำกัน (1111)
  - ห้ามเขียนรหัสผ่านทิ้งไว้บนกระดาษหรือแปะไว้ตามที่ต่างๆ
  - ห้ามตั้งฟังก์ชันจำรหัสผ่านอัตโนมัติ (Auto-save password) ในระบบที่สำคัญ
  - ห้ามใช้รหัสผ่านซ้ำกับที่เคยใช้ไปแล้ว

## 6. ขั้นตอนการดำเนินการเปลี่ยน PASSWORD ขั้นสูง
1. **รอบการเปลี่ยน:** รหัสผ่านขั้นสูงทุกระบบ **ต้องถูกเปลี่ยนทุกๆ 90 วัน**
2. **การขออนุมัติ:** เจ้าหน้าที่ (เช่น System Admin) ต้องกรอก **"แบบฟอร์มการขอเบิกใช้ PASSWORD ขั้นสูง" (FM-MIS-013)** และเสนอให้กรรมการบริหาร (MD) เซ็นอนุมัติ
3. **การบันทึกประวัติ:** หลังจากเปลี่ยนรหัสผ่านเรียบร้อย จะต้องบันทึกประวัติลงใน **"แบบฟอร์มประวัติการเปลี่ยน PASSWORD ขั้นสูง" (FM-MIS-015)**
4. **การตรวจสอบ:** ทุกๆ 6 เดือน จะต้องพิมพ์ประวัติการเปลี่ยนรหัสผ่านขั้นสูงออกมาให้กรรมการผู้จัดการอาวุโสเซ็นรับรอง

## 7. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารทั้งหมดของแผนก MIS (รวมถึงแบบฟอร์มการขอเบิกใช้และประวัติการเปลี่ยนรหัสผ่าน) ถูกจัดเก็บอย่างน้อย **1 ปี**
