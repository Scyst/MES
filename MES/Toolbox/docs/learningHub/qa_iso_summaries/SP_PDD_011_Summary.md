# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมการผลิตชิ้นส่วนแลกเปลี่ยนความร้อน (Heat Exchanger Production Control)
**รหัสเอกสาร:** SP-PDD-011 (Rev.03)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้ควบคุมขั้นตอนกระบวนการผลิตตั้งแต่เป็นวัตถุดิบจนกลายเป็นผลิตภัณฑ์สำเร็จรูป (Heat Exchanger)
- **ขอบเขต:** ครอบคลุมกระบวนการผลิตในแผนก Heat Exchanger ทั้งหมด

## 2. ความรับผิดชอบหลัก
- **ฝ่ายวางแผน (Planning):** จัดทำและส่งแผนการผลิต (Master Plan)
- **ผู้จัดการ / Supervisor แผนกผลิต:** วางแผนย่อย, ควบคุมคุณภาพ, ตรวจความพร้อมของเครื่องจักร
- **พนักงานฝ่ายผลิต:** เบิกวัตถุดิบ, ตรวจเช็คเครื่องจักรก่อนเริ่มงาน, บันทึกยอดผลิตและปัญหาลงในใบ Check Sheet ประจำชั่วโมง
- **พนักงาน QC:** เข้าตรวจสอบคุณภาพในสายการผลิตตามเอกสารมาตรฐาน IQS (Incoming Quality Standard)

## 3. ขั้นตอนการผลิต Heat Exchanger (Workflow)
1. **การเตรียมวัตถุดิบ:** ฝ่ายผลิตรับแผนงาน นำไปเบิกวัตถุดิบจากสโตร์ เมื่อได้ของให้ตรวจสอบ หาก Part ผิดให้ส่งคืนสโตร์ทันที
2. **กระบวนการผลิตหลัก:** พนักงานต้องผลิตชิ้นงานตาม Control Plan, Drawing, และ WI โดยผ่านเครื่องจักรตามลำดับดังนี้:
   - ปั๊มขึ้นรูปอะลูมิเนียมฟิน (Fin Press Machine)
   - ตัดท่อทองแดง (Hairpin Bender)
   - ร้อยคอยล์ (Insert Hairpin)
   - อัดคอยล์ (Vertical Expander Machine)
   - อบคอยล์ (Dry Oven Machine)
   - เชื่อม U-pipe (Auto Brazing)
   - เช็ครอยรั่ว (Leak Test)
3. **การจัดการเมื่อพบปัญหา (NG):**
   - **พบปัญหางานเสียจากการผลิต:** นำงานออกจากไลน์ (Line out) บันทึกยอดเสีย นำไปซ่อม (Repair) และส่งกลับเข้ากระบวนการผลิตใหม่
   - **พบปัญหาจากวัตถุดิบ (Raw Material):** ต้องรีบแจ้ง SCM, QC และ Planning ทันที
4. **การจบงาน (End Line):**
   - ชิ้นงานที่ผ่านกระบวนการจะถูกบันทึกลง **Production Report** 
   - ระบบจะทำการตัดยอดวัตถุดิบ และโอนยอดสินค้าสำเร็จรูป (FG) เข้าสู่คลังสินค้า (Storage Location OEM)
   - ปิด Job การผลิต

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารต่างๆ เช่น แผนการผลิต, ใบตรวจสอบเครื่องจักรประจำวัน, ใบเช็ครอยรั่ว, และใบแจ้งซ่อม จัดเก็บรักษาไว้เป็นเวลา **5 ปี**
