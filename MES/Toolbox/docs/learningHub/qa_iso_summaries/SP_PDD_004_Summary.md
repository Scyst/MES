# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การประเมินความล้มเหลวของสายการผลิต (Process FMEA & A)
**รหัสเอกสาร:** SP-PDD-004 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้วิเคราะห์ปัญหาและจุดเสี่ยงที่อาจส่งผลกระทบต่อกระบวนการผลิต (ประเมินก่อนติดตั้งสายการผลิต) และหาแนวทางป้องกันเพื่อลดความผันแปรของกระบวนการ
- **ขอบเขต:** เริ่มตั้งแต่การรับข้อมูลผลิตภัณฑ์ใหม่จาก R&D, การตั้งทีมงาน (Function Team), การทำ FMEA ไปจนถึงการกำหนดมาตรการป้องกัน (Preventive Action)

## 2. หน้าที่ความรับผิดชอบหลัก
- **ฝ่ายออกแบบ (Design):** วิเคราะห์สเปคผลิตภัณฑ์ และออก Drawing / BOM
- **ฝ่ายวิศวกรรม (Engineering):** ออกแบบกระบวนการควบคุม, นำทีมทำ Process FMEA, และหามาตรการป้องกัน
- **ฝ่ายผลิต (Production) / QA:** ร่วมประเมินความเสี่ยงและกำหนดแนวทางป้องกัน

## 3. หลักการประเมินความเสี่ยง (FMEA - Failure Mode and Effects Analysis)
การประเมินระดับความเสี่ยงจะคำนวณจากค่า **RPN (Risk Priority Number)** ซึ่งมาจากสมการ:
> **RPN = S x O x D**

โดยแบ่งเกณฑ์คะแนน (1-5) ดังนี้:
1. **S (Severity - ความรุนแรง):**
   - 5 = ร้ายแรงมาก (กระทบความปลอดภัย/ข้อกฎหมาย)
   - 4 = ร้ายแรง (ทำให้ผลิตไม่ได้/หยุดชะงัก)
   - 3 = ค่อนข้างร้ายแรง (ลูกค้าไม่พอใจ)
   - 2 = เล็กน้อย (ลูกค้าอาจสังเกตเห็น)
   - 1 = เกือบจะไม่มีผลกระทบ
2. **O (Occurrence - โอกาสเกิด):**
   - 5 = เกิดขึ้นบ่อย (> 1 ครั้ง/วัน)
   - 4 = เกิดสูง (1 ครั้ง/สัปดาห์)
   - 3 = ปานกลาง (1 ครั้ง/3 เดือน)
   - 2 = ต่ำ (1 ครั้ง/ปี)
   - 1 = แทบจะไม่เกิด (1 ครั้ง/3 ปี)
3. **D (Detection - การตรวจจับ):**
   - 5 = ไม่สามารถตรวจจับได้
   - 4 = ตรวจจับยาก (สุ่มตรวจเป็นระยะ)
   - 3 = ตรวจจับได้ภายในสายการผลิต
   - 2 = ตรวจพบในกระบวนการถัดไป
   - 1 = ตรวจพบได้อย่างแน่นอน

## 4. เกณฑ์การจัดลำดับความเร่งด่วนในการแก้ไข
เมื่อได้ค่า RPN ให้นำมาเทียบระดับความเร่งด่วน ดังนี้:
- **ระดับ S (RPN 64-125):** ต้องดำเนินมาตรการแก้ไขโดยทันที
- **ระดับ A (RPN 27-63):** เฝ้าสังเกตและทำการแก้ไขตามปัญหาที่เกิดขึ้น
- **ระดับ B (RPN 8-26):** ดำเนินการแก้ไขหากเวลาและทรัพยากรเอื้ออำนวย
- **ระดับ C (RPN 1-7):** ความเสี่ยงที่เหลืออยู่ในระดับที่ยอมรับได้ (Acceptable risk)

## 5. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารการประเมิน FMEA เก็บรักษาไว้ **ตลอดอายุการใช้งาน** (Lifetime)
