# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การปฏิบัติการแก้ไข (Corrective Action)
**รหัสเอกสาร:** SP-QCS-006 (Rev.01)
**วันที่ประกาศใช้:** 20/09/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อค้นหาสาเหตุของปัญหาที่ไม่เป็นไปตามข้อกำหนด วิเคราะห์แนวทางแก้ไข และจัดทำมาตรการป้องกันไม่ให้ปัญหาเดิมเกิดซ้ำ (Recurrence) อย่างมีประสิทธิผล
- **ขอบเขต:** ครอบคลุมการหาสาเหตุ, การวางแผนแก้ไข (Action Plan), การติดตามผล และการปรับปรุงมาตรฐานการทำงาน

## 2. คำจำกัดความ (Definitions)
- **QMR:** ตัวแทนฝ่ายบริหาร (Quality Management Representative)
- **CAR (Corrective Action Request):** ใบขอให้ดำเนินการแก้ไขและป้องกัน

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **แหล่งที่มาของปัญหา (Input):**
   - ข้อร้องเรียนหรือเคลมจากลูกค้า (Customer Claim)
   - ข้อสั่งการจากที่ประชุมทบทวนฝ่ายบริหาร (Management Review)
   - รายงานของเสีย/สิ่งที่ไม่เป็นไปตามข้อกำหนด (NCR)
2. **การเปิดใบ CAR:**
   - เจ้าหน้าที่ QA รับเรื่องและเรียกประชุมทีมข้ามสายงาน (Cross Functional Team - CFT) 
   - *กำหนดเวลาตอบกลับ:* กรณีเร่งด่วนไม่เกิน 3 วัน, ปกติภายใน 7 วัน
3. **การวิเคราะห์หาสาเหตุ (Root Cause Analysis):**
   - ใช้เครื่องมือทางสถิติ เช่น Why-Why Analysis, 7 QC Tools (Cause & Effect Diagram)
4. **การกำหนดแนวทางแก้ไข (Action Plan):**
   - ใช้หลักการ 5P, 8D, QCC, QC Story หรือ Tree Diagram มาประยุกต์
   - จัดทำแผนปฏิบัติการ (ACTION PLAN) ระบุหัวข้อ ผู้รับผิดชอบ และกำหนดเสร็จ
5. **การติดตามผล (Follow-up):**
   - QA ติดตามประสิทธิภาพของการแก้ไขว่าปัญหากลับมาเกิดซ้ำหรือไม่ โดยเฝ้าติดตามเป็นระยะเวลา **6 เดือน**
   - หากผ่านการประเมิน (Accept): ให้นำไปขยายผล (Horizontal Deployment) ป้องกันในกระบวนการอื่นที่คล้ายกัน หรือสินค้ารุ่นใหม่
   - หากไม่ผ่าน (Reject): ต้องกลับไปประชุมหาแนวทางใหม่
6. **การปรับปรุงมาตรฐาน (Standard Update) & ปิด CAR:**
   - แผนกที่เกี่ยวข้องต้องอัปเดตเอกสารมาตรฐาน (เช่น WI, Control Plan) และจัดอบรม (Training) พนักงาน
   - QMR หรือผู้จัดการฝ่ายประกันคุณภาพ เป็นผู้อนุมัติ "ปิดใบ CAR"

## 4. การรายงานและเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** บันทึกคุณภาพต่างๆ (เช่น รายงานตรวจประเมิน) เก็บรักษาไว้เป็นเวลา **5 ปี**
