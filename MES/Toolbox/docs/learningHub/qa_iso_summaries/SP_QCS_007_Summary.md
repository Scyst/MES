# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การจัดการคำร้องเรียนของลูกค้า (Customer Complaint)
**รหัสเอกสาร:** SP-QCS-007 (Rev.01)
**วันที่ประกาศใช้:** 20/09/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าข้อร้องเรียนของลูกค้าได้รับการแก้ไขอย่างถูกต้อง เพื่อสร้างความพึงพอใจให้กับลูกค้า
- **ขอบเขต:** ครอบคลุมข้อร้องเรียนและข้อเสนอแนะของลูกค้า ทั้งทางวาจาและเอกสารที่เกี่ยวกับระบบคุณภาพ

## 2. คำจำกัดความ (Definitions)
- **Customer Complain:** คำร้องเรียนของลูกค้าที่แจ้งถึงปัญหาคุณภาพ
- **Customer Claim:** การแจ้งเคลมสินค้าของลูกค้า (ขอชดเชย)
- **C/M (Countermeasure):** มาตรการตอบโต้หรือการแก้ไขปัญหา

## 3. ขั้นตอนการจัดการเมื่อลูกค้ามีการร้องเรียน
1. **การรับเรื่อง:** ฝ่ายวางแผนธุรกิจ (Sales) รับเรื่องจากลูกค้า และแจ้งให้ QA/QC ทราบ
2. **การรวบรวมข้อมูล:** บันทึกข้อมูลลงใบรับคำร้องเรียน (FM-QCS-006) หากข้อมูลไม่ชัดเจน QA จะต้องเดินทางไปดูปัญหาที่หน้างานของลูกค้า
3. **การตรวจสอบและแก้ไขเบื้องต้น (Correction):**
   - QA สืบสวนข้อมูล หากเป็นปัญหาจริงจะออก **CAR (ใบขอให้แก้ไข)** แจ้งฝ่ายที่เกี่ยวข้อง
   - ประสานงานกับผลิตและคลังสินค้าเพื่อเปลี่ยนหรือคัดแยกสต็อกสินค้าส่งให้ลูกค้าใช้ทดแทนชั่วคราว
4. **การวิเคราะห์และหาทางแก้ไข (Action Plan):**
   - QA เรียกประชุมทีมข้ามสายงาน (CFT) ใช้เครื่องมือทางสถิติ (Why-Why, 5P, 8D) หาสาเหตุรากเหง้า
   - สรุปแนวทางแก้ไขเป็น Action Plan
5. **การตอบกลับลูกค้าและการติดตามผล:**
   - นำเสนอการแก้ไขปัญหาให้ลูกค้ายอมรับ (หากลูกค้าไม่ยอมรับ ต้องกลับมาประชุมหาวิธีใหม่)
   - ต้องตอบใบรายงานแก้ไข (FM-QC-005) ให้เสร็จภายใน **7 วัน** และ QA จะติดตามผล (C/M) ทุกๆ 3 เดือน
6. **การปรับปรุงระบบและการสื่อสาร:**
   - สื่อสารปัญหาให้พนักงานทราบผ่านบอร์ดประชมสัมพันธ์ หรือ Morning Talk
   - อัปเดตเอกสารมาตรฐาน (WI/Control Plan) และบันทึกลง Trouble History Sheet
   - สรุปรายงานประจำเดือนให้ฝ่ายบริหารในรอบ Management Review

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** บันทึกข้อร้องเรียน, ใบ CAR, และรายงานสรุป เก็บรักษาไว้เป็นเวลา **5 ปี**
