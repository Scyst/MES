# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การบำรุงรักษาเครื่องจักรเชิงป้องกัน (Preventive Maintenance)
**รหัสเอกสาร:** SP-MTD-004 (Rev.01)
**วันที่ประกาศใช้:** 04/09/2018
*(หมายเหตุ: เอกสารฉบับนี้เป็นฉบับปรับปรุง (Rev.01) ซึ่งมีเนื้อหาและรูปแบบการทำงานเหมือนกับ SP-MTD-001 ทุกประการ แต่อาจมีการปรับปรุงเลขที่เอกสารอ้างอิงและแบบฟอร์มภายใน)*

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าเครื่องจักรและอุปกรณ์ทั้งหมดในโรงงานที่ส่งผลกระทบโดยตรงต่อคุณภาพของสินค้า จะได้รับการตรวจเช็ค ดูแล และบำรุงรักษาตามช่วงระยะเวลาที่กำหนด 
- **ขอบเขต:** ครอบคลุมกิจกรรมการซ่อมบำรุงรักษาเชิงป้องกันสำหรับเครื่องจักรและอุปกรณ์ภายในบริษัทฯ ที่ขึ้นทะเบียนไว้

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการโรงงาน:** รับผิดชอบรวบรวมและขึ้นทะเบียนเครื่องจักร
- **หัวหน้าแผนกซ่อมบำรุง:** รับผิดชอบจัดทำแผน บำรุงรักษา และควบคุมการทำงาน
- **ช่างซ่อมบำรุง:** ปฏิบัติงานตามแผนซ่อมบำรุง
- **หัวหน้าแผนกที่เกี่ยวข้อง:** รับผิดชอบแจ้งซ่อม หรือตรวจเช็คอุปกรณ์ประจำวัน (Daily Check)

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **จัดทำรายชื่อเครื่องจักร:** ช่างซ่อมบำรุงจัดทำรายชื่อ (Machine Master List)
2. **จัดทำแผน PM:** จัดทำแผนการซ่อมบำรุงประจำปีและประจำเดือน
3. **การอนุมัติ:** เสนอแผนให้ผู้จัดการโรงงานอนุมัติ
4. **ดำเนินการตามแผน:** ช่างซ่อมบำรุงเข้าตรวจเช็คตามระยะเวลาที่กำหนด หากเครื่องจักรไม่พร้อมให้แจ้งเลื่อนและบันทึกเหตุผล
5. **บันทึกผล:** หลังดำเนินการเสร็จสิ้น ให้บันทึกประวัติการซ่อมบำรุงลงในแบบฟอร์มและประวัติเครื่องจักร
6. **สรุปผล:** สรุปผลการทำงานประจำเดือน
