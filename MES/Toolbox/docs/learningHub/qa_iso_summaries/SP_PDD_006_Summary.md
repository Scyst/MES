# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การแจ้งซ่อมเครื่องจักร (Repair Machine Request)
**รหัสเอกสาร:** SP-PDD-006 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนการแจ้งซ่อมและการซ่อมบำรุงเครื่องจักร/อุปกรณ์ภายในโรงงาน ให้สามารถกลับมาใช้งานได้อย่างปกติและปลอดภัย
- **ขอบเขต:** ครอบคลุมตั้งแต่การเขียนใบแจ้งซ่อม, การรับเรื่อง, การวิเคราะห์ปัญหา, การเบิกอะไหล่, การลงมือซ่อม, และการทดสอบรับรองผล

## 2. ความรับผิดชอบหลัก
- **ผู้ร้องขอ (พนักงาน/หัวหน้าฝ่ายผลิต):** เขียนใบแจ้งซ่อม และเป็นผู้ตรวจสอบรับรองผลหลังจากการซ่อมเสร็จสิ้น
- **แผนกซ่อมบำรุง (Maintenance):** รับใบแจ้งซ่อม, วิเคราะห์ปัญหา, เบิกอะไหล่, ดำเนินการซ่อม, และบันทึกประวัติการซ่อม

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การแจ้งซ่อม:** 
   - เมื่อเครื่องจักรขัดข้อง ผู้ใช้งานต้องแจ้งหัวหน้างานและเขียน **ใบแจ้งซ่อม (FM-PDD-003)**
   - หัวหน้างานตรวจสอบเบื้องต้น หากแก้เองไม่ได้ ให้ส่งเรื่องให้แผนกซ่อมบำรุง (ใช้ฟอร์ม FM-MTD-001)
2. **การวิเคราะห์และมอบหมายงาน:**
   - หัวหน้าแผนกซ่อมบำรุงวิเคราะห์อาการและมอบหมายให้ช่างซ่อมบำรุง
   - *กรณีซ่อมเองไม่ได้:* หัวหน้าแผนกจะติดต่อช่างภายนอก (Supplier) และทำเรื่อง **ใบขอจัดซื้อ (PR)** เพื่อจ้างซ่อม
3. **การเบิกอะไหล่และการซ่อม:**
   - ช่างซ่อมบำรุงวิเคราะห์ปัญหาเชิงลึก และทำใบเบิกอะไหล่จากสโตร์
   - ดำเนินการซ่อมแซม พร้อมบันทึกสาเหตุและวิธีแก้ไขลงในใบแจ้งซ่อม
4. **การทดสอบและรับรองผล (Verification):**
   - หลังซ่อมเสร็จ ต้องทำการทดลองเดินเครื่องและผลิตชิ้นงานทดสอบจำนวน **30 ชิ้น (n=30 Pcs)** ร่วมกับฝ่ายผลิต
   - **กรณีผ่าน:** ผู้แจ้งซ่อมเซ็นรับรองผลในใบแจ้งซ่อม เพื่อปิดงาน (Close Job)
   - **กรณีไม่ผ่าน:** แผนกซ่อมบำรุงต้องนำกลับไปวิเคราะห์หาสาเหตุและซ่อมใหม่
5. **การบันทึกประวัติ:**
   - เจ้าหน้าที่ซ่อมบำรุงนำข้อมูลไปบันทึกลงใน **ประวัติการซ่อมเครื่องจักร** เพื่อเป็นฐานข้อมูลต่อไป

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารบันทึกประวัติและใบแจ้งซ่อม เก็บรักษาไว้เป็นเวลา **5 ปี**
