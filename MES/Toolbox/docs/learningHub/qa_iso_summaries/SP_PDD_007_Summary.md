# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การปรับปรุงอย่างต่อเนื่อง (Continuous Improvement)
**รหัสเอกสาร:** SP-PDD-007 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการกำหนดกิจกรรมการปรับปรุงองค์กรอย่างต่อเนื่อง (Continuous Improvement)
- **ขอบเขต:** ใช้ภายในบริษัท SCAN (ส่วนสายการผลิต Line AC Hose)

## 2. คำจำกัดความ (Definitions)
การปรับปรุงอย่างต่อเนื่องจะวัดผลผ่านกรอบการทำงาน **DQSS** ซึ่งประกอบด้วย:
- **D = DELIVERY:** การส่งมอบสินค้า (ตรงต่อเวลา)
- **Q = QUALITY:** คุณภาพการส่งมอบผลิตภัณฑ์ (ได้ตามมาตรฐาน)
- **S = STOCK:** การควบคุมปริมาณสินค้าคงคลัง (Stock) ให้เหมาะสม
- **S = SERVICE:** การบริการหลังการขาย

## 3. ความรับผิดชอบและขั้นตอนการปฏิบัติงาน
1. **กรรมการผู้จัดการ / ผู้จัดการฝ่าย:** 
   - รับผิดชอบเจรจาและทำข้อตกลงระยะยาวกับลูกค้า
2. **ฝ่ายควบคุมคุณภาพ (QA/QC):** 
   - วิเคราะห์สัดส่วนของเสีย (% Defect) จากลูกค้า
   - นำเสนอปัญหาคุณภาพให้ที่ประชุมทราบ **ทุกๆ เดือน** และวางแผนปรับปรุง
3. **ผู้จัดการฝ่ายผลิต / MINI MD:** 
   - ดูแล ควบคุม และนำเสนอผลการประเมินตามหลัก **DQSS** เป็นประจำ **ทุกสัปดาห์ / ทุกเดือน**
4. **แผนกบริการลูกค้า (Customer Service):** 
   - ติดตามผลสำรวจความพึงพอใจจากลูกค้าในแต่ละเดือน
5. **เทคนิคการปรับปรุง (Action Plan):**
   - พนักงานต้องมีการนำเสนอ Action Plan ประจำปี เพื่อเป็นเป้าหมายในการปรับปรุงการทำงานของตนเองและหน่วยงานอย่างต่อเนื่อง
