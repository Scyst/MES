# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การวางแผนและกระบวนการผลิต (Planning and Process)
**รหัสเอกสาร:** SP-PDD-001 (Rev.02)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการควบคุมกระบวนการผลิต ให้บรรลุความต้องการของลูกค้าในด้าน **คุณภาพ (Quality), การส่งมอบ (Delivery), และต้นทุน (Cost)**
- **ขอบเขต:** ครอบคลุมกระบวนการผลิตตั้งแต่ได้รับคำสั่งซื้อ (PO) จากลูกค้า ไปจนถึงการส่งมอบเข้าคลังสินค้า

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการฝ่ายผลิต:** บริหารภาพรวม ประสานงานฝ่ายที่เกี่ยวข้อง และปรับปรุงประสิทธิภาพการผลิต
- **MINI MD / Supervisor:** ควบคุมดูแลการผลิตรายวันให้ได้ตามเป้าหมาย, จัดทำคู่มือปฏิบัติงาน (WI), อบรมพนักงาน และเตรียมความพร้อมก่อนผลิต
- **พนักงานฝ่ายผลิต:** ปฏิบัติงานตาม WI, ตรวจสอบคุณภาพงานของตนเอง (Self-check), และแจ้งปัญหาให้หัวหน้าทราบทันที

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การรับคำสั่งซื้อ (Receive PO):**
   - แผนกบริการลูกค้า/MINI MD รับ PO ตรวจสอบชนิด ปริมาณ และกำหนดส่งมอบ แล้วแจ้งให้ทุกฝ่ายทราบ
2. **การวางแผนการผลิต (Production Planning):**
   - จัดประชุมร่วมกับแผนกที่เกี่ยวข้อง โดยอ้างอิงจาก Production Capacity
   - ประสานงานฝ่ายจัดซื้อเพื่อให้วัตถุดิบเข้าสอดคล้องกับแผนการผลิต
3. **การเตรียมความพร้อม (Preparation):**
   - เตรียมเครื่องจักรและอุปกรณ์ให้พร้อม และจะเริ่มผลิตได้เมื่อผู้จัดการโรงงานอนุมัติ
4. **การเริ่มผลิตและควบคุม (Execution & Control):**
   - ทำการผลิตและควบคุมตาม **CONTROL PLAN**
   - ต้องให้ QC หรือผู้รับผิดชอบตรวจสอบ **2 ชิ้นแรก** ก่อนเดินสายการผลิตจริง
   - พนักงานผลิตทำการสุ่มตรวจและตรวจสอบชิ้นงานด้วยตนเองตาม WI
   - **กรณีพบของเสีย:** ให้แยกใส่ **ภาชนะสีแดง** และบันทึกข้อมูล
   - **กรณีพบปัญหาที่แก้ไม่ได้:** พนักงานต้อง **หยุดการผลิต** และแจ้งผู้บังคับบัญชาทันที
5. **การจัดการสินค้าสำเร็จรูปและการสอบกลับ:**
   - สินค้าที่ผ่านการตรวจสอบ (Pass) จะส่งเข้าสโตร์พร้อมใบนำส่ง
   - วัตถุดิบและบรรจุภัณฑ์ที่นำมาใช้ต้องมี **ป้ายชี้บ่ง (Tag)** ติดอยู่ตลอดเวลาเพื่อการสอบกลับ (Traceability) และต้องบันทึกเลขล็อตลงใน Work Sheet

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** บันทึกการผลิต (เช่น Work Lot Sheet, Daily Report, Check Sheet) เก็บรักษาไว้เป็นเวลา **5 ปี**
