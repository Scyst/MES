# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การตรวจและการทดสอบสินค้าสำเร็จรูป (Final Inspection)
**รหัสเอกสาร:** SP-QCS-003 (Rev.03)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจได้ว่าผลิตภัณฑ์ที่ผ่านกระบวนการผลิตมีคุณภาพตรงตามความต้องการของลูกค้าก่อนทำการส่งมอบ
- **ขอบเขต:** ครอบคลุมการสุ่มตรวจและการตรวจสอบสินค้าขั้นสุดท้ายก่อนส่งมอบ

## 2. คำจำกัดความ (Definitions)
- **QC PASSED Final:** สินค้าสำเร็จรูปตรวจสอบแล้วผ่าน
- **Tag HOLD:** สินค้าไม่ผ่าน รอการตัดสินใจ
- **Tag REJECT:** สินค้าไม่ผ่าน ต้องส่งคืนหรือนำไปจัดการต่อ
- **ใบ NCR:** ใบรายงานผลิตภัณฑ์ที่ไม่เป็นไปตามข้อกำหนด

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การเตรียมการส่งมอบ:** ฝ่ายผลิตทำการตรวจสินค้า 100% และแจ้งให้ QC เข้าตรวจสอบก่อนส่งเข้าคลังสินค้า
2. **การสุ่มตรวจโดย QC:**
   - ใช้มาตรฐานการสุ่ม JIS-Z-9015 สุ่มตรวจแบบปกติ Level II ที่ **AQL = 0.65** (หรือตามลูกค้ากำหนด)
   - QC จะทำการสุ่มตรวจและบันทึกผลลงในฟอร์ม Outgoing Inspection (FM-QCS-004) จำนวน **5 ตัวอย่าง**
3. **การจัดการกรณีพบปัญหา:**
   - **กรณีต้องซ่อม (REWORK):** ติดป้าย Tag Rework ส่งเข้าพื้นที่ Repair เมื่อซ่อมเสร็จต้องเรียก QC มาทวนสอบใหม่ หากซ่อมไม่ได้ QC จะอนุมัติเป็นชิ้นงานเสีย (Scrap)
   - **กรณียอมรับได้ (กรณีพิเศษ):** ใช้แบบฟอร์มขอใช้พิเศษ (FM-QCS-006) เพื่ออนุมัติ

## 4. การออกเอกสาร IPP (Initial Production Part)
- ในกรณีที่ลูกค้าสั่งงานที่มีการเปลี่ยนแปลงชิ้นส่วน (Part) หรือกระบวนการผลิต (ตามที่ลูกค้าร้องขอ) จะต้องแนบ **IPP Tag** ไปยังลูกค้าทุกครั้งเพื่อแจ้งจุดที่มีการเปลี่ยนแปลง โดย QC จะต้องเป็นผู้ตรวจสอบ IPP Tag นี้ด้วย

## 5. การรายงานและเก็บบันทึก
- **รายวัน:** รวบรวมข้อมูลลงใน Final inspection daily report (FM-QCS-007)
- **รายเดือน/รายไตรมาส:** จัดทำรายงานวิเคราะห์ปัญหาด้วย 7 QC Tools ส่งให้ฝ่ายบริหารทบทวน
- **ระยะเวลาการจัดเก็บเอกสาร:** บันทึกคุณภาพและแผนคุณภาพสินค้าต่างๆ เก็บรักษาไว้เป็นเวลา **5 ปี**
