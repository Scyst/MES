# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** นโยบายและขั้นตอนการจัดซื้อ (Purchasing Policy Procedure)
**รหัสเอกสาร:** SP-PUD-006 (Rev.01)
**วันที่ประกาศใช้:** 01/09/2018

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นมาตรฐานและแนวทางในการดำเนินงานจัดซื้อ จัดจ้าง และคัดเลือกผู้ขาย (Supplier) ทั้งในประเทศและต่างประเทศ ให้เป็นไปในทิศทางเดียวกันและมีประสิทธิภาพสูงสุด
- **ขอบเขต:** ครอบคลุมตั้งแต่การเปรียบเทียบราคา การออกใบสั่งซื้อ (PO) การรับของ การตรวจสอบคุณภาพ และการจ่ายเงิน

## 2. นโยบายและขั้นตอนการจัดซื้อหลัก (Purchasing Policy)
การจัดซื้อแบ่งออกเป็น 2 กรณีหลัก ได้แก่:
1. **การจัดซื้อด้วยเงินสด (Cash Purchase):** สำหรับกรณีเร่งด่วนหรือสินค้าจุกจิกบางประเภทที่ไม่ต้องออก PO
2. **การจัดซื้อผ่านใบสั่งซื้อ (PO Purchase):** เป็นหลักฐานสำคัญที่ใช้ผูกพันทางกฎหมายกับผู้ขาย โดยต้องระบุรายละเอียดให้ชัดเจน (ชนิดสินค้า, ปริมาณ, ราคาต่อหน่วย, วันที่ต้องการส่งมอบ)

### 2.1 นโยบายการเปรียบเทียบราคา
- ฝ่ายจัดซื้อมีหน้าที่ต้อง **เปรียบเทียบราคาจากผู้ขายอย่างน้อย 2 รายขึ้นไป** สำหรับการซื้อสินค้าใหม่ เพื่อหาราคาและเงื่อนไขที่ดีที่สุด
- *ข้อยกเว้น:* หากเป็นสินค้าที่มีการผูกขาด (Single Source) หรือลูกค้าระบุผู้ขายมาให้เฉพาะเจาะจง จะต้องบันทึกเหตุผลไว้เป็นหลักฐาน

### 2.2 ขั้นตอนการทำงานผ่านระบบ (System Flow)
1. **ขอซื้อ (PR):** หน่วยงานผู้ใช้งานสร้างใบขอซื้อ (PR) ในระบบ
2. **ดำเนินการสั่งซื้อ:** จัดซื้อดึงข้อมูล PR มาเปรียบเทียบราคา และสร้างใบสั่งซื้อ (PO) ในระบบ MRP
3. **อนุมัติ (Approve):** PO ต้องได้รับการอนุมัติจาก Section Manager, AMD, หรือ MD ตามอำนาจอนุมัติวงเงิน
4. **สั่งซื้อและรับของ:** ส่ง PO ให้ Vendor คอนเฟิร์ม -> เมื่อของมาส่ง สโตร์ (Store) ตรวจรับเทียบกับ PO
5. **ตรวจสอบคุณภาพ (IQC):** พนักงาน IQC ตรวจสอบคุณภาพวัตถุดิบ 
   - หาก **ผ่าน:** ส่งข้อมูลให้บัญชีเพื่อทำจ่ายเงิน (Payment)
   - หาก **ไม่ผ่าน:** แจ้งจัดซื้อเพื่อทำเรื่องเคลม/เปลี่ยนคืนกับ Vendor

## 3. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารใบสั่งซื้อ (PO), ใบขอซื้อ (PR) เก็บรักษาไว้ตามที่ระบุในมาตรฐานการควบคุมเอกสารของบริษัท
