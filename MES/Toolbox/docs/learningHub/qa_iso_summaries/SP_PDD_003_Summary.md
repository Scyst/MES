# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การเปลี่ยนแปลงกระบวนการ (Process Change)
**รหัสเอกสาร:** SP-PDD-003 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าการเปลี่ยนแปลงใดๆ ในกระบวนการผลิต ได้รับการทบทวนว่าจะไม่มีผลกระทบต่อคุณภาพสินค้า และ **ต้องได้รับการอนุมัติจากลูกค้า** ก่อนเริ่มการผลิตจริง
- **ขอบเขต:** ครอบคลุมกระบวนการผลิตทั้งหมดของบริษัท

## 2. คำจำกัดความของการเปลี่ยนแปลง (Process Change)
การเปลี่ยนแปลงที่ต้องถูกควบคุม ได้แก่:
1. การเพิ่ม/ลด/สลับขั้นตอนการผลิต ที่ต้องแก้ไขแผนควบคุมคุณภาพ (Control Plan)
2. การเปลี่ยนประเภทหรือแหล่งที่มา (Supplier) ของวัตถุดิบ ส่วนประกอบ หรือสารเคมี
3. การเปลี่ยนแปลงทางวิศวกรรม เช่น ขนาด (Dimension)
4. การเปลี่ยนแปลงสถานที่ผลิต
5. การเปลี่ยนประเภทเครื่องจักร หรือเครื่องมือเฉพาะทาง

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การแจ้งการเปลี่ยนแปลง:** เมื่อมีความต้องการเปลี่ยนแปลง (จากลูกค้าหรือภายใน) ต้องแจ้งผู้จัดการฝ่ายผลิตและ QA รับทราบทันที
2. **การทดสอบและตรวจสอบ:** ดำเนินการผลิตชิ้นงานตัวอย่างจากกระบวนการที่เปลี่ยนใหม่ และให้ QA ตรวจสอบคุณภาพ
3. **การขออนุมัติจากลูกค้า (4M Change Request):**
   - หากผลตรวจสอบผ่าน QA จะทำการแจ้งลูกค้าเพื่อขออนุมัติ โดยใช้เอกสาร **ยื่นขอ 4M Change**
   - *เอกสารประกอบการยื่นขอ เช่น:* เหตุผลที่เปลี่ยน, รายการ Part, การเปรียบเทียบ Flow การผลิตเก่า-ใหม่, ข้อมูลการทดสอบเทียบเก่า-ใหม่, และเอกสารคุณภาพที่อัปเดตแล้ว (WI, Control Plan)
4. **การอนุมัติและการนำไปใช้:**
   - **ห้ามผลิตจริง** จนกว่าจะได้รับอนุมัติจากลูกค้า
   - เมื่อลูกค้าอนุมัติ ให้นำเนื้อหาที่เปลี่ยนแปลงไปอัปเดตลงในเอกสารมาตรฐานทั้งหมด (WI, PQCT) และทำการอบรม (Training) พนักงาน
   - ให้ผู้รับผิดชอบบันทึกการจัดการ 4M ในวันที่มีการเปลี่ยนแปลงลงในเอกสาร FM-QCS-025

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารกระบวนการผลิต, Quality Control Plan และ IPP/PPAP เก็บรักษาไว้เป็นเวลา **5 ปี**
