# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** กระบวนการรับและจ่ายสินค้าสำเร็จรูป (Finish Goods Receive and Issue Procedure)
**รหัสเอกสาร:** SP-PUD-009 (Rev.01)
**วันที่ประกาศใช้:** 15/12/2017
*(หมายเหตุ: เอกสารฉบับนี้อยู่ในหมวด PU แต่เนื้อหาเกี่ยวข้องกับการทำงานของคลังสินค้า (Warehouse) เป็นหลัก)*

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นมาตรฐานในการปฏิบัติงานรับ-จ่ายสินค้าสำเร็จรูป (Finished Goods - FG) ให้มีความถูกต้องและเป็นระบบ
- **ขอบเขต:** ครอบคลุมการรับและการจ่ายสินค้าสำเร็จรูปจากคลังสินค้า (Warehouse) 

## 2. ความรับผิดชอบหลัก
- **หัวหน้าแผนกคลังสินค้า:** มีหน้าที่ควบคุมการรับ จ่าย และจัดเก็บสินค้าสำเร็จรูป รวมถึงควบคุมการปฏิบัติงานของเจ้าหน้าที่คลังสินค้า
- **เจ้าหน้าที่คลังสินค้า / เจ้าหน้าที่เอกสาร:** มีหน้าที่คัดแยกเอกสาร, จัดเก็บสินค้า, และจ่ายสินค้าสำเร็จรูปให้เป็นไปตามข้อกำหนด

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การรับสินค้าเข้าคลัง:**
   - ฝ่ายผลิต (Production) ทำการคีย์ยอด Output FG เข้าระบบ
   - เจ้าหน้าที่คลังสินค้ารับสินค้าจากฝ่ายผลิต **หลังจากที่ผ่านการตรวจสอบคุณภาพจาก QA แล้วเท่านั้น**
   - เจ้าหน้าที่คลังสินค้าตรวจสอบความเรียบร้อยของบรรจุภัณฑ์ก่อนการเคลื่อนย้าย
   - นำสินค้าไปจัดเก็บในพื้นที่ที่กำหนด (Lay Out) อย่างชัดเจน
2. **การจ่ายสินค้าและจัดส่ง:**
   - เจ้าหน้าที่คลังสินค้ารับใบแจ้งความต้องการ (Information Request Sheet) จากลูกค้าก่อนส่งสินค้า
   - เจ้าหน้าที่ทำการเปิดใบสั่งขาย (Sales Order) ในระบบตามความต้องการของลูกค้า
   - จัดเตรียมสินค้า นำมารอที่จุดโหลด (Staging) และทำการ **Scan Barcode** ให้ครบจำนวนก่อนนำขึ้นรถ
   - ออกใบส่งของระหว่างหน่วยงาน (Intersection Delivery Order) และให้ผู้มีอำนาจเซ็นอนุมัติการจัดส่ง
   - จัดส่งสินค้าพร้อมใบส่งของให้ลูกค้าเซ็นรับทราบ และนำสำเนาใบส่งของกลับคืนมาเพื่อเป็นหลักฐาน

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ใบส่งของระหว่างหน่วยงาน (Intersection Delivery Order) ถูกจัดเก็บไว้ที่แผนกเป็นเวลา **1 ปี**
