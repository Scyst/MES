# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** ระเบียบการแจ้งซ่อมและการซ่อมกรณีฉุกเฉิน (Repair Request and Emergency Repairs)
**รหัสเอกสาร:** SP-MTD-002 (Rev.01)
**วันที่ประกาศใช้:** 26/07/2016

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดวิธีการซ่อมบำรุงเครื่องจักรและอุปกรณ์ที่มีอยู่ภายในโรงงานทั้งหมดเมื่อเกิดการชำรุด ให้สามารถกลับมาใช้งานได้อย่างมีประสิทธิภาพและปลอดภัย
- **ขอบเขต:** ครอบคลุมกิจกรรมการซ่อมบำรุงเมื่อเกิดเหตุขัดข้อง (Breakdown) ตั้งแต่การเขียนใบแจ้งซ่อม, วิเคราะห์ปัญหา, เบิกอะไหล่, ซ่อมแซม, ไปจนถึงการตรวจรับงาน

## 2. ความรับผิดชอบหลัก
- **ผู้ร้องขอ (เช่น ฝ่ายผลิต, QC, สโตร์):** เขียนใบแจ้งซ่อมอย่างชัดเจน และเป็นผู้ตรวจสอบ/เซ็นรับรองผลหลังจากการซ่อมเสร็จสิ้น
- **ฝ่ายวิศวกรรม/ซ่อมบำรุง (Maintenance):** รับใบแจ้งซ่อม, วิเคราะห์ปัญหาเบื้องต้น, มอบหมายงาน, ดำเนินการซ่อม, และบันทึกประวัติเครื่องจักร

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)

### 3.1 การแจ้งซ่อมปกติ (Normal Repair)
1. **แจ้งซ่อม:** ผู้พบปัญหาเขียนใบแจ้งซ่อม (Repair Request) ส่งให้แผนกซ่อมบำรุง
2. **รับเรื่องและวิเคราะห์:** แผนกซ่อมบำรุงลงรับเอกสารและวิเคราะห์ปัญหา
3. **จัดการอะไหล่:** 
   - หากต้องซื้อใหม่: ทำใบขอจัดซื้อ (PR) ส่งให้ฝ่ายจัดซื้อ
   - หากมีในสต๊อก: ทำการเบิกจ่ายอะไหล่
4. **ดำเนินการซ่อม:** ช่างซ่อมบำรุงทำการซ่อมแซมตามอาการ
5. **ส่งมอบงาน:** ผู้ร้องขอตรวจสอบความเรียบร้อยและเซ็นรับรองผลการซ่อม
6. **บันทึกประวัติ:** ช่างซ่อมบำรุงบันทึกประวัติการซ่อมลงในแฟ้มประวัติเครื่องจักร (Machine Record)

### 3.2 การซ่อมกรณีฉุกเฉิน (Emergency Repair / Breakdown)
1. **การแจ้งเหตุ:** หากเครื่องจักรหยุดชะงักระหว่างผลิต ให้ผู้ควบคุมเครื่องหยุดการผลิตและติดป้าย **"เครื่องชำรุด"** ทันที พร้อมแจ้งหัวหน้างานและช่างซ่อมบำรุงด้วยวาจาเพื่อความรวดเร็ว
2. **ประเมินผลกระทบ:** ประสานงานกับฝ่ายที่เกี่ยวข้องเพื่อประเมินเรื่องความปลอดภัยและผลกระทบต่อแผนการส่งมอบสินค้าให้ลูกค้า
3. **ซ่อมแซม:** ช่างเข้าซ่อมแซมทันที (หากต้องใช้ช่างภายนอก/Supplier ให้ติดต่อด่วน และต้องมีการประเมินผลการทำงานของ Supplier ด้วย)
4. **ติดตามเอกสาร:** หลังซ่อมเสร็จและเดินเครื่องได้ปกติ ผู้ร้องขอต้องเขียนใบแจ้งซ่อมย้อนหลังให้ครบถ้วน เพื่อให้ช่างซ่อมบำรุงบันทึกประวัติและปลดป้าย "เครื่องชำรุด" ออก

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบแจ้งซ่อม (Repair Request) และเอกสารบันทึกประวัติเครื่องจักร (Machine Record)
- **ระยะเวลาการจัดเก็บ:** ใบแจ้งซ่อมเก็บรักษาไว้ **5 ปี**, เอกสารประวัติเครื่องจักรเก็บไว้ **ตลอดไป**
