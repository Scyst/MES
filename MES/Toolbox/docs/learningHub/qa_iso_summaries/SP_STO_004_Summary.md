# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมการเคลื่อนย้าย จัดเก็บ และบรรจุภัณฑ์ (Handling Storage Packing and Preservation Control)
**รหัสเอกสาร:** SP-STO-004 (Rev.03)
**วันที่ประกาศใช้:** 1/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดแนวทางการเคลื่อนย้ายและจัดเก็บวัตถุดิบและสินค้าสำเร็จรูป ให้เกิดความปลอดภัย เป็นระเบียบเรียบร้อย และป้องกันความเสียหายที่อาจเกิดขึ้น
- **ขอบเขต:** ครอบคลุมตั้งแต่การรับวัตถุดิบจากผู้ขาย (Vendor) เข้าสู่สถานที่จัดเก็บ ไปจนถึงการเคลื่อนย้ายสินค้าสำเร็จรูปส่งให้ลูกค้า

## 2. อุปกรณ์ที่ใช้ในการเคลื่อนย้าย
- **Fork Lift (รถโฟล์คลิฟต์):** ใช้สำหรับเคลื่อนย้ายสิ่งของที่มีน้ำหนักมาก และระยะทางไกล ผู้ใช้งานจะต้องได้รับการฝึกอบรมและได้รับอนุญาตเท่านั้น
- **Hand Lift (รถลากพาเลท):** ใช้สำหรับเคลื่อนย้ายสิ่งของที่มีน้ำหนักไม่มาก และระยะทางใกล้

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)

### 3.1 การรับวัตถุดิบ (Material Receive Flow)
1. **Vendor** นำส่งวัตถุดิบพร้อมใบสั่งซื้อและ Invoice
2. **เจ้าหน้าที่สโตร์** ตรวจสอบสภาพความสมบูรณ์ของบรรจุภัณฑ์ หากพบว่าชำรุด ให้แจ้ง QC ตรวจสอบคุณภาพทันที และแจ้งกลับ Vendor
3. ตรวจสอบจำนวนและเลขที่ใบสั่งซื้อให้ตรงกัน หากไม่ตรงให้แจ้งแผนกจัดซื้อ
4. เจ้าหน้าที่สโตร์เซ็นรับวัตถุดิบ นำวัตถุดิบไปจัดเก็บตามพื้นที่ที่กำหนด (Location Store)
5. ทำการคัดแยกเอกสารและทำรายการรับเข้า (GR) ในระบบ **SAP** 
6. นำส่งเอกสารให้แผนกบัญชีเพื่อเตรียมทำจ่ายต่อไป

### 3.2 การจ่ายวัตถุดิบ (Material Supply Flow)
1. **ฝ่ายผลิต** ทำการเปิดใบเบิก (Reservation) ในระบบ
2. **เจ้าหน้าที่สโตร์** จัดเตรียมวัตถุดิบตามใบเบิก และตรวจสอบว่ามีของเพียงพอหรือไม่
   - *หากของไม่พอ:* แจ้งฝ่ายจัดซื้อเพื่อติดตาม Vendor (ใช้เอกสาร Shortage from Vendor)
3. **จ่ายวัตถุดิบ (FIFO):** เจ้าหน้าที่สโตร์จ่ายวัตถุดิบให้ฝ่ายผลิตตามหลัก เข้าก่อน-ออกก่อน (FIFO)
4. ทำการโอนย้ายยอดในระบบ **SAP** โดยอ้างอิงจากเลขที่ Reservation
5. ฝ่ายผลิตตรวจสอบจำนวนที่ได้รับ และทำรายการเบิกใช้ (Good Issue) ตามใบสั่งผลิต
6. สโตร์ต้องคอยตรวจนับวัตถุดิบคงเหลือเทียบกับระบบ SAP อย่างสม่ำเสมอ

## 4. การเก็บบันทึก
- การทำงานทุกขั้นตอนจะถูกบันทึกและอ้างอิงผ่านระบบ **SAP** และเอกสาร Invoice/Delivery Note
