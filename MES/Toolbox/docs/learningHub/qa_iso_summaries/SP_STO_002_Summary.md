# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมวัตถุดิบในสินค้าคงคลัง (Stock Control)
**รหัสเอกสาร:** SP-STO-002 (Rev.02)
**วันที่ประกาศใช้:** 1/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อควบคุมวัตถุดิบในคลังสินค้าให้ตรงตามปริมาณที่จะผลิต มีความถูกต้องแม่นยำ และควบคุมการรับ-จ่ายตามเวลาที่กำหนด
- **ขอบเขต:** เริ่มตั้งแต่การรับวัตถุดิบเข้าคลัง การควบคุม และการบันทึกข้อมูลเข้าสู่ระบบ

## 2. ความรับผิดชอบหลัก
- **พนักงานคลังสินค้า (Store):** รับวัตถุดิบ, ป้อนข้อมูลเข้าระบบ, จ่ายวัตถุดิบให้ฝ่ายผลิต และรับผิดชอบให้ยอดสินค้าจริงตรงกับระบบ
- **พนักงาน QC:** ตรวจสอบคุณภาพวัตถุดิบรับเข้า (Incoming Inspection) ก่อนรับเข้าคลัง
- **พนักงานจัดซื้อ (Purchasing):** ออกใบสั่งซื้อ (PO) ให้ตรงกับความต้องการ

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การรับและตรวจสอบ:**
   - เมื่อวัตถุดิบมาส่ง แผนกสโตร์จะตรวจสอบเอกสารเบื้องต้น (Part No., จำนวน, Invoice) ว่าตรงกับ PO หรือไม่
   - แผนก QC เข้าตรวจสอบคุณภาพตามมาตรฐาน หากผ่าน (OK) สโตร์จะรับเข้าคลัง แต่หากไม่ผ่าน (NG) QC จะออกใบ NCR ตีกลับไปยัง Supplier
2. **การบันทึกข้อมูล:** 
   - เมื่อรับวัตถุดิบเรียบร้อย พนักงานสโตร์จะบันทึกข้อมูลเข้าระบบ (เช่น SAP, EXPRESS) และปรับปรุงยอดใน **Stock Card** ให้เป็นปัจจุบัน
3. **การควบคุมการจ่ายแบบ FIFO (First In - First Out):**
   - แผนกสโตร์จะต้องควบคุมการจ่ายวัตถุดิบโดยใช้หลักการ **เข้าก่อน-ออกก่อน**
   - มีการใช้ **สติกเกอร์รหัสสี (FIFO Color Code)** เพื่อแยกเดือนที่รับเข้าอย่างชัดเจน (เช่น มกราคม=สีน้ำเงิน, กุมภาพันธ์=สีแดง) พนักงานจะต้องสังเกตสีและเลือกจ่ายของที่รับเข้ามาก่อนเสมอ
4. **การตรวจนับสต๊อก (Stock Count):**
   - สโตร์, ฝ่ายผลิต และบัญชี จะต้องร่วมกันตรวจนับสต๊อกเป็น **ประจำทุกเดือน**
   - *กรณีฝากวัตถุดิบไว้ที่ Supplier/ผู้รับจ้างช่วง:* Supplier ต้องส่งรายงานการนับสต๊อกมาทุกวันที่ 30 ของเดือน และฝ่ายควบคุมการผลิตจะสุ่มไปตรวจนับหน้างานจริง (2 เดือน/ครั้ง)

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารควบคุม Stock Card, บันทึก FIFO, และ Incoming Inspection Check Sheet ถูกจัดเก็บไว้เป็นเวลา **5 ปี**
