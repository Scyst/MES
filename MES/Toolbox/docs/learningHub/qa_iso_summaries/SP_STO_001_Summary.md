# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** กระบวนการจัดการสินค้าสำเร็จรูป (Finish Goods Management System - FGMS)
**รหัสเอกสาร:** SP-STO-001 (Rev.02)
**วันที่ประกาศใช้:** 18/08/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการควบคุมการจัดการสินค้าสำเร็จรูป (Finished Goods - FG) ตั้งแต่การรับจากฝ่ายผลิต, การจัดเก็บ, การเคลื่อนย้าย, และการจัดส่งให้ลูกค้าอย่างถูกต้องตามมาตรฐาน
- **ขอบเขต:** ครอบคลุมการจัดการสินค้าสำเร็จรูปที่เกิดจากการผลิตงาน OEM (เช่น แอร์, ทีวี, ตู้เย็น)

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการแผนกสโตร์และคลังสินค้า:** จัดทำระบบมาตรฐาน บริหารจัดการ และควบคุมภาพรวม
- **หัวหน้าแผนกคลังสินค้า:** ควบคุมการทำงานของพนักงานและ **ผู้รับจ้างช่วง (Subcontractor)** 
- **ผู้รับจ้างช่วงและพนักงาน:** ปฏิบัติงานให้เป็นไปตามขั้นตอนที่กำหนดในระบบ FGMS

## 3. ขั้นตอนการทำงาน (Workflow)

### 3.1 การรับสินค้าสำเร็จรูปจากฝ่ายผลิต (Receiving)
1. **การติด Tag:** ฝ่ายผลิตทำการพิมพ์และติดป้าย **Pallet ID Tag** ที่สร้างจากระบบ FGMS
2. **การตรวจสอบโดย QC:** 
   - หาก **ไม่ผ่าน (NG):** สแกน Pallet ID และ Serial Number เพื่อตีกลับให้ฝ่ายผลิตนำไป Rework
   - หาก **ผ่าน (OK):** สแกนยืนยันการปล่อยผ่านระบบ FGMS และติดป้ายชี้บ่งสถานะ
3. **การนำเข้าจัดเก็บ (Put-away):** พนักงานคลังสินค้าสแกนป้ายเพื่อรับงาน และสแกนตำแหน่ง Location ที่จะจัดเก็บ เพื่อนำข้อมูลเข้าระบบ FGMS

### 3.2 การเตรียมและบรรจุตู้สินค้าสำหรับขาย (Shipping / Container Loading)
1. **การวางแผน:** Admin แผนกคลังสินค้ารับข้อมูลจากฝ่ายขาย เพื่อกำหนดวัน/เวลาเรียกรถบรรทุกตู้คอนเทนเนอร์ และบันทึกแผนลงในระบบ FGMS
2. **การหยิบสินค้า (Picking):** รถโฟล์คลิฟท์ทำการสแกน Pallet Tag ID เพื่อหยิบสินค้าตามแผนที่กำหนด
3. **การสแกนจ่ายออก (Scanning Out):** พนักงานสแกน **Serial Number** ของตัวสินค้าทุกชิ้นให้ตรงตาม Model, Batch และจำนวน
4. **การตรวจสอบระหว่างโหลดตู้:** 
   - QC ตรวจสอบสภาพสินค้าระหว่างโหลด หากพบสินค้าชำรุด จะต้องนำออกจากระบบ (สแกนออก) แล้วให้พนักงานเบิกสินค้าดีมาทดแทน
5. **การปิดตู้ (Closing):** เมื่อโหลดครบถ้วน พนักงานตรวจสอบความถูกต้องในระบบ FGMS แล้วทำการ Post ยืนยัน พร้อมทั้งล็อกซีลตู้คอนเทนเนอร์และถ่ายรูปไว้เป็นหลักฐาน

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ข้อมูลการรับสินค้าสำเร็จรูป และข้อมูลการขายสินค้าบรรจุตู้คอนเทนเนอร์ ถูกจัดเก็บไว้ใน **FGMS Database** เป็นเวลา **5 ปี**
