# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การสอบกลับผลิตภัณฑ์ (Product Traceability)
**รหัสเอกสาร:** SP-PDD-015 (Rev.02)
**วันที่ประกาศใช้:** 3/11/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการสอบกลับ (Trace) แหล่งที่มาของผลิตภัณฑ์ที่ผ่านการผลิตไปแล้ว หากพบปัญหาหรือมีการร้องเรียน
- **ขอบเขต:** ครอบคลุมการทำงานภายในหน่วยงานฝ่ายผลิต (Production)

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการฝ่ายผลิต:** รับผิดชอบรับเรื่องและแจกจ่ายงานให้ผู้ที่เกี่ยวข้องทำการสอบกลับ
- **เจ้าหน้าที่ฝ่ายวางแผน (Planning):** ทำหน้าที่สืบค้นหาข้อมูลในระบบ FGMS (Finished Goods Management System) และระบบ SAP

## 3. ขั้นตอนการสอบกลับ (Workflow)
เมื่อลูกค้าร้องเรียนหรือแจ้งปัญหาโดยส่งหมายเลข **Serial Number** ของผลิตภัณฑ์มาให้ จะมีขั้นตอนการสืบค้นดังนี้:
1. **ค้นหาในระบบ FGMS:**
   - นำ Serial Number ไปค้นหาในระบบ FGMS (ระบุวันที่และโมเดลที่ผลิต)
   - ระบบจะแสดงข้อมูล **วันที่ผลิต (Production Date)** และ **หมายเลขล็อต/แบทช์ (Batch No.)** ของสินค้านั้น
2. **ค้นหาในระบบ SAP:**
   - นำ Batch No. และวันที่ผลิตที่ได้ ไปค้นหาหมายเลขใบสั่งผลิต/สั่งซื้อ (PO) ในระบบ SAP
   - ข้อมูล Component ในระบบ SAP ที่ตรงกับ Header Text ใน PO จะแสดงรายการวัตถุดิบและชิ้นส่วนทั้งหมดที่ถูกเบิกมาใช้ผลิตในล็อตนั้นๆ 
   - *ผลลัพธ์:* ทำให้ทราบว่าสินค้านี้ใช้วัตถุดิบจาก Supplier รายใด และผลิตในช่วงเวลาไหน เพื่อตีกรอบปัญหาได้อย่างแม่นยำ

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ข้อมูลที่เกี่ยวข้องในระบบ (System Data) เก็บรักษาไว้เป็นเวลา **5 ปี**
