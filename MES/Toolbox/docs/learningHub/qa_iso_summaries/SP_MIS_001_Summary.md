# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การรักษาความปลอดภัยข้อมูลแผนก MIS (MIS Data Security)
**รหัสเอกสาร:** SP-MIS-001 (Rev.04)
**วันที่ประกาศใช้:** 08/09/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดนโยบายความมั่นคงปลอดภัยสารสนเทศ การควบคุมการเข้าถึงระบบ การสำรองข้อมูล (Backup/Restore) และการรักษาความปลอดภัยทางกายภาพของห้อง Server
- **ขอบเขต:** ครอบคลุมการใช้งานระบบสารสนเทศทั้งหมดของกลุ่มบริษัท SNC Former

## 2. ความรับผิดชอบหลัก
- **System Administrator:** ดูแลเครือข่าย สร้าง/ลบสิทธิ์ผู้ใช้ ตรวจสอบ Log และจัดการระบบสำรองข้อมูล (Backup)
- **Programmer:** พัฒนาและปรับปรุงระบบ โดยต้องทดสอบในระบบจำลอง (Test Environment) ก่อนนำขึ้นระบบจริงเสมอ
- **HR / ต้นสังกัด:** ต้องแจ้ง MIS ให้ทราบเมื่อมีพนักงานเข้าใหม่ โอนย้าย หรือลาออก เพื่อเพิ่มหรือยกเลิกสิทธิ์การเข้าถึงระบบอย่างทันท่วงที
- **ผู้ใช้งาน (User):** ต้องเก็บรักษารหัสผ่านเป็นความลับ และปฏิบัติตามนโยบาย IT อย่างเคร่งครัด

## 3. นโยบายการควบคุมการเข้าถึง (Access Control & Password)
- รหัสผ่านต้องมีความยาว **8 ตัวอักษรขึ้นไป** ประกอบด้วยตัวอักษร ตัวเลข หรือสัญลักษณ์พิเศษ และไม่ใช้คำที่เดาง่าย (เช่น 1234, 1111)
- บังคับเปลี่ยนรหัสผ่านทุกๆ **90 วัน**
- ระบบจะล็อก (Lock) ทันทีหากใส่รหัสผ่านผิดเกิน **3 ครั้ง**
- การนำคอมพิวเตอร์ส่วนตัวมาใช้งานในบริษัท หรือการรีโมทจากภายนอก (Remote Access) ต้องได้รับการอนุมัติเป็นลายลักษณ์อักษร

## 4. ความปลอดภัยทางกายภาพ (Physical Security)
- **ห้อง Server:** จำกัดสิทธิ์การเข้าออกเฉพาะผู้ที่ได้รับอนุญาต และต้องลงบันทึกการเข้า-ออกทุกครั้ง
- **อุณหภูมิห้อง Server:** ต้องควบคุมให้อยู่ระหว่าง **23-26 องศาเซลเซียส**
- **ระบบไฟสำรอง (UPS):** ต้องสามารถสำรองไฟให้ Server ได้มากกว่า 30 นาที และต้องทดสอบถอดปลั๊กเพื่อเช็คสภาพทุกๆ 6 เดือน

## 5. การสำรองข้อมูลและการป้องกันไวรัส (Backup & Antivirus)
- **การสำรองข้อมูล (Backup):** มีตารางสำรองข้อมูลแบบ Daily (จันทร์-ศุกร์) และ Weekly (เสาร์) แบ่งเป็นแบบ Full และ Incremental
- **การกู้คืน (Restore):** ต้องมีการทดสอบซ้อมกู้คืนข้อมูล เพื่อให้มั่นใจว่าไฟล์ Backup สามารถใช้งานได้จริง
- **การป้องกันไวรัส:** คอมพิวเตอร์และ Server ทุกเครื่องต้องติดตั้ง Antivirus และอัปเดต Patch อย่างสม่ำเสมอ

## 6. บทลงโทษเมื่อฝ่าฝืนระเบียบ
หากพบว่ามีการใช้งานระบบที่ผิดระเบียบหรือไม่เหมาะสม (เช่น ใช้อินเทอร์เน็ตในทางที่ไม่ควร) ผู้ดูแลระบบสามารถเพิกถอนสิทธิ์ได้ทันที และมีบทลงโทษดังนี้:
- ครั้งที่ 1: ตักเตือนด้วยวาจาและบันทึกลงทะเบียน
- ครั้งที่ 2: ตักเตือนเป็นลายลักษณ์อักษร
- ครั้งที่ 3: พักงาน 1-6 วัน โดยไม่ได้รับค่าจ้าง
- ครั้งที่ 4: เลิกจ้าง
