# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** กระบวนการสั่งซื้อสินค้าทั่วไป (General Purchase)
**รหัสเอกสาร:** SP-PUD-004 (Rev.00)
**วันที่ประกาศใช้:** 24/01/2017

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการสั่งซื้อสินค้าและบริการทั่วไปภายในประเทศ ให้ได้รับสินค้าตรงตามความต้องการของผู้ขอซื้อ และทันต่อเวลาใช้งานโดยไม่ส่งผลกระทบต่อการทำงาน
- **ขอบเขต:** ครอบคลุมตั้งแต่การค้นหาสินค้า/บริการ, การออกใบสั่งซื้อ (PO), การจัดส่งให้ผู้ขาย, ไปจนถึงการติดตามการส่งมอบ

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการแผนกจัดซื้อ:** มีหน้าที่พิจารณาและอนุมัติรายชื่อผู้ขาย (Approved Supplier List - ASL)
- **พนักงานแผนกจัดซื้อ:** มีหน้าที่สั่งซื้อสินค้าจากร้านค้าที่อยู่ในรายชื่อ ASL ที่ได้รับการอนุมัติแล้วเท่านั้น

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การขออนุมัติสั่งซื้อ (Purchase Request):** 
   - หน่วยงานที่ต้องการซื้อ จะต้องกรอกใบขอสั่งซื้อ (P/R) หรือ Demand Order (D/O) พร้อมให้ผู้บริหารอนุมัติ โดยมีเงื่อนไขวงเงินอนุมัติดังนี้:
     - **น้อยกว่า 100,000 บาท:** อนุมัติโดย ผู้จัดการแผนก, MD, และท่านรองประธานกรรมการฯ
     - **ตั้งแต่ 100,000 บาทขึ้นไป:** อนุมัติโดย ผู้จัดการแผนก, MD, ท่านรองประธานฯ, และท่านประธานฯ
2. **การออกใบสั่งซื้อ (PO):**
   - พนักงานจัดซื้อรับใบ P/R มาตรวจสอบความถูกต้อง หากข้อมูลไม่ครบถ้วนให้ตีกลับ
   - พนักงานจัดซื้อออกใบสั่งซื้อ (PO) อนุมัติโดย MD 
   - *กรณีแก้ไขข้อมูลใบสั่งซื้อ:* ต้องระบุสาเหตุการแก้ไขในช่อง REV และขออนุมัติใหม่ตามลำดับ
3. **การสั่งซื้อและการควบคุมสารเคมี:**
   - ส่งใบสั่งซื้อให้ผู้ขายและขอรับการเซ็นต์ตอบรับ (Supplier Acknowledgement) กลับมาแนบใบ PO
   - *กรณีเป็นสารเคมีต้องห้าม:* ต้องเรียกขอเอกสาร RoHS, Test Report, และ MSDS จากผู้ขายเสมอ
4. **การติดตามการส่งมอบ:**
   - ติดตามการส่งมอบล่วงหน้า **1-2 วัน** ก่อนถึงกำหนดส่ง (Due Date)
   - หากผู้ขายไม่สามารถส่งมอบได้ตามกำหนด ต้องรีบแจ้งผู้ขอซื้อทันทีเพื่อปรับแผน หรือหาทางจัดส่งให้เร็วที่สุด
5. **การรับสินค้า:**
   - แผนกสโตร์ตรวจสอบสินค้าเทียบกับใบสั่งซื้อและใบกำกับภาษี
   - หากสินค้ามีปัญหาคุณภาพ ให้แจ้ง QC ตรวจสอบ และแจ้งจัดซื้อเพื่อดำเนินการประสานงานเปลี่ยนคืนกับผู้ขาย

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** ใบสั่งซื้อ (Purchase Order), ใบขอสั่งซื้อ (P/R), และใบ Demand Order ถูกจัดเก็บเข้าแฟ้มเรียงตามเลขที่อย่างเป็นระบบ
