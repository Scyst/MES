# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** กระบวนการจัดหา (Procurement Procedure)
**รหัสเอกสาร:** SP-PUD-011 (Rev.00)
**วันที่ประกาศใช้:** 03/09/2018

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นมาตรฐานและแนวทางในการจัดหาวัดถุดิบ ผลิตภัณฑ์ อุปกรณ์ หรือบริการที่ใช้ในการผลิต รวมถึงการคัดเลือกผู้ขาย (Vendor) และผู้รับเหมาช่วง (Subcontractor)
- **ขอบเขต:** ครอบคลุมขั้นตอนการจัดหาและคัดเลือกผู้ขาย/ผู้รับจ้างช่วง ทั้งจากแหล่งภายในประเทศและต่างประเทศ

## 2. คำจำกัดความ (Definitions)
- **Vendor:** ผู้ขาย ผู้ผลิต หรือผู้ส่งมอบชิ้นส่วนวัตถุดิบ
- **Subcontractor:** ผู้รับจ้างช่วงที่รับทำงานซึ่งส่งผลต่อคุณภาพ เช่น งานชุบ งานปั๊ม งานฉีดพลาสติก
- **Raw Material:** วัตถุดิบ ชิ้นส่วนที่ประกอบเป็นผลิตภัณฑ์สำเร็จรูป
- **Consumable / วัสดุสิ้นเปลือง:** วัสดุ อุปกรณ์ หรือเครื่องมือที่ใช้ในการผลิต แต่ไม่ได้ประกอบเป็นส่วนหนึ่งของผลิตภัณฑ์สำเร็จรูป

## 3. ขั้นตอนการดำเนินการจัดหา (Sourcing Flow)
1. **รับความต้องการจัดหา:** ฝ่ายจัดซื้อรับแจ้งความต้องการ เช่น เอกสารแจ้งการเปลี่ยนแปลงทางวิศวกรรม (ECN) หรือแบบแปลน (Drawing)
2. **เสนอราคา (Quotation):** จัดซื้อติดต่อ Vendor เพื่อขอใบเสนอราคา นำมาตรวจสอบความเหมาะสมของราคาและเจรจาต่อรอง
3. **ขอชิ้นงานตัวอย่าง (Sample Request):** 
   - จัดซื้อขอชิ้นงานตัวอย่างจาก Vendor พร้อมเอกสารประกอบ (Sample/Document) 
   - ส่งให้แผนก **QA/QC** ทำการตรวจสอบคุณภาพตัวอย่าง (OTSQ - Off Tool Sample Quality)
4. **การอนุมัติชิ้นงานตัวอย่าง:**
   - *กรณีไม่ผ่าน (Fail):* สั่งให้ Vendor ทำการแก้ไขและส่งชิ้นงานตัวอย่างมาใหม่
   - *กรณีผ่าน (Pass):* ทำการเลือก Vendor รายนั้น (Vendor Selection)
5. **การขออนุมัติและบันทึกระบบ:**
   - จัดทำเอกสารสรุป เสนอให้ผู้บริหารระดับ **MD / AMD** อนุมัติราคา
   - เมื่อได้รับการอนุมัติ จะทำการบันทึกราคาสินค้าลงในระบบ (Put Price on System) เพื่อให้สามารถเปิดใบสั่งซื้อ (PO) ในระบบได้ต่อไป

## 4. การเก็บบันทึก
- การจัดเก็บเอกสารให้เป็นไปตามมาตรฐานการควบคุมเอกสารของบริษัท (เช่น ใบสั่งซื้อ, ใบขออนุมัติราคา, ผลตรวจตัวอย่าง)
