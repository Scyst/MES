# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การจัดทำ Limit Sample (Limit Sample Preparation)
**รหัสเอกสาร:** SP-PDD-010 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการจัดทำ ควบคุมดูแล และอัปเดตชิ้นงานตัวอย่างที่เป็นเส้นแบ่งเกณฑ์คุณภาพ (Limit Sample)
- **ขอบเขต:** ครอบคลุมขั้นตอนการจัดทำชิ้นงาน Limit Sample ทั้งหมดภายในบริษัท

## 2. คำจำกัดความ (Definitions)
- **Limit Sample (ตัวอย่างขีดจำกัด):** ชิ้นส่วนตัวอย่างที่แสดงขีดจำกัดของคุณภาพ ที่บ่งบอกว่าเป็นงานดี (OK) หรืองานเสีย (NG) มักใช้ในกรณีที่กำหนดสเปคเป็นตัวเลขทางปริมาณได้ยาก (เช่น รอยขีดข่วน, สี, ความหยาบ)

## 3. เงื่อนไขและขั้นตอนการปฏิบัติงาน
1. **การจัดทำ Limit Sample:**
   - จัดทำขึ้นเมื่อได้รับคำสั่งจากลูกค้า หรือเมื่อผู้ผลิตพิจารณาว่าจำเป็น
   - ต้องทำเครื่องหมาย (เช่น ตีเส้นล้อมรอบ หรือชี้ด้วยลูกศร) เพื่อแสดงตำแหน่งขีดจำกัดให้ชัดเจน และติดป้าย "Limit Sample"
   - ต้องจัดทำให้เสร็จและได้รับการอนุมัติ **ก่อนเข้าสู่ขั้นตอนการผลิตจริง (Mass Production)**
2. **แบบฟอร์มควบคุม (Control Form):**
   - การจัดทำ Limit Sample ต้องมีเอกสารควบคุมระบุรายละเอียด: วันที่จัดทำ, หมายเลขควบคุม, หัวข้อที่ใช้ตรวจ (เช่น รอยขีดข่วน, รูปร่าง), Part No., และ **ระยะเวลาที่มีผลในการใช้งาน (วันหมดอายุ)** โดยพิจารณาจากการเสื่อมสภาพตามกาลเวลา
3. **การตกลงร่วมกับลูกค้า (Agreement):**
   - ผู้ผลิตต้องนำ Limit Sample ไปตกลงร่วมกับลูกค้าให้ได้รับการยอมรับ **ห้ามส่งมอบชิ้นงานที่ประเมินด้วย Limit Sample หากลูกค้ายังไม่เห็นชอบ**
   - ลูกค้าอาจร้องขอให้ทำ Limit Sample แบบเดียวกันเก็บไว้ที่ลูกค้าด้วย
4. **การบำรุงรักษาและการควบคุม:**
   - หากต้องทำ Limit Sample หลายชิ้นที่เหมือนกัน ให้กำหนดหมายเลขกำกับและควบคุมผ่าน "บัญชีรายชื่อ (Master List)"
   - ผู้ผลิตต้องหมั่นตรวจสอบสภาพของ Limit Sample อย่างสม่ำเสมอ ว่ายังอยู่ในสภาพที่ตกลงกันไว้ (ไม่ชำรุด หรือสีซีดจาง)
   - หากมีการเปลี่ยนแปลงแก้ไขข้อตกลง ต้องหารือกับลูกค้าใหม่ทุกครั้ง

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** แบบฟอร์มและบัญชีควบคุม Limit Sample จะถูกเก็บรักษาไว้ **จนกว่าจะมีการออกเอกสารสั่งหยุดการผลิต (End of Life)**
