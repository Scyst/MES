# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การออกแบบกระบวนการ (Process Design)
**รหัสเอกสาร:** SP-PDD-002 (Rev.01)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้เป็นแนวทางในการจัดทำโครงการใหม่ การประเมินความเป็นไปได้ในการลงทุน และการจัดตั้งกระบวนการผลิตต่างๆ ให้มีความถูกต้อง ไม่ผิดพลาด
- **ขอบเขต:** ครอบคลุมตั้งแต่การนำเสนอโครงการ, การประเมินการลงทุน, การออกแบบกระบวนการ, การเสนอซื้อเครื่องจักร, การติดตั้ง, การทดลองผลิต (Trial) และการเตรียมพร้อมก่อนการผลิตจริง (Pre-Production)

## 2. ความรับผิดชอบหลัก
- **ผู้จัดการฝ่ายผลิต:** นำเสนอและขออนุมัติโครงการ, ควบคุมโครงการ, รายงานผล และปิดโครงการ
- **หัวหน้าฝ่ายวิศวกรรม (Engineering Manager):** จัดทำเอกสารที่เกี่ยวข้อง (เช่น Flow, FMEA, Control Plan), ประสานงานติดตั้งเครื่องจักร, ทดลองผลิต (Trial) และรับรองกระบวนการ

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การเริ่มต้นโครงการ:** ฝ่ายบริหารหรือฝ่ายขายสั่งการผลิตสินค้าใหม่ ฝ่ายออกแบบจะจัดทำ Drawing และ Part List
2. **การออกแบบกระบวนการ (Process Design):** ฝ่ายวิศวกรรมจัดทำ Quality Process Flow, Process Layout, และ Production Process Plan
3. **การประเมินทรัพยากร:** ฝ่ายวิศวกรรมประเมิน Cycle Time, Process Capacity, และ Manpower
4. **การลงทุนเครื่องจักร:** จัดทำ Machine List, ประเมิน Investment Cost และแจ้งฝ่ายจัดซื้อ (PU) เพื่อสั่งซื้อเครื่องจักร
5. **การประเมินความเสี่ยงและคุณภาพ:** 
   - จัดทำ **Process FMEA** และ Quality Control Plan
   - จัดทำเอกสารการบำรุงรักษา Machine Daily Check Sheet
   - สร้างระบบป้องกันความผิดพลาด (Poka Yoke) และจัดทำ Limit Sample
6. **การติดตั้งและทดลอง (Trial & Pre-Production):**
   - ประสานงาน Supplier ติดตั้งเครื่องจักร
   - ทดลองผลิต (Pre-Production) เพื่อรับรองเครื่องจักรและกระบวนการ
   - จัดทำ QA Matrix, แผนซ่อมบำรุงตามวาระ (PM) และรายการอะไหล่สำรอง (Spare Part)
7. **การรับรองชิ้นงาน (Approval):**
   - ดำเนินการจัดทำ IPP/PPAP ส่งให้ลูกค้าอนุมัติ
8. **การปรับปรุงกระบวนการ:** หากมีปัญหาคุณภาพ หรือลูกค้าร้องขอให้ปรับปรุง จะมีการจัดทำ Process Improve Project

## 4. การเก็บบันทึก
- **ระยะเวลาการจัดเก็บเอกสาร:** เอกสารด้านวิศวกรรมต่างๆ (เช่น Investment Plan, FMEA, Control Plan, PPAP) เก็บรักษาไว้เป็นเวลา **5 ปี**
