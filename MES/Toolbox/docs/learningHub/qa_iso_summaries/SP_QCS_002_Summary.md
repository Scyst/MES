# สรุประเบียบปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การตรวจและการทดสอบระหว่างกระบวนการผลิต (Inprocess Inspection)
**รหัสเอกสาร:** SP-QCS-002 (Rev.03)
**วันที่ประกาศใช้:** 15/07/2022

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่ากระบวนการผลิตในทุกๆ ขั้นตอนเป็นไปตามแผนคุณภาพ และได้ผลิตภัณฑ์ที่มีคุณภาพตรงตามที่ลูกค้าต้องการ
- **ขอบเขต:** ครอบคลุมการกำหนดเกณฑ์สุ่มตรวจ และการตรวจสอบคุณภาพระหว่างการผลิต

## 2. คำจำกัดความ (Definitions)
- **HOLD:** ผลิตภัณฑ์ตรวจสอบแล้วไม่ผ่าน รอการพิจารณาตัดสินใจ
- **REJECT:** ผลิตภัณฑ์ตรวจสอบแล้วไม่ผ่าน ไม่ยอมรับ
- **REWORK:** ผลิตภัณฑ์ตรวจสอบแล้วไม่ผ่าน ให้นำไปทำการแก้ไขซ่อมแซม
- **ใบ NCR:** ใบรายงานผลิตภัณฑ์ที่ไม่เป็นไปตามข้อกำหนด

## 3. ขั้นตอนการปฏิบัติงาน (Workflow)
1. **การเริ่มผลิตและตรวจสอบชิ้นงานแรก (First Piece Inspection):** 
   - พนักงานฝ่ายผลิตและพนักงาน QC จะต้องตรวจสอบชิ้นงาน **3 ตัวแรก** ทุกครั้งก่อนเริ่มงาน, ขึ้น Lot ใหม่, หรือหลังจากหยุดเครื่อง 
   - หากไม่ผ่าน ต้องทำการแก้ไขและตรวจสอบใหม่จนกว่าจะผ่านถึงจะผลิตต่อได้
2. **การสุ่มตรวจระหว่างผลิต:**
   - เจ้าหน้าที่ QC จะดำเนินการสุ่มตรวจ **ทุกๆ 2 ชั่วโมง** โดยอ้างอิงมาตรฐาน JIS-Z-9015 (หรือ MIL-STD-105E) สุ่มตรวจแบบปกติ Level II ที่ **AQL = 0.65** (หรือตามลูกค้ากำหนด)
3. **การตรวจติดตามสายการผลิต (Patrol Line):**
   - QC ทำการตรวจสอบ Patrol Line ในสายการผลิต **วันละ 1 ครั้ง**
4. **กรณีงานพบปัญหา (Defect Handling):**
   - หากยอมรับได้แบบกรณีพิเศษ: ให้ฝ่ายผลิตออกใบคำร้อง (FM-QCS-006) และ QC ทำการ Remark (ACCEPT) 
   - หากต้องแก้ไข: QC ทำการติดป้าย **Tag REWORK** ที่ชิ้นงาน เมื่อแก้ไขเสร็จ QC ต้องทวนสอบอีกครั้ง

## 4. การรายงานและเก็บบันทึก
- **รายวัน:** รวบรวมข้อมูลลงใน In process inspection daily report (FM-QCS-007)
- **รายเดือน/ไตรมาส/ครึ่งปี:** หัวหน้า QC จัดทำรายงานวิเคราะห์ปัญหาและสาเหตุด้วยหลักสถิติ (7 QC Tools) ส่งให้ฝ่ายบริหารทบทวน
- **ระยะเวลาการจัดเก็บเอกสาร:** บันทึกคุณภาพต่างๆ (เช่น แผนคุณภาพ, Check Sheet) เก็บรักษาไว้เป็นเวลา **5 ปี**
