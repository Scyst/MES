# สรุปขั้นตอนปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การทบทวนโดยฝ่ายบริหาร (Management Review)
**รหัสเอกสาร:** SNC-EP-EMR-02 (Rev.04)
**วันที่ประกาศใช้:** 15/09/2025

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางให้ฝ่ายบริหารระดับสูงใช้ในการทบทวนระบบการจัดการสิ่งแวดล้อมและความปลอดภัย (ISO 14001 / ISO 45001) ให้มั่นใจว่าระบบยังคงมีความเหมาะสม เพียงพอ มีประสิทธิผล และมีการปรับปรุงพัฒนาอย่างต่อเนื่อง
- **ขอบเขต:** ครอบคลุมการทบทวนผลการดำเนินงานด้านความปลอดภัยและสิ่งแวดล้อมของทุกบริษัทในเครือ SNC

## 2. องค์ประชุมและรอบความถี่ (Meeting Frequency)
- **ความถี่:** จัดประชุมอย่างน้อย **ปีละ 1 ครั้ง** (โดยมักจะจัดขึ้นภายหลังเสร็จสิ้นการตรวจติดตามภายใน หรือเมื่อมีปัญหาสำคัญ)
- **ผู้เข้าร่วมประชุม:** รองประธานกรรมการบริหาร (ประธานที่ประชุม), กรรมการผู้จัดการ (MD), ตัวแทนฝ่ายบริหาร (EMR/SMR), ผู้จัดการแผนก, และ Mini MD ทุกส่วนงาน

## 3. วาระการประชุมทบทวน (Meeting Inputs)
ฝ่ายบริหารจะประชุมเพื่อทบทวนประเด็นสำคัญ ดังนี้:
1. การติดตามผลการดำเนินงานจากการประชุมทบทวนครั้งก่อน
2. การเปลี่ยนแปลงของปัจจัยภายใน-ภายนอก กฎหมายใหม่ และความคาดหวังของผู้มีส่วนได้ส่วนเสีย
3. ผลการดำเนินงานเทียบกับวัตถุประสงค์และเป้าหมายความปลอดภัย (KPIs)
4. สถิติอุบัติเหตุ เหตุการณ์เกือบเกิดอุบัติเหตุ (Near Miss) และโรคจากการทำงาน
5. ผลการตรวจวัดสภาพแวดล้อมในการทำงาน (แสง/เสียง/ความร้อน) และผลการตรวจสุขภาพพนักงาน
6. ผลการตรวจติดตามภายใน (Internal Audit) และสถานะการแก้ไขใบ CAR
7. ความเพียงพอของทรัพยากร (คน, งบประมาณ, อุปกรณ์ป้องกัน)
8. ข้อเสนอแนะและโอกาสในการปรับปรุงอย่างต่อเนื่อง

## 4. ผลลัพธ์จากการทบทวนและการติดตามผล (Outputs)
- **รายงานการประชุม:** ผู้ที่ได้รับมอบหมายต้องจัดทำรายงานการประชุมให้เสร็จสิ้น **ภายใน 1 สัปดาห์** และเสนอให้ประธานที่ประชุมเซ็นอนุมัติ
- **การติดตามมติที่ประชุม:** EMR/SMR มีหน้าที่ติดตามผลการปรับปรุงตามมติของฝ่ายบริหาร และรายงานความคืบหน้าให้ผู้บริหารทราบต่อไป
