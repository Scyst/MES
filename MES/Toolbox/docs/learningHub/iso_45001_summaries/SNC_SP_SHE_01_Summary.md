# สรุปขั้นตอนปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การประเมินความเสี่ยงด้านอาชีวอนามัยและความปลอดภัย
**รหัสเอกสาร:** SNC-SP-SHE-01 (Rev.01)
**วันที่ประกาศใช้:** 15/09/2025

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อใช้ชี้บ่งอันตรายที่แฝงอยู่ในการทำงานทั้งหมด นำมาประเมินระดับความเสี่ยง และกำหนดมาตรการควบคุมเพื่อป้องกันอุบัติเหตุและการเจ็บป่วย
- **ขอบเขต:** ครอบคลุมทุกกิจกรรม (Routine และ Non-Routine) ผลิตภัณฑ์ บริการ และสภาพแวดล้อมการทำงานของพนักงานทุกระดับ รวมถึงผู้รับเหมาภายนอก

## 2. คำจำกัดความที่สำคัญ
- **อันตราย (Hazard):** แหล่งกำเนิดหรือสถานการณ์ที่อาจก่อให้เกิดการบาดเจ็บ ความเจ็บป่วย หรือทรัพย์สินเสียหาย
- **เหตุการณ์เกือบอุบัติเหตุ (Near Miss):** เหตุการณ์ที่ไม่พึงประสงค์ที่เกิดขึ้นแล้วมีแนวโน้มหรือเกือบจะทำให้เกิดอุบัติเหตุ (แต่ยังไม่เกิด)
- **อุบัติเหตุ (Accident):** เหตุการณ์ที่ไม่ได้คาดคิด ซึ่งเกิดขึ้นแล้วส่งผลให้เกิดการบาดเจ็บ เสียชีวิต หรือทรัพย์สินเสียหาย

## 3. ขั้นตอนการชี้บ่งอันตรายและประเมินความเสี่ยง
1. **การรวบรวมกิจกรรม:** หัวหน้างานในแต่ละแผนกต้องรวบรวมกิจกรรมการทำงานทั้งหมดลงในตารางทะเบียนงาน (SNC-FM-SHE-46)
2. **การชี้บ่งอันตราย:** นำกิจกรรมมาวิเคราะห์หาอันตราย โดยพิจารณาจาก 5 ด้านหลัก:
   - **ด้านกายภาพ (Physical):** การลื่นล้ม, ของตกใส่, เสียงดัง, ความร้อน, รังสี
   - **ด้านการยศาสตร์ (Ergonomic):** การยกของหนัก, ท่าทางซ้ำๆ, พื้นที่คับแคบ
   - **ด้านสารเคมี (Chemical):** การสูดดม, สัมผัส, หรือกลืนกินสารเคมี
   - **ด้านชีวภาพ (Biological):** สัตว์มีพิษ, เชื้อโรค, แบคทีเรีย
   - **ด้านจิตสังคม (Psychosocial):** ความเครียด, ความเหนื่อยล้า, การถูกกลั่นแกล้ง (Harassment)
3. **การประเมินระดับความเสี่ยง:** คำนวณจากสมการ `ความเสี่ยง = โอกาสเกิด (%P) x ความรุนแรง (C1) x ระยะเวลาสัมผัส (C2)` แบ่งเกณฑ์ดังนี้:
   - **0 - 300 (ไม่มีนัยสำคัญ):** ยอมรับได้ ไม่ต้องดำเนินการเพิ่ม
   - **>300 - 700 (ต่ำ/ยอมรับได้):** ทบทวนมาตรการป้องกันที่มีอยู่
   - **>700 - 900 (ปานกลาง):** ต้องหาทางลดระดับความเสี่ยง และเพิ่มมาตรการควบคุม
   - **>900 (สูง/ยอมรับไม่ได้):** **ห้ามทำงาน!** ต้องรีบจัดทำแผนงานด้านความปลอดภัย (Action Plan) เพื่อลดความเสี่ยงโดยด่วนที่สุด

## 4. มาตรการควบคุมความเสี่ยง
หากพบว่าความเสี่ยงอยู่ในระดับที่ต้องจัดการ ให้เรียงลำดับการแก้ปัญหาจากวิธีที่ดีที่สุดไปหาวิธีสุดท้าย ดังนี้:
1. การกำจัดอันตราย (Elimination)
2. การทดแทน (Substitution) เช่น เปลี่ยนไปใช้สารเคมีที่อันตรายน้อยกว่า
3. การควบคุมทางวิศวกรรม (Engineering Controls) เช่น ติดตั้งการ์ดป้องกัน, ทำระบบระบายอากาศ
4. การควบคุมเชิงบริหารจัดการ (Administrative Controls) เช่น จัดกะทำงาน, ทำป้ายเตือน
5. อุปกรณ์ป้องกันส่วนบุคคล (PPE) **(ทางเลือกสุดท้าย)**

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ทะเบียนงาน (SNC-FM-SHE-46), รายการชี้บ่งอันตราย (SNC-FM-SHE-47), ทะเบียนความเสี่ยงที่มีนัยสำคัญ (SNC-FM-SHE-48)
- **ระยะเวลาการจัดเก็บ:** เก็บรักษาเอกสารการประเมินความเสี่ยงไว้ **2 ปี**
