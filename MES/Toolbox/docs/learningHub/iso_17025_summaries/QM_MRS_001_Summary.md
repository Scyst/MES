# สรุปคู่มือคุณภาพห้องปฏิบัติการ (Laboratory Quality Manual)
**ชื่อเอกสาร:** คู่มือคุณภาพห้องปฏิบัติการทดสอบ (Quality Manual)
**รหัสเอกสาร:** QM-MRS-001 (Rev.00)
**วันที่ประกาศใช้:** 07/07/2021
**มาตรฐานอ้างอิง:** มอก. 17025-2561 (ISO/IEC 17025:2017)

## 1. ขอบข่ายและวัตถุประสงค์ (Scope & Purpose)
- **ศูนย์ทดสอบ SNC (SNC Testing Center):** จัดตั้งขึ้นเพื่อให้บริการทดสอบประสิทธิภาพของเครื่องปรับอากาศ (เช่น การวัดค่าความสามารถในการทำความเย็น Cooling Capacity, การวัดอัตราการใช้พลังงานไฟฟ้า, ค่าประสิทธิภาพตามฤดูกาล SEER)
- **มาตรฐานที่ใช้ทดสอบ:** อ้างอิงตามมาตรฐานสากลและมาตรฐานระดับชาติ เช่น ISO 5151, ISO 16358-1, มอก. 2134, มอก. 2714 และข้อกำหนดโครงการฉลากเบอร์ 5 ของ กฟผ. (EGAT)
- **เป้าหมาย:** สร้างความเชื่อมั่นแก่ลูกค้าและหน่วยงานกำกับดูแลว่า ผลการทดสอบของศูนย์ทดสอบมีความถูกต้อง แม่นยำ โปร่งใส และเป็นไปตามหลักวิชาการสากล

## 2. นโยบายคุณภาพและความมุ่งมั่น (Quality Policy)
ศูนย์ทดสอบ SNC มุ่งมั่นปฏิบัติตามหลักการสำคัญ 5 ข้อ:
1. ปฏิบัติงานทดสอบด้วยความซื่อสัตย์ ความเป็นกลาง และยึดมั่นในจรรยาบรรณวิชาชีพ
2. ดำเนินการทดสอบอย่างถูกต้องตามมาตรฐานสากล ด้วยเครื่องมือที่มีความสอบกลับได้ทางมาตรวิทยา (Metrological Traceability)
3. บุคลากรทุกคนต้องเข้าใจ ปฏิบัติ และธำรงไว้ซึ่งระบบคุณภาพ ISO/IEC 17025
4. ปรับปรุงประสิทธิผลของระบบบริหารงานคุณภาพอย่างต่อเนื่อง
5. ตอบสนองความต้องการของผู้ใช้บริการด้วยความรวดเร็วและรักษาความลับของลูกค้าสูงสุด

## 3. โครงสร้างองค์กรและบทบาทหน้าที่ (Structural Requirements)
- **ผู้บริหารสูงสุด (Top Management):** สนับสนุนทรัพยากร งบประมาณ และประกาศนโยบายความเป็นกลาง
- **ผู้จัดการคุณภาพ (Quality Manager):** รับผิดชอบการบริหารระบบคุณภาพ ตรวจสอบการปฏิบัติตามคู่มือ จัดการข้อร้องเรียน และควบคุมเอกสารระบบ
- **ผู้จัดการวิชาการ (Technical Manager):** รับผิดชอบด้านเทคนิควิชาการ ความถูกต้องของวิธีทดสอบ การคำนวณค่าความไม่แน่นอน (Uncertainty) และการรับรองรายงานผลการทดสอบ
- **เจ้าหน้าที่ทดสอบ (Testing Operator):** ปฏิบัติการทดสอบตามวิธีมาตรฐาน (WI) และบันทึกข้อมูลผลการทดสอบตามจริง

## 4. สรุปข้อกำหนดหลักของมาตรฐาน ISO/IEC 17025 (Key Clauses)

### ข้อ 4: ข้อกำหนดทั่วไป (General Requirements)
- **ความเป็นกลาง (Impartiality):** ปราศจากความกดดันทางการค้า การเงิน หรืออิทธิพลภายใน-ภายนอกที่จะส่งผลต่อความซื่อตรงของผลทดสอบ
- **การรักษาความลับ (Confidentiality):** ข้อมูลผลทดสอบและข้อมูลผลิตภัณฑ์ของลูกค้าทั้งหมดถือเป็นความลับสูงสุด ห้ามเปิดเผยแก่บุคคลภายนอกโดยไม่ได้รับอนุญาต

### ข้อ 6: ข้อกำหนดด้านทรัพยากร (Resource Requirements)
- **บุคลากร:** ต้องมีความรู้ ความสามารถ ผ่านการประเมินสมรรถนะ (Competency) และได้รับการฝึกอบรมอย่างต่อเนื่อง
- **สิ่งอำนวยความสะดวกและสภาวะแวดล้อม:** ห้องทดสอบ (Psychrometric / Calorimeter Room) ต้องควบคุมอุณหภูมิและความชื้นอย่างเคร่งครัดตามวิธีทดสอบ
- **เครื่องมือและการสอบกลับได้:** เครื่องมือวัดทุกชิ้นต้องผ่านการสอบเทียบ (Calibration) ไปยังสถาบันมาตรวิทยาแห่งชาติ (NIMT) หรือมาตรฐานสากล

### ข้อ 7: ข้อกำหนดด้านกระบวนการ (Process Requirements)
- **การทวนสอบวิธีทดสอบ (Method Verification):** วิธีทดสอบมาตรฐานต้องได้รับการทวนสอบเพื่อยืนยันว่าศูนย์ทดสอบสามารถดำเนินการได้ตามเกณฑ์
- **การจัดการตัวอย่างทดสอบ:** บันทึกรับสภาพตัวอย่าง ติดรหัสชี้บ่ง และป้องกันการสับสนหรือชำรุดเสียหาย
- **การประกันความใช้ได้ของผลทดสอบ:** ดำเนินการทดสอบซ้ำ (Repeatability), การสอบเทียบระหว่างกัน, และเข้าร่วมการทดสอบความชำนาญระหว่างห้องปฏิบัติการ (Proficiency Testing - PT)
- **การรายงานผล (Reporting Results):** ออกรายงานผลการทดสอบ (Test Report) ที่มีข้อมูลครบถ้วน ชัดเจน และมีลายเซ็นผู้มีอำนาจลงนามรับรอง

### ข้อ 8: ข้อกำหนดระบบการบริหาร (Management System Requirements)
- การควบคุมเอกสารและบันทึก, การจัดการความเสี่ยงและโอกาส, การปฏิบัติการแก้ไข (CAR), การตรวจประเมินภายใน (Internal Audit), และการประชุมทบทวนโดยฝ่ายบริหาร (Management Review)
