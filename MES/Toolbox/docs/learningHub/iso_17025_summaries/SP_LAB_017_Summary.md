# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การจัดการตัวอย่างทดสอบ (Handling of Test Items)
**รหัสเอกสาร:** SP-LAB-017 (Rev.00)
**วันที่ประกาศใช้:** 07/07/2021
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 7.4 การจัดการตัวอย่างทดสอบ

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนในการรับตัวอย่าง การชี้บ่ง การรักษาสภาพตัวอย่างระหว่างรอทดสอบ การป้องกันความเสียหายหรือเสื่อมสภาพ และการส่งคืนตัวอย่างให้แก่ลูกค้า
- **ขอบเขต:** ครอบคลุมผลิตภัณฑ์เครื่องปรับอากาศและชิ้นส่วนทั้งหมดที่ส่งเข้ามาทดสอบในศูนย์ทดสอบ SNC

## 2. ขั้นตอนการรับตัวอย่าง (Sample Receiving)
1. **การตรวจสภาพภายนอก:** เจ้าหน้าที่ทดสอบตรวจสอบสภาพตัวอย่างเครื่องปรับอากาศเมื่อมาถึง บันทึกลงใน **"ใบขอรับบริการทดสอบ" (FM-LAB-047)**
   - *กรณีตัวอย่างผิดปกติหรือชำรุด:* ให้ปฏิเสธการรับและส่งคืนลูกค้าทันที แต่หากลูกค้ายืนยันจะให้ทดสอบต่อ **ต้องระบุสภาพชำรุดดังกล่าวลงในใบขอรับบริการ และต้องระบุเป็นคำเตือนในใบรายงานผลการทดสอบ (Test Report) อย่างชัดเจน**
2. **การทบทวนทรัพยากร:** ผู้จัดการวิชาการทบทวนความพร้อมของห้องแล็บและเครื่องมือก่อนลงนามรับงาน

## 3. การกำหนดรหัสชี้บ่งตัวอย่าง (Sample Identification)
เพื่อป้องกันการสลับตัวอย่าง ศูนย์ทดสอบกำหนดรหัสชี้บ่งรูปแบบ:
`AAAA-BB-CC/DDMMYY`
- `AAAA` = ลำดับใบขอรับบริการทดสอบ (4 หลัก)
- `BB` = ประเภทตัวอย่างเครื่องปรับอากาศ:
  - `01` = Wall type (ติดผนัง)
  - `02` = Window type (หน้าต่าง)
  - `03` = Portable type (เคลื่อนที่)
  - `04` = Duct type (ท่อลม)
  - `05` = Ceiling type (แขวนใต้ฝ้า)
  - `06` = Floor standing (ตั้งพื้น)
  - `07` = Floor/Ceiling (ตั้ง/แขวน)
  - `08` = Other (อื่นๆ)
- `CC` = ลำดับที่ของตัวอย่าง
- `DDMMYY` = วันเดือนปี ค.ศ. ที่รับตัวอย่าง
*(ตัวอย่าง: `0001-01-01/050421` หมายถึง ใบคำร้องที่ 1 แอร์ติดผนัง ตัวอย่างที่ 1 รับวันที่ 5 เมษายน 2021)*
- ใช้ปากกาถาวร (Permanent Marker) เขียนรหัสชี้บ่งลงบนตัวอย่างให้ชัดเจน

## 4. การจัดเก็บและการส่งคืนตัวอย่าง (Storage and Return)
- **การจัดเก็บ:** จัดเก็บตัวอย่างในห้องรับตัวอย่างที่ควบคุมอุณหภูมิและความชื้นเหมาะสมเพื่อไม่ให้ชิ้นส่วนอิเล็กทรอนิกส์หรือฉนวนเสียหาย
- **การส่งคืนตัวอย่าง:** เมื่อทดสอบเสร็จสิ้น ให้บันทึกการส่งคืนตัวอย่างใน **"บันทึกควบคุมการรับตัวอย่าง ทดสอบและรายงานผล" (FM-LAB-049)**
- **การทำลายตัวอย่าง (กรณีไม่มารับคืน):** ผู้จัดการวิชาการจะเข้าตรวจสอบตัวอย่างที่ตกค้างทุก 3 เดือน หากครบกำหนดตามสัญญา จะทำบันทึกและอนุมัติการทำลายตัวอย่างต่อไป

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบขอรับบริการทดสอบ (FM-LAB-047), บันทึกควบคุมการรับตัวอย่าง ทดสอบและรายงานผล (FM-LAB-049)
- **ระยะเวลาการจัดเก็บ:** เอกสารบันทึกการรับและคืนตัวอย่างทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
