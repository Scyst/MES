# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การปฏิบัติการเพื่อจัดการความเสี่ยงและโอกาส (Actions to Address Risks and Opportunities)
**รหัสเอกสาร:** SP-LAB-003 (Rev.00)
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 8.5 การปฏิบัติการเพื่อจัดการความเสี่ยงและโอกาส, ข้อ 4.1 ความเป็นกลาง

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าห้องปฏิบัติการมีระบบการบริหารความเสี่ยงและโอกาสอย่างมีประสิทธิผล สามารถประกันได้ว่าระบบการจัดการคุณภาพบรรลุผลลัพธ์ตามที่วางแผนไว้ ป้องกันหรือลดผลกระทบที่ไม่พึงประสงค์ และผลักดันให้เกิดการปรับปรุงอย่างต่อเนื่อง
- **ขอบเขต:** ครอบคลุมการชี้บ่ง ประเมิน ควบคุม และติดตามความเสี่ยงทั้งจากปัจจัยภายใน (บุคลากร, เครื่องมือ, สภาพแวดล้อม, กระแสเงินสด, ความเป็นกลาง) และปัจจัยภายนอก (คู่แข่ง, เศรษฐกิจ, ผู้ขาย/ผู้สอบเทียบภายนอก, ความคุ้นเคยกับลูกค้า)

## 2. เกณฑ์การประเมินความเสี่ยง (Risk Assessment Matrix)

### 2.1 โอกาสในการเกิดความเสี่ยง (Likelihood: L)
- **ระดับ 1 (น้อยมาก):** แทบไม่มีโอกาสเกิด ความถี่ประมาณ 5 ปีต่อครั้ง
- **ระดับ 2 (น้อย):** นานๆ ครั้ง ความถี่ประมาณ 2 – 4 ปีต่อครั้ง
- **ระดับ 3 (ปานกลาง):** เกิดขึ้นเป็นประจำ ความถี่ประมาณ 1 ปีต่อครั้ง
- **ระดับ 4 (สูง):** เกิดบ่อยครั้ง มากกว่า 1 ครั้งต่อปี

### 2.2 ความรุนแรงของผลกระทบ (Impact: I)
- **ระดับ 1 (น้อยมาก):** ไม่มีผลกระทบโดยตรงต่อกิจกรรมของห้องปฏิบัติการ
- **ระดับ 2 (น้อย):** มีผลกระทบแต่สามารถควบคุมได้ภายในหน่วยงาน
- **ระดับ 3 (ปานกลาง):** มีผลกระทบที่ไม่สามารถควบคุมได้ทันที แต่ห้องแล็บยังเปิดดำเนินการต่อไปได้
- **ระดับ 4 (สูง):** มีผลกระทบรุนแรงจนห้องปฏิบัติการไม่สามารถดำเนินงานได้ หรือสร้างความเสียหายต่อชื่อเสียงองค์กรอย่างร้ายแรง

### 2.3 การจัดระดับความเสี่ยง (Risk Level = L x I)
| ระดับคะแนน | ระดับความเสี่ยง (Risk Level) | มาตรการจัดการ (Risk Treatment) |
| :---: | :---: | :--- |
| **1 – 3** | **ความเสี่ยงต่ำ (Low Risk)** | ยอมรับได้ ไม่จำเป็นต้องมีมาตรการจัดการเพิ่มเติม |
| **4 – 8** | **ความเสี่ยงปานกลาง (Medium Risk)** | ยอมรับได้ แต่ต้องมีมาตรการเฝ้าระวังเพื่อไม่ให้ระดับความเสี่ยงเพิ่มขึ้น |
| **9 – 11** | **ความเสี่ยงสูง (High Risk)** | **ยอมรับไม่ได้** ต้องจัดทำ Action Plan จัดการความเสี่ยงให้อยู่ในระดับที่ยอมรับได้ |
| **12 – 16** | **ความเสี่ยงสูงมาก (Extreme Risk)** | **ยอมรับไม่ได้อย่างยิ่ง** ต้องดำเนินมาตรการแก้ไขเร่งด่วนทันที |

## 3. กลยุทธ์การจัดการความเสี่ยง (Risk Treatment Strategies)
1. **หลีกเลี่ยงความเสี่ยง (Avoidance):** ยุติกิจกรรมที่มีความเสี่ยงสูงหรือไม่ชำนาญ หรือป้องกันไม่ให้เจ้าหน้าที่ทดสอบติดต่อลูกค้าโดยตรงเพื่อรักษาความเป็นกลาง
2. **เปลี่ยนความเสี่ยงเป็นโอกาส (Exploiting Opportunity):** เช่น เครื่องมือรุ่นเก่าเสื่อมสภาพ นำไปสู่การลงทุนจัดซื้อเครื่องมือรุ่นใหม่ที่มีประสิทธิภาพสูงกว่า
3. **กำจัดแหล่งกำเนิดความเสี่ยง (Elimination):** แก้ไขที่สาเหตุรากเหง้า (Root Cause) เช่น ส่งพนักงานอบรมทักษะเพื่อลด Human Error
4. **ลดโอกาสเกิดหรือลดความรุนแรง (Mitigation):** จัดทำ Work Instruction และแผนบำรุงรักษาเชิงป้องกัน
5. **แบ่งปันความเสี่ยง (Sharing):** ขึ้นทะเบียนผู้ขาย/ผู้สอบเทียบใน AVL ไว้หลายรายเพื่อกระจายความเสี่ยงด้านการส่งมอบ
6. **ยอมรับความเสี่ยงโดยการตัดสินใจของผู้บริหาร (Retention):** สำหรับความเสี่ยงที่ไม่คุ้มค่าต่อการลงทุน เช่น ภัยธรรมชาติ โดยผู้บริหารสูงสุดเป็นผู้อนุมัติ

## 4. ขั้นตอนการติดตามผลและการทบทวน
1. ชี้บ่งความเสี่ยงใน **"แบบฟอร์มชี้บ่งความเสี่ยงและโอกาส" (FM-LAB-013)**
2. จัดทำ **"แผนปฏิบัติงานชี้บ่งความเสี่ยงและโอกาส" (Action Plan - FM-LAB-014)** และมอบหมายผู้รับผิดชอบ
3. ผู้จัดการคุณภาพติดตามผลตาม **"แบบฟอร์มการติดตามผลการดำเนินงาน" (FM-LAB-012)** หากแผนไม่บรรลุเป้าหมาย ต้องเปิดคำร้องขอให้แก้ไข (CAR - FM-LAB-020) ตามระเบียบ SP-LAB-007
4. นำผลการจัดการความเสี่ยงเข้าทบทวนในการประชุมทบทวนโดยฝ่ายบริหาร (Management Review) อย่างน้อยปีละ 1 ครั้ง

## 5. แบบฟอร์มและบันทึกคุณภาพที่เกี่ยวข้อง
- แบบฟอร์มชี้บ่งความเสี่ยงและโอกาส (FM-LAB-013)
- แผนปฏิบัติงานชี้บ่งความเสี่ยงและโอกาส (Action Plan - FM-LAB-014)
- แบบฟอร์มการติดตามผลการดำเนินงานการจัดการความเสี่ยงและโอกาส (FM-LAB-012)
- คำร้องขอให้แก้ไข (CAR - FM-LAB-020)
- **การจัดเก็บ:** แผนก DCC จัดเก็บ 5 ปีในระบบ Save Folder
