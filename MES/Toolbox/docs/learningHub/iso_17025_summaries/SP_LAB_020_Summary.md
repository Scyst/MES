# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การฝึกอบรมและการประเมินความสามารถบุคลากร (Personnel Training and Competence)
**รหัสเอกสาร:** SP-LAB-020 (Rev.00)
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 6.2 บุคลากร (Personnel)

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าบุคลากรของห้องปฏิบัติการได้รับการฝึกอบรม มีทักษะ ความรู้ ความเข้าใจ และมีความสามารถเหมาะสมตามลักษณะงานที่ได้รับมอบหมาย
- **ขอบเขต:** บุคลากรทุกคนที่ปฏิบัติงานเกี่ยวข้องกับระบบการบริหารงานคุณภาพและด้านวิชาการของห้องปฏิบัติการทดสอบ

## 2. ขั้นตอนการปฏิบัติงาน (Workflow)

### 2.1 หน้าที่ตำแหน่งงานและการระบุความจำเป็นในการฝึกอบรม (JD & Training Needs)
1. จัดทำ **"ใบพรรณาลักษณะงาน" (Job Description - FM-LAB-040)** สำหรับทุกตำแหน่งในห้องแล็บ ให้บุคลากรทุกคนลงนามรับทราบขอบเขตหน้าที่
2. กำหนดหลักสูตรพื้นฐานที่จำเป็นประจำตำแหน่งตาม **"ความจำเป็นของการฝึกอบรมประจำตำแหน่ง" (FM-LAB-034)**
3. จัดทำ **"แผนฝึกอบรมประจำปี" (Training Plan - FM-PER-014)** ครอบคลุมทั้ง On the Job Training (OJT), การอบรมภายใน, และการอบรมภายนอก

### 2.2 เกณฑ์การประเมินประสิทธิผลการฝึกอบรม (Competence Evaluation Criteria)
| วิธีการประเมิน | เกณฑ์การตัดสินว่าผ่าน |
| :--- | :--- |
| 1. การซักถาม (Verbal Q&A) | เข้าใจ ตอบคำถามและอธิบายหลักการได้ถูกต้อง |
| 2. การสังเกตการณ์ปฏิบัติงาน (Observation) | สามารถปฏิบัติงาน ทดสอบ และใช้เครื่องมือได้อย่างถูกต้องตามระเบียบ |
| 3. การทดสอบข้อเขียน (Written Exam) | ได้คะแนน **มากกว่า 70%** |
| 4. การฝึกอบรมภายนอก | มีใบประกาศนียบัตร / ใบรับรอง (Certificate) |
| 5. การประเมินทางเทคนิค | ผลทดสอบความชำนาญ (PT), ผล Inter-lab, หรือ Intra-lab ผ่านตามเกณฑ์ที่กำหนด |
*หากผลการประเมินไม่ผ่านเกณฑ์ จะต้องจัดฝึกอบรมซ้ำและประเมินผลใหม่อีกครั้ง*

### 2.3 การมอบหมายอำนาจหน้าที่การปฏิบัติงาน (Personnel Authorization - FM-LAB-062)
ผู้บริหารสูงสุดจะจัดทำและลงนามใน **"บันทึกมอบหมายการปฏิบัติงาน" (FM-LAB-062)** เพื่อแต่งตั้งและอนุญาตให้บุคลากรปฏิบัติงานเฉพาะด้าน ดังนี้:
1. การจัดทำ ดัดแปลง ทวนสอบ และพิสูจน์ความใช้ได้ของวิธีทดสอบ (Method Validation/Verification)
2. การวิเคราะห์และประเมินผลการทดสอบ
3. การรายงานผล การทบทวน และการอนุมัติรายงานผลทดสอบ (Test Report Approval)

### 2.4 การเฝ้าระวังความสามารถ (Competence Monitoring)
- ผู้จัดการวิชาการต้องเฝ้าระวังและประเมินความสามารถของบุคลากรที่ได้รับมอบหมายงาน **อย่างน้อยปีละ 1 ครั้ง** โดยระบุไว้ในแผนฝึกอบรมประจำปี

### 2.5 การประเมินความเบี่ยงเบนที่มีนัยสำคัญในการทดสอบ (Assessment of Significant Deviations - FM-LAB-063)
เจ้าหน้าที่ทดสอบต้องได้รับการฝึกอบรมให้สามารถประเมินผลกระทบและความเสี่ยงของการเบี่ยงเบนในกระบวนการทดสอบ:
- **ตัวอย่างผิดปกติ/ไม่สมบูรณ์:** แจ้งลูกค้าเพื่อนำส่งตัวอย่างใหม่ หรือระบุหมายเหตุความผิดปกติในรายงานผล
- **สภาวะแวดล้อมหลุดจากเกณฑ์ควบคุม:** ระงับการทดสอบทันที ปรับสภาวะให้เข้าเกณฑ์ และออกใบ NC
- **เครื่องมือเลยกำหนดสอบเทียบ:** ต้องทำ Intermediate Check ทันที หากผ่านจึงใช้งานได้ชั่วคราว พร้อมทวนสอบผลกระทบย้อนหลัง และออกใบ NC
- **ไฟฟ้าดับระหว่างการทดสอบ:** ผลการทดสอบโมฆะ ต้องทำการทดสอบตัวอย่างใหม่ทั้งหมด และออกใบ NC

## 3. แบบฟอร์มและบันทึกคุณภาพที่เกี่ยวข้อง
- ใบพรรณาลักษณะงาน (FM-LAB-040)
- ความจำเป็นของการฝึกอบรมประจำตำแหน่ง (FM-LAB-034)
- แผนฝึกอบรมประจำปี (FM-PER-014)
- แบบบันทึกผลการฝึกอบรม (FM-LAB-061)
- ประวัติการฝึกอบรมและการทำงาน (FM-LAB-093)
- บันทึกมอบหมายการปฏิบัติงาน (FM-LAB-062)
- แบบบันทึกการประเมินความเบี่ยงเบนที่มีนัยสำคัญในการทดสอบ (FM-LAB-063)
- **การจัดเก็บ:** จัดเก็บในระบบ HR ตลอดอายุการเป็นพนักงาน
