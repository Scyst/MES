# 📚 MES Learning Hub — Knowledge Base & Curriculum Documentation

คลังเอกสาร สรุปมาตรฐานอุตสาหกรรม (ISO & Compliance Standards), เช็กลิสต์การตรวจประเมินโรงงานของลูกค้าสากล (Customer Audits), แผนที่หลักสูตรวิศวกรรม (Full-Stack Roadmap) และประวัติการสังเคราะห์เนื้อหาทั้งหมดของศูนย์เรียนรู้ MES Learning Hub

---

## 📁 โครงสร้างเอกสารในโฟลเดอร์นี้

### 1. แผนที่หลักสูตรและเส้นทางพัฒนาทักษะ (Curriculum Roadmaps)
- [`ENTERPRISE_FULLSTACK_ROADMAP.md`](./ENTERPRISE_FULLSTACK_ROADMAP.md) — พิมพ์เขียวหลักสูตรวิศวกรซอฟต์แวร์โรงงาน 5 ระยะ (Full-Stack & IIoT Roadmap)
- [`ROBOTICS_AI_VISION_MODULES.md`](./ROBOTICS_AI_VISION_MODULES.md) — หลักสูตรหุ่นยนต์แขนกลอุตสาหกรรม 6 แกน และ Machine Vision ขั้นสูง

### 2. แทร็กเกอร์ติดตามการสังเคราะห์บทเรียน (Learning Trackers)
- [`qa_iso_learning_tracker.md`](./qa_iso_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร ISO 9001:2015
- [`iso_14001_learning_tracker.md`](./iso_14001_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร ISO 14001:2015 (สิ่งแวดล้อมและ Net Zero)
- [`iso_45001_learning_tracker.md`](./iso_45001_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร ISO 45001:2018 (ความปลอดภัย อาชีวอนามัย และ LOTO)
- [`iso_17025_learning_tracker.md`](./iso_17025_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร ISO/IEC 17025:2017 (ห้องปฏิบัติการสอบเทียบและการวัด)
- [`ppap_learning_tracker.md`](./ppap_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร PPAP 18 องค์ประกอบ
- [`customer_audit_learning_tracker.md`](./customer_audit_learning_tracker.md) — สรุปการสังเคราะห์เกณฑ์การตรวจประเมินของลูกค้าสากล (Global Customer Audits & ESG)
- [`operational_qa_learning_tracker.md`](./operational_qa_learning_tracker.md) — สรุปการสังเคราะห์หลักสูตร Live Operational QA & Audit Defense

### 3. คลังสรุปมาตรฐานและข้อกำหนดเชิงลึก (Standard Summaries)
- `customer_audit_summaries/` (7 ไฟล์) — เช็กลิสต์และข้อกำหนดของลูกค้า เช่น Lowe's, NPI/ECN, First Pass Yield, ESG, Sharp Tool Recall
- `iso_14001_summaries/` (19 ไฟล์) — สรุปวิธีปฏิบัติงานด้านสิ่งแวดล้อม การจัดการสารเคมี ขยะอุตสาหกรรม และแผนฉุกเฉิน
- `iso_17025_summaries/` (24 ไฟล์) — คู่มือคุณภาพห้องแล็บ การควบคุมเครื่องมือวัด ความไม่แน่นอนในการวัด (Uncertainty) และ Calibration
- `iso_45001_summaries/` (25 ไฟล์) — ระเบียบปฏิบัติงานความปลอดภัย การประเมินความเสี่ยง JSA งานที่ต้องขอใบอนุญาต (Work Permit) และการ์ดเครื่องจักร
- `operational_qa_summaries/` (5 ไฟล์) — แนวทางการรับมือผู้ตรวจประเมินหน้างานจริงและการชี้แจง Nonconformance
- `ppap_summaries/` (6 ไฟล์) — กระบวนการอนุมัติชิ้นส่วนการผลิต DFMEA/PFMEA, Control Plan, MSA, และ PSW
- `qa_iso_summaries/` (46 ไฟล์) — ระเบียบการควบคุมกระบวนการผลิต การตรวจสอบคุณภาพชิ้นงาน และการควบคุมเอกสารตามระบบ ISO 9001
