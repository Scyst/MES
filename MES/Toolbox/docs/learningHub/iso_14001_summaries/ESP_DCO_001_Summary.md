# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การสื่อสารและประชาสัมพันธ์ด้านสิ่งแวดล้อม (Environmental Communication)
**รหัสเอกสาร:** ESP-DCO-001 (Rev.06)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการสื่อสารประชาสัมพันธ์ทั้งภายในและภายนอกองค์กร ถ่ายทอดนโยบาย เป้าหมาย ระเบียบปฏิบัติด้านสิ่งแวดล้อม และเปิดรับฟังข้อคิดเห็น/ข้อร้องเรียนในลักษณะ **การสื่อสารสองทาง (Two-Way Communication)**
- **ขอบเขต:** ครอบคลุมการสื่อสารระหว่างพนักงานทุกระดับ รวมถึงบุคคลและหน่วยงานภายนอก (ชุมชน, ลูกค้า, คู่ค้า, ราชการ)

## 2. กลุ่มเป้าหมายและช่องทางการสื่อสาร
บริษัทแบ่งการสื่อสารออกตามกลุ่มผู้มีส่วนได้ส่วนเสีย 4 กลุ่มหลัก:

1. **พนักงานภายในองค์กร:**
   - *เนื้อหา:* นโยบายสิ่งแวดล้อม, การคัดแยกขยะ, การประหยัดพลังงาน, แผนฉุกเฉิน
   - *ช่องทาง:* บอร์ดประชาสัมพันธ์, กิจกรรม Morning Talk, LINE กลุ่ม, อีเมลภายใน, และการอบรม
   - *การรับฟังความเห็น:* จัดให้มี **"กล่องรับฟังความคิดเห็น/ข้อเสนอแนะด้านสิ่งแวดล้อม"** ตามจุดต่างๆ
2. **ผู้รับเหมาและคู่ค้า (Suppliers):**
   - *เนื้อหา:* กฎการทิ้งขยะในโรงงาน, ข้อควรระวังการใช้สารเคมี, การป้องกันอัคคีภัย
   - *ช่องทาง:* การอบรมก่อนเข้าทำงาน, เอกสารแนบท้ายสัญญาจัดซื้อจัดจ้าง, การแจ้งผ่านเจ้าหน้าที่ความปลอดภัย
3. **ชุมชนรอบข้างและท้องถิ่น:**
   - *เนื้อหา:* นโยบายสิ่งแวดล้อม, ผลกระทบต่อชุมชน, ช่องทางแจ้งเรื่องร้องเรียน
   - *ช่องทาง:* ป้ายประชาสัมพันธ์หน้าโรงงาน, จัดเตรียม **"แบบฟอร์มรับข้อร้องเรียน" ไว้ที่ป้อม รปภ.** หน้าโรงงาน
4. **ลูกค้า:**
   - *เนื้อหา:* นโยบายสิ่งแวดล้อม และใบรับรองมาตรฐาน ISO 14001
   - *ช่องทาง:* อีเมล, เอกสารนำเสนอ, หรือการเข้าตรวจโรงงานของลูกค้า (Customer Audit)

## 3. ขั้นตอนการจัดการข้อร้องเรียนด้านสิ่งแวดล้อม (Complaints Handling)
- เมื่อมีข้อร้องเรียนจากชุมชนหรือพนักงาน (ผ่านวาจา, โทรศัพท์, หรือแบบฟอร์มที่ป้อม รปภ.) ให้บันทึกลงใน **ฟอร์ม EF-DCO-024**
- ฝ่ายบุคคลและสิ่งแวดล้อม (EMR) จะลงพื้นที่ตรวจสอบหาสาเหตุที่แท้จริง
- ดำเนินการแก้ไข และ **ทำหนังสือชี้แจงผลการแก้ไขกลับไปยังผู้ร้องเรียน** ทันที เพื่อรักษาความสัมพันธ์อันดีกับชุมชน

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ตารางการสื่อสารข้อมูล (EF-DCO-023), บันทึกการรับข้อร้องเรียน/ข้อเสนอแนะด้านสิ่งแวดล้อม (EF-DCO-024)
- **ระยะเวลาการจัดเก็บ:** เอกสารการสื่อสารและข้อร้องเรียนทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
