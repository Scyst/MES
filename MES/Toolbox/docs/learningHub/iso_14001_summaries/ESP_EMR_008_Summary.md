# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การจัดการขยะและของเสียอันตราย (Waste Management)
**รหัสเอกสาร:** ESP-EMR-008 (Rev.08)
**วันที่ประกาศใช้:** 15/02/2565

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อควบคุมการคัดแยก จัดเก็บ ขนย้าย และกำจัดขยะทุกประเภทให้ถูกต้องตามกฎหมายสิ่งแวดล้อม ลดผลกระทบต่อธรรมชาติ และส่งเสริมการนำขยะกลับมาใช้ประโยชน์ใหม่ (Recycle/Reuse)
- **ขอบเขต:** ครอบคลุมการจัดการขยะทุกชนิดภายในบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน) และบริษัทในเครือ

## 2. การคัดแยกขยะ 5 ประเภทหลัก (Waste Segregation)
บริษัทกำหนดให้คัดแยกขยะออกเป็น 5 ประเภทอย่างเคร่งครัด:

1. **ขยะทั่วไป:**
   - *ตัวอย่าง:* เศษขยะทำความสะอาด, ถุงพลาสติกไม่ปนเปื้อน, ซองขนม, กล่องโฟม, กระดาษทิชชู่
   - *การจัดการ:* มัดปากถุงให้มิดชิด นำไปไว้ที่ห้องเก็บขยะทั่วไป เพื่อให้ อบต./เทศบาล มาเก็บขนไปกำจัด
2. **ขยะรีไซเคิล:**
   - *ตัวอย่าง:* เศษกระดาษ, ลังกระดาษ, เศษเหล็ก, เศษท่อทองแดง, พาเลทไม้, พลาสติกที่ไม่ปนเปื้อนสารเคมี
   - *การจัดการ:* รวบรวมคัดแยกเพื่อจำหน่ายให้กับผู้รับซื้อที่ได้รับอนุญาต ผ่านระบบอิเล็กทรอนิกส์ของกรมโรงงานอุตสาหกรรม
3. **ขยะอันตราย:**
   - *ตัวอย่าง:* ถ่านไฟฉาย, แบตเตอรี่, หลอดไฟฟลูออเรสเซนต์, ตลับหมึกพิมพ์, ถุงมือ/เศษผ้าเปื้อนน้ำมัน, ภาชนะบรรจุสารเคมี, น้ำมันเครื่องใช้แล้ว, กากตะกอนน้ำเสีย
   - *การจัดการ:* **ทิ้งลงถังขยะอันตราย (ถังแดง)** และส่งกำจัดกับบริษัทรับกำจัดของเสียที่ขึ้นทะเบียนถูกต้องกับกรมโรงงานอุตสาหกรรมเท่านั้น
4. **ขยะติดเชื้อ:**
   - *ตัวอย่าง:* สำลี, ผ้าก๊อซ, เข็มฉีดยา, วัสดุปฐมพยาบาลในห้องพยาบาล
   - *การจัดการ:* ทิ้งในถังขยะติดเชื้อในห้องพยาบาล มัดปากถุงให้มิดชิดทุกวัน และส่งมอบให้พยาบาลนำไปกำจัดร่วมกับโรงพยาบาล
5. **ขยะมูลฝอยเปียก (เศษอาหาร):**
   - *ตัวอย่าง:* เศษอาหารจากโรงอาหาร
   - *การจัดการ:* แยกใส่ถังเฉพาะเพื่อนำไปแจกจ่ายให้ชุมชนใกล้เคียงใช้เป็นอาหารสัตว์

## 3. การเฝ้าระวังและตรวจสอบ
- คณะกรรมการสิ่งแวดล้อมจะร่วมกันเดินตรวจติดตามการคัดแยกขยะของทุกแผนก **เดือนละ 1 ครั้ง** (ในสัปดาห์แรกของเดือน) เพื่อประเมินผลและปรับปรุงพฤติกรรมของพนักงาน

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบบันทึกการทิ้งขยะ (EF-DCO-034)
- **ระยะเวลาการจัดเก็บ:** เอกสารบันทึกการกำจัดขยะเก็บรักษาไว้เป็นเวลา **5 ปี** (ตามกฎหมายกากอุตสาหกรรม)
