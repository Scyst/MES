# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมสารเคมีหกรั่วไหล (Chemical Spill Control)
**รหัสเอกสาร:** ESP-EMR-010 (Rev.06)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนในการควบคุม ป้องกัน และแก้ไขเมื่อเกิดเหตุสารเคมีหกรั่วไหล เพื่อไม่ให้ส่งผลกระทบต่อสิ่งแวดล้อม ชุมชน และสุขภาพของพนักงาน
- **ขอบเขต:** ครอบคลุมการจัดเก็บ การเบิกใช้ และการขนย้ายสารเคมีทั้งหมดภายในบริษัท

## 2. เกณฑ์การแบ่งระดับความรุนแรงของสารเคมีรั่วไหล
บริษัทแบ่งการรั่วไหลออกเป็น 2 ระดับตามปริมาตร:

### 2.1 รั่วไหลปริมาณเล็กน้อย (น้อยกว่า 2.5 ลิตร)
- ผู้ปฏิบัติงานหรือผู้พบเห็นต้องเข้าระงับเหตุและทำความสะอาดทันทีตามที่ระบุในเอกสาร **MSDS / SDS** ประจำจุดทำงาน
- แจ้งหัวหน้างานประจำพื้นที่ให้รับทราบ

### 2.2 ภาวะฉุกเฉิน / รั่วไหลปริมาณมาก (มากกว่า 2.5 ลิตรขึ้นไป)
1. **แจ้งเหตุและอพยพ:** ผู้พบเห็นแจ้งหัวหน้าพื้นที่ทันที และทำการปิดกั้นพื้นที่เกิดเหตุไม่ให้ผู้ไม่เกี่ยวข้องเข้าไป
2. **ปฐมพยาบาล:** หากมีผู้ได้รับบาดเจ็บหรือสัมผัสสารเคมี ให้พาออกจากพื้นที่และปฐมพยาบาลเบื้องต้น นำส่งห้องพยาบาลทันที
3. **ป้องกันการไหลลงท่อน้ำ:** **(สำคัญที่สุด)** ต้องรีบกั้นไม่ให้สารเคมีไหลลงสู่รางระบายน้ำฝนหรือแหล่งน้ำสาธารณะ
4. **ตัดต้นตอ:** พยายามหยุดการรั่วไหลจากแหล่งกำเนิด (เช่น ปิดวาล์ว, พลิกถังตั้งขึ้น)
5. **ดูดซับและทำความสะอาด:** ใช้วัสดุดูดซับ (ทราย, ขี้เลื่อย, เศษผ้า) ซับสารเคมีให้แห้ง ตักใส่ภาชนะ และส่งกำจัดตามระเบียบการจัดการขยะอันตราย (ESP-EMR-008)

## 3. การรายงานและการออกใบ NC Report
- ผู้รับผิดชอบพื้นที่ต้องเขียนรายละเอียดลงใน **แบบฟอร์มรายงานข้อบกพร่อง (NC Report - EF-DCO-022)** ภายใน **7 วัน** หลังเกิดเหตุ เพื่อหาสาเหตุที่แท้จริงและกำหนดมาตรการป้องกันไม่ให้เกิดซ้ำ
- จป.วิชาชีพ จะลงตรวจสอบผลการแก้ไขหน้างานจริง หากผ่านจะเซ็นอนุมัติปิดเรื่อง หากไม่ผ่านจะสั่งแก้ไขใหม่ทันที
- สรุปรายงานเหตุการณ์เสนอต่อที่ประชุมการทบทวนฝ่ายบริหาร

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบรายงานข้อบกพร่อง NC Report (EF-DCO-022)
- **ระยะเวลาการจัดเก็บ:** เก็บรักษาไว้เป็นเวลา **5 ปี**
