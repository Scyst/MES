# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การสรรหาทรัพยากรบุคคล (Recruitment and Manpower Management)
**รหัสเอกสาร:** ESP-HRD-004 (Rev.08)
**วันที่ประกาศใช้:** 05/04/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อคัดเลือกและบรรจุพนักงานที่มีความรู้ความสามารถตรงตามความต้องการของแต่ละหน่วยงานอย่างเพียงพอ และมีกระบวนการประเมินผลการทำงานที่เป็นมาตรฐาน
- **ขอบเขต:** ครอบคลุมการสรรหาพนักงานใหม่, การโอนย้าย, การประเมินผลทดลองงาน, การประเมินผลงานประจำปี, ไปจนถึงการลาออกของพนักงานทุกระดับ

## 2. ขั้นตอนการสรรหาและคัดเลือกพนักงาน
1. **การวางแผนและขออัตรากำลัง:** แผนกที่ต้องการคนต้องกรอก **"ใบเสนอขอพนักงาน" (F-PER-004)** โดยระบุคุณสมบัติตาม Job Description (JD) ชัดเจน และเสนอผู้บริหารอนุมัติ
2. **การสัมภาษณ์งาน:** คณะกรรมการสัมภาษณ์ประกอบด้วย ฝ่ายบุคคล, ผู้จัดการแผนกต้นสังกัด, และผู้บริหารระดับสูง (กรณีระดับหัวหน้างานขึ้นไป)
3. **การปฐมนิเทศพนักงานใหม่:** พนักงานใหม่ทุกคนต้องผ่านการอบรมกฎระเบียบบริษัท กฎความปลอดภัย และนโยบายสิ่งแวดล้อมก่อนเริ่มงาน

## 3. การประเมินผลการทดลองงาน (Probation Evaluation)
- **รอบการประเมิน:**
  - สัญญาจ้างทดลองงาน 120 วัน: ประเมินผลเมื่อครบ **90 วัน** (ใช้แบบฟอร์ม F-PER-007)
  - สัญญาจ้างทดลองงาน 180 วัน: ประเมินผลเมื่อครบ **150 วัน**
- **กรณีไม่ผ่านทดลองงาน:** ฝ่ายบุคคลต้องแจ้งให้พนักงานทราบเป็นลายลักษณ์อักษรล่วงหน้าอย่างน้อย **30 วัน**

## 4. การโอนย้าย การประเมินประจำปี และการลาออก
- **การโอนย้าย (Transfer):** ต้องได้รับการอนุมัติจากทั้งแผนกเดิมและแผนกใหม่ (ใช้แบบฟอร์ม F-PER-025) จากนั้นฝ่ายบุคคลจะอัปเดตข้อมูลตำแหน่งและ Cost Center ในระบบ SAP
- **การประเมินประจำปี:** หัวหน้างานประเมินผลงานเพื่อพิจารณาปรับเงินเดือนและโบนัสประจำปี (F-PER-024)
- **การลาออก (Resignation):** พนักงานต้องยื่นใบลาออก **ล่วงหน้าอย่างน้อย 30 วัน** (F-PER-028) และส่งมอบทรัพย์สินคืนบริษัท (F-PER-029) 
  - *ข้อพึงระวัง:* หากละทิ้งหน้าที่ติดต่อกัน 3 วันทำงานโดยไม่มีเหตุอันควร จะถือว่าพ้นสภาพและถูกเลิกจ้างทันที

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบสมัครงาน, ใบขอพนักงาน, แบบประเมินทดลองงาน, ใบโอนย้าย, ใบลาออก (F-PER-002 ถึง 029)
- **ระยะเวลาการจัดเก็บ:** เอกสารประวัติพนักงานและการประเมินทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
