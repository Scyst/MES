# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมเอกสารด้านสิ่งแวดล้อม (Environmental Document Control)
**รหัสเอกสาร:** ESP-EMR-006 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนในการจัดทำ การอนุมัติ การควบคุม การแจกจ่าย และการทำลายเอกสารในระบบ ISO 14001:2015 ให้เป็นระเบียบและป้องกันการใช้เอกสารผิดเวอร์ชัน
- **ขอบเขต:** ครอบคลุมเอกสารคู่มือสิ่งแวดล้อม (EM), ระเบียบปฏิบัติงาน (ESP), วิธีการทำงาน (WI), แบบฟอร์ม (EF), และเอกสารจากภายนอกทั้งหมด

## 2. ระบบการประทับตราควบคุมเอกสาร
- **"ORIGINAL" (หมึกสีแดง):** ประทับกึ่งกลางด้านล่างของเอกสารต้นฉบับตัวจริง
- **"CONTROLLED COPY" (หมึกสีแดง):** ประทับด้านล่างซ้ายของเอกสารสำเนาที่แจกจ่ายให้แผนกต่างๆ (เอกสารควบคุม)
- **"UNCONTROLLED COPY" (หมึกสีน้ำเงิน):** ประทับบนเอกสารที่ไม่ต้องควบคุมการเรียกคืน (เช่น สำเนาให้ลูกค้าดู)
- **"OBSOLETED DOCUMENT" (หมึกสีแดง):** ประทับบนเอกสารฉบับเก่าที่ถูกยกเลิกแล้ว
- **"EXTERNAL DOCUMENT" (หมึกสีน้ำเงิน):** ประทับบนเอกสารที่รับมาจากภายนอก (เช่น กฎหมาย, คู่มือเครื่องจักร)

## 3. ขั้นตอนการขอจัดทำ / แก้ไข / ยกเลิกเอกสาร (DAR Workflow)
1. **ยื่นคำร้อง:** ผู้ขอเขียนแบบฟอร์ม **DAR (Document Action Request - EF-DCO-012)** ระบุเหตุผล และแนบฉบับร่าง
2. **การทบทวนและอนุมัติ:** ผู้จัดการแผนกทบทวน และเสนอตัวแทนฝ่ายบริหาร (EMR) อนุมัติ
3. **การแจกจ่ายและเรียกคืน (DCC):**
   - เจ้าหน้าที่ DCC แจกจ่ายเอกสารฉบับใหม่พร้อมบันทึกใน **EF-DCO-015**
   - **การเรียกคืนฉบับเก่า:** ต้องตามเก็บเอกสารฉบับเก่ากลับมาทำลาย (ฉีก/เข้าเครื่องทำลายเอกสาร) **ภายใน 1 วัน** หรือโดยเร็วที่สุด
4. **การทบทวนเอกสารประจำปี:** เจ้าของเอกสารต้องทบทวนความทันสมัยของคู่มือและขั้นตอนการทำงาน **ปีละ 1 ครั้ง ภายในเดือนมกราคมของทุกปี** (บันทึกใน EF-DCO-017)

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบ DAR (EF-DCO-012), Master List (EF-DCO-013), ผังแจกจ่าย (EF-DCO-014), ทะเบียนแจกจ่าย (EF-DCO-015), เอกสารภายนอก (EF-DCO-016), ใบรายงานทบทวนเอกสาร (EF-DCO-017)
- **ระยะเวลาการจัดเก็บ:** เอกสารควบคุมทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
