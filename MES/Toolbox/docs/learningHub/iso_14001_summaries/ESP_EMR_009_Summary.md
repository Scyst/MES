# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การวิเคราะห์และประเมินความเสี่ยงด้านสิ่งแวดล้อม (Environmental Risk and Opportunity Assessment)
**รหัสเอกสาร:** ESP-EMR-009 (Rev.03)
**วันที่ประกาศใช้:** 28/05/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดแนวทางในการวิเคราะห์และประเมินความเสี่ยง (ปัจจัยลบ) และโอกาส (ปัจจัยบวก) ในระบบสิ่งแวดล้อม เพื่อหามาตรการควบคุมให้อยู่ในระดับที่ยอมรับได้
- **ขอบเขต:** ครอบคลุมการวิเคราะห์ความเสี่ยงด้านสิ่งแวดล้อมในทุกระดับของบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน)

## 2. ลำดับขั้นการวิเคราะห์ความเสี่ยง 5 ระดับ (Risk Pyramid)
1. **ระดับองค์กร (Business Risk):** วิเคราะห์ SWOT ความอยู่รอดและภาพลักษณ์ธุรกิจ
2. **ระดับผู้มีส่วนได้ส่วนเสีย:** ความต้องการของลูกค้า ชุมชน และหน่วยงานรัฐ
3. **ระดับวัตถุประสงค์และเป้าหมาย (KPIs):** ความเสี่ยงที่จะทำให้ไม่บรรลุเป้าสิ่งแวดล้อม
4. **ระดับกระบวนการ (Process Approach):** วิเคราะห์ Input -> Process -> Output โดยใช้แผนภาพเต่า (Turtle Diagram - ปัจจัย 4M+1E)
5. **ระดับปัญหาสิ่งแวดล้อม (Environmental Aspects):** น้ำเสีย มลพิษทางอากาศ ขยะอันตราย

## 3. เกณฑ์การประเมินความเสี่ยง (Risk Matrix 5x5)
คำนวณจากสมการ `ความเสี่ยง = ผลกระทบ (Impact 1-5) x โอกาสเกิด (Likelihood 1-5)`:
- **ระดับต่ำ (Low: 1 - 3 คะแนน - สีเขียว):** ยอมรับได้ ไม่ต้องเพิ่มมาตรการ
- **ระดับปานกลาง (Medium: 4 - 9 คะแนน - สีเหลือง):** เฝ้าติดตามและควบคุมไม่ให้ความเสี่ยงขยับสูงขึ้น
- **ระดับสูง (High: 10 - 16 คะแนน - สีส้ม):** **มีนัยสำคัญ!** ต้องกำหนดมาตรการควบคุมและติดตามอย่างใกล้ชิด
- **ระดับวิกฤต (Extreme: 20 - 25 คะแนน - สีแดง):** **ยอมรับไม่ได้เด็ดขาด!** ต้องเร่งจัดทำแผนปฏิบัติการ (Action Plan) เพื่อลดความเสี่ยงโดยด่วน

## 4. การจัดทำแผนปฏิบัติการ (Action Plan)
- สำหรับความเสี่ยงที่มีนัยสำคัญ (คะแนนตั้งแต่ 10 ขึ้นไป) จะต้องจัดทำ **"แผนการจัดการความเสี่ยง (Action Plan - EF-DCO-037)"** กำหนดผู้รับผิดชอบและวันแล้วเสร็จ
- EMR จะติดตามผลการดำเนินงานและนำเสนอต่อที่ประชุมการทบทวนฝ่ายบริหารอย่างน้อย **ปีละ 1 ครั้ง**

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** แบบประเมินความเสี่ยงและโอกาส (EF-DCO-036), แผนการจัดการความเสี่ยง Action Plan (EF-DCO-037), แบบวิเคราะห์กระบวนการ (EF-DCO-038)
- **ระยะเวลาการจัดเก็บ:** เอกสารการประเมินความเสี่ยงทั้งหมดเก็บรักษาไว้เป็นเวลา **3 ปี**
