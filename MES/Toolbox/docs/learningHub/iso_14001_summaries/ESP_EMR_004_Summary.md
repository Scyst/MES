# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** วัตถุประสงค์และเป้าหมายด้านสิ่งแวดล้อม (Environmental Objectives and Targets)
**รหัสเอกสาร:** ESP-EMR-004 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการกำหนดวัตถุประสงค์และเป้าหมาย (KPIs) ด้านสิ่งแวดล้อมของแต่ละหน่วยงาน เพื่อขับเคลื่อนให้นโยบายสิ่งแวดล้อมขององค์กรประสบความสำเร็จเป็นรูปธรรม
- **ขอบเขต:** ครอบคลุมการจัดทำ การติดตามผล และการทบทวนเป้าหมายสิ่งแวดล้อมภายในบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน) และบริษัทในเครือ

## 2. ปัจจัยในการกำหนดวัตถุประสงค์และเป้าหมาย
คณะกรรมการสิ่งแวดล้อมจะพิจารณากำหนดเป้าหมายโดยอ้างอิงจาก 5 ปัจจัยหลัก:
1. **ประเด็นปัญหาสิ่งแวดล้อมที่มีนัยสำคัญ (Significant Aspects):** เช่น มลพิษน้ำเสีย, ปริมาณขยะอันตราย
2. **นโยบายสิ่งแวดล้อมของบริษัท:** ความมุ่งมั่นในการลดโลกร้อนและประหยัดพลังงาน
3. **เทคโนโลยีที่เหมาะสม:** เครื่องจักรหรือระบบบำบัดที่นำมาใช้ได้จริง
4. **งบประมาณการลงทุน:** ความคุ้มค่าทางเศรษฐศาสตร์
5. **กรอบระยะเวลา:** กำหนดเดดไลน์ที่ชัดเจน

## 3. ขั้นตอนการดำเนินงานและการติดตามผล (Workflow)
1. **การกำหนดเป้าหมายที่วัดผลได้:** เป้าหมายที่ตั้งขึ้น **ต้องสามารถวัดผลเป็นตัวเลขได้ชัดเจน (Measurable)** เช่น ลดการใช้พลังงานไฟฟ้าลง 5%, ลดปริมาณขยะอันตรายลง 10%
2. **การอนุมัติ:** เสนอให้กรรมการผู้จัดการ (MD) พิจารณาอนุมัติ
3. **การจัดทำแผนปฏิบัติการ (Action Plan):** แต่ละแผนกจัดทำ "แผนเพิ่มประสิทธิภาพการปฏิบัติงานประจำปี" (EF-DCO-007)
4. **การติดตามผลทุกไตรมาส:** หัวหน้าแผนกต้องทำรายงานสรุปความคืบหน้าของเป้าหมาย **ทุกๆ 3 เดือน (รายไตรมาส)** เพื่อประเมินว่าทำได้ตามแผนหรือไม่
5. **การทบทวนประจำปี:** นำผลการดำเนินงานตลอดทั้งปีเสนอต่อที่ประชุมการทบทวนฝ่ายบริหาร (Management Review) เพื่อปรับปรุงเป้าหมายสำหรับปีถัดไป

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** แผนเพิ่มประสิทธิภาพการปฏิบัติงานประจำปี (EF-DCO-007)
- **ระยะเวลาการจัดเก็บ:** เก็บรักษาไว้เป็นเวลา **5 ปี**
