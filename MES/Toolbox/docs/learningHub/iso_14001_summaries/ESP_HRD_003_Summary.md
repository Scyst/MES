# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การเฝ้าระวังและตรวจวัดสิ่งแวดล้อม (Environmental Monitoring and Measurement)
**รหัสเอกสาร:** ESP-HRD-003 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นมาตรฐานในการตรวจวัดและเฝ้าระวังกระบวนการหรือกิจกรรมที่อาจส่งผลกระทบต่อสิ่งแวดล้อม ให้มั่นใจว่าสอดคล้องกับกฎหมายสิ่งแวดล้อมและเป้าหมายขององค์กร
- **ขอบเขต:** ครอบคลุมการตรวจวัดสิ่งแวดล้อมและกิจกรรมการดำเนินงานของบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน) และบริษัทในเครือ

## 2. ขั้นตอนการดำเนินงาน (Workflow)
1. **จัดทำแผนการตรวจวัดสิ่งแวดล้อม:**
   - คณะกรรมการสิ่งแวดล้อมสรุปประเด็นด้านสิ่งแวดล้อม (Aspects) และข้อกำหนดทางกฎหมาย
   - จัดทำ **"แผนการติดตามผลตรวจวัดค่าด้านสิ่งแวดล้อม" (EF-DCO-033)** ระบุพารามิเตอร์, วิธีการตรวจ, จุดตรวจ, ความถี่, และเครื่องมือที่ใช้
   - เสนอให้ผู้ช่วยผู้จัดการ/ผู้อำนวยการตรวจสอบ และเสนอ MD อนุมัติ
2. **การตรวจวัดจริง:**
   - หากใช้บริการจากห้องปฏิบัติการภายนอก หน่วยงานนั้น **ต้องได้รับการรับรองอย่างถูกต้องจากทางราชการ (กรมโรงงานฯ)**
   - เครื่องมือตรวจวัดทุกชิ้นต้องมี **ใบรับรองผลการสอบเทียบ (Calibration Certificate)** ที่ยังไม่หมดอายุ
3. **การประเมินผลและการรายงาน:**
   - นำผลการตรวจวัดมาเปรียบเทียบกับเกณฑ์มาตรฐานทางกฎหมาย
   - ตัวแทนฝ่ายบริหาร (EMR) ทำการประเมินผลและสรุปรายงาน
4. **กรณีผลตรวจเกินมาตรฐานกฎหมาย (Exceeded Standards):**
   - ให้ปฏิบัติตามระเบียบการแก้ไขและป้องกัน (Corrective Action - ESP-HRD-002) โดยออก **ใบ NCR** เพื่อให้หน่วยงานที่เกี่ยวข้องเร่งปรับปรุงแก้ไขทันที

## 3. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** แบบฟอร์มแผนการติดตามผลตรวจวัดค่าด้านสิ่งแวดล้อม (EF-DCO-033) และรายงานผลการตรวจวัดจากแล็บ
- **ระยะเวลาการจัดเก็บ:** เอกสารและรายงานการตรวจวัดทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
