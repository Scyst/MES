# ◈ System Monitor Pro (v5.0)

การอัปเกรดเป็นระดับ Pro และการแพ็กเป็นไฟล์ `.exe` สำเร็จเรียบร้อยแล้วครับ! โปรแกรมนี้สามารถก็อปปี้ไปเปิดเครื่องไหนก็ได้ทันที 🚀

## มีอะไรใหม่ในเวอร์ชันนี้บ้าง?

> [!TIP]
> **ไฟล์รันโปรแกรมจะอยู่ที่:** `e:\MES\MES\MES\PerformanceMonitor\dist\SystemMonitorPro.exe` 
> คุณสามารถก๊อปปี้แค่ไฟล์นี้ไฟล์เดียวไปไว้ที่ไหนก็ได้ หรือส่งให้เพื่อนใช้ได้เลย!

### 1. 💾 Persistent Storage (ย้ายที่เก็บไฟล์ชั่วคราว)
เพื่อให้ไฟล์ `.exe` ทำงานได้สมบูรณ์แบบ ไฟล์ตั้งค่าและฐานข้อมูลทั้งหมดจะถูกเก็บไว้อย่างปลอดภัยที่ `%APPDATA%\SystemMonitor` (ซึ่งเป็นที่อยู่มาตรฐานของ Windows) จะไม่มีไฟล์แปลกๆ โผล่ขึ้นมาเกะกะโฟลเดอร์ที่คุณรัน `.exe` อีกต่อไป

### 2. 🗄️ SQLite History Database
โปรแกรมจะทำการบันทึกข้อมูล CPU, RAM และ GPU ลงฐานข้อมูลทุกๆ 10 วินาทีแบบเงียบๆ (ลบข้อมูลที่เก่ากว่า 7 วันทิ้งให้อัตโนมัติเพื่อไม่ให้หนักเครื่อง)

### 3. 🌐 Remote Web Dashboard
เมื่อคุณเปิด `SystemMonitorPro.exe` ไว้ โปรแกรมจะจำลองตัวเองเป็น Web Server ด้วย คุณสามารถเปิดเว็บบราวเซอร์ (Chrome/Edge) ในเครื่อง หรือแม้แต่มือถือที่ต่อ Wi-Fi เดียวกัน แล้วพิมพ์ URL นี้:
- `http://localhost:5000` (ดูบนเครื่องตัวเอง)
- `http://[IP-เครื่องคอม]:5000` (ดูผ่านมือถือ/เครื่องอื่น)

จะเจอหน้า Web Dashboard สไตล์ Cyberpunk ที่แสดงค่าแบบ Real-time!

### 4. 🚀 Auto-Start (เปิดพร้อม Windows)
คลิกขวาที่หน้าต่างโปรแกรม จะมีเมนูใหม่ชื่อ **"🚀 Run at Startup"** หากติ๊กถูกไว้ โปรแกรมจะสร้าง Shortcut ไปไว้ในโฟลเดอร์ Startup ของ Windows ทำให้เปิดคอมปุ๊บ โปรแกรมจะรันรอที่มุมจอปั๊บแบบอัตโนมัติ

---

## ขั้นตอนการทดสอบ

1. เข้าไปที่ `e:\MES\MES\MES\PerformanceMonitor\dist\`
2. ดับเบิลคลิกไฟล์ `SystemMonitorPro.exe`
3. ลองลากเปิดเบราว์เซอร์ไปที่ `http://localhost:5000` ดู Web Dashboard
4. ลองคลิกขวาที่โปรแกรมแล้วติ๊ก `Run at Startup` ดูครับ
