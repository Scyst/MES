👥 1. Manpower, Income Per Head & Grading (ระบบจัดการกำลังคนและประเมินผล)

Massive Overhaul

🎯 ปัญหา & เป้าหมาย

ข้อมูลค่าแรงขาดการวิเคราะห์เชิงลึก, การตั้งค่าเกณฑ์ประเมินรายไลน์ทำได้ยาก, HR ต้องคำนวณเงิน OT/DL ด้วยมือเมื่อมีการสลับกะ

✨ สิ่งที่พัฒนาสำเร็จ

  • Analytics Dashboard Modal: สร้าง Panel กราฟ 7 ตัว วิเคราะห์รายได้พนักงาน แยกเป็น Base (DL) และ OT อย่างชัดเจน พร้อม PIN ปกป้องข้อมูล (ใช้รหัสผ่านจริง)
  • Earned Value Calculation: เปลี่ยนจาก Mock Data มาคำนวณจาก Production Logs จริงๆ เพื่อให้ได้ "มูลค่า" ที่พนักงานผลิตได้จริง
  • Batch Operations: เพิ่ม Soft/Hard Reset กะทำงาน, Batch Approve, และ Auto Recalculation เมื่อมีการ Shift Swap
  • Criteria Management: เพิ่ม Dynamic criteria แบ่งตามสายการผลิต และฟังก์ชัน Batch Edit criteria ได้ทีเดียวทุกไลน์
  • Export & Performance: แก้ SQL เพื่อลดเวลาโหลดรายงาน (จาก >10s) และปรับ Excel ให้มี "Trend Matrix" สำหรับดูแนวโน้มรายได้หลายวัน
📈 Business Impact:

ผู้บริหารมี Dashboard ดูผลตอบแทนและความคุ้มค่าของพนักงานแบบ Real-time ข้อมูลแม่นยำขึ้น 100% ลดงาน HR ลงมหาศาล

🖥️ 2. System Monitor Pro (โปรแกรมมอนิเตอร์เซิร์ฟเวอร์แบบ Desktop)

New Application

🎯 ปัญหา & เป้าหมาย

ฝ่าย IT ขาดเครื่องมือ Lightweight สำหรับติดตามสถานะ Server และคอมพิวเตอร์ลูกข่ายแบบเรียลไทม์ที่รองรับ GPU

✨ สิ่งที่พัฒนาสำเร็จ

  • Tauri + React Stack: สร้าง Desktop App ขนาดเล็กและเร็ว
  • Advanced UI Modes: รองรับ Window Mode, Widget Mode, และ Mini Mode พร้อม Modern Theme (Glassmorphism) สลับได้ทันที
  • Comprehensive Metrics: ดึงข้อมูล CPU (แบ่งราย Core), RAM, DISK, NET และ **GPU (Nvidia/WMIC)**
  • History Area Charts: แสดงกราฟย้อนหลัง (Timeframe Selection)
  • OS Notifications: แจ้งเตือนทันทีเมื่อระบบใช้ทรัพยากรเกินลิมิต
📈 Business Impact:

IT สามารถเฝ้าระวัง Server และเครื่องตามไลน์ผลิตได้สะดวกขึ้นผ่าน Widget บนหน้าจอ ไม่ต้องเปิด Task Manager ทิ้งไว้

⚙️ 3. PE & Safety System (ระบบซ่อมบำรุงและความปลอดภัย)

Safety Initiative

🎯 ปัญหา & เป้าหมาย

ต้องการนำระบบ LOTO (Lockout/Tagout) มาใช้จริง, ลดเอกสารกระดาษในการตรวจความปลอดภัย, และแก้ปัญหาคอมค้าง

✨ สิ่งที่พัฒนาสำเร็จ

  • Pre-Op Dynamic Checklists: สร้างหน้า Dashboard สำหรับจัดการฟอร์ม Checklist ตรวจสอบเครื่องจักรก่อนเริ่มงาน
  • E-LOTO (Phase 2): สร้าง API ล็อก/ปลดล็อกเครื่องจักร เพิ่มปุ่ม "Apply LOTO" และ Badge เตือนสถานะกระจายในทุกๆ หน้า (Kanban, Machine Lists)
  • Printable Visual Boards: สร้างเครื่องมือ Gen การ์ดและป้าย Visual Management พิมพ์ใช้งานได้ทันที
  • Quick Hazard Report: ปรับ UI การแจ้งเหตุอันตรายให้ใช้งานง่ายเหมือนใน Mobile App
  • Memory Leak Fix: ใช้ Page Visibility API หยุดรันกราฟเบื้องหลัง แก้ Chrome แดก RAM 7.8GB
📈 Business Impact:

ยกระดับความปลอดภัย (Zero Accident Goal) ด้วยระบบ E-LOTO และ Checklist Digital ลดอุบัติเหตุและแก้ปัญหาโปรแกรมค้าง
