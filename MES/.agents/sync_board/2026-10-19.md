### Thermal Printer (Honeywell PC42E-T Barcode & QR Density Calibration)
- **เวลาทำงาน (Time)**: 08:56 - 09:05
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: ผู้ใช้งานสังเกตว่า Barcode ใน ZPL ยังสั้นและไม่เต็มความกว้างเหมือนสติ๊กเกอร์จริง และสอบถามว่าทำไม QR Code ถึงรู้สึกว่าไม่ละเอียดเท่าตัวจริง หรือเป็นเพราะภาพจำลอง
- **สิ่งที่แก้ไขไป (What)**:
  1. ถอดรหัส (Decode) ข้อมูล QR Code และบาร์โค้ดจากภาพสติ๊กเกอร์ของจริง พบว่าข้อมูลคือ `70737-1026-432/864` (18 ตัวอักษร)
  2. วิเคราะห์สาเหตุที่ QR Code รู้สึกไม่ละเอียด: ใน ZPL เดิมใช้โหมด Error Correction M อัตโนมัติ ทำให้ได้ตาราง Version 1 เพียง 21 × 21 โมดูล (สี่เหลี่ยมแต่ละช่องมีขนาดใหญ่ถึง 11 dots) ในขณะที่สติ๊กเกอร์จริงเป็นตาราง Version 2 ที่ 25 × 25 โมดูล จึงปรับ ZPL เป็น `^FDQA,${scanId}^FS` (Error Correction ระดับ Q - 25%) ขนาด `Mag=9` ทำให้ได้ตาราง 25 × 25 โมดูล แต่ละจุดมีขนาด 9 dots เนียน ละเอียด และแน่นเท่าของจริง 100%
  3. ปรับขนาด Barcode: ปรับความสูงเป็น 54 dots (`^BY2,2,54^BCN,54,N,N,N`) เริ่มที่พิกัด `Y = 280` ทำให้บาร์โค้ดยาวถึง `X = 495 dots` เต็มพื้นที่ใต้ตาราง ไม่เหลือช่องว่างโล่งแบบเดิม
  4. อัปเดตรูปพรีวิว `page/production/images/label_preview_4x2.png` และอัปโหลดไฟล์ `page/production/script/thermalPrinter.js` ขึ้น FTP

### LearningHub (Smart Hybrid Access: โหมดผู้เยี่ยมชมปลอดภัย + ซิงค์การออกจากระบบ MES แบบเรียลไทม์)
- **เวลาทำงาน (Time)**: 10:25 - 10:44
- **ปัญหา / สิ่งที่ต้องทำ (Why)**:
  1. ผู้ใช้งานสังเกตว่าเมื่อออกจากระบบหลัก MES แล้ว ตัวระบบ MES Learning Hub ยังคงจำชื่อผู้ใช้งานเดิมใน `localStorage` และไม่ยอมออกจากระบบตาม
  2. ผู้ใช้งานต้องการแนวทางสายกลาง (Smart Hybrid Access) ที่อนุญาตให้ผู้เยี่ยมชมที่ได้รับลิงก์สามารถเข้าอ่านหลักสูตรมาตรฐานทั่วไปได้อิสระโดยไม่ต้องล็อกอิน แต่ต้องปกป้องข้อมูลความลับภายในโรงงานและข้อมูลส่วนบุคคลของพนักงาน (PDPA / 405 พนักงาน / 4D Grading / Audit Matrix / Community Hub) ไม่ให้รั่วไหลเมื่อไม่ได้ล็อกอิน
- **สิ่งที่แก้ไขไป (What)**:
  1. **ซิงค์การออกจากระบบแบบเรียลไทม์ (Real-Time Logout Sync):** ปรับปรุง `fetchRealUserSession()` ใน `communityStore.js` และ `Navbar.jsx` (รวมถึงตรวจจับ Event `focus` และ `visibilitychange` เวลาสลับแท็บกลับมา) เมื่อตรวจพบว่า `$_SESSION['user']` ในระบบหลักว่างเปล่า (`authenticated: false`) จะล้างข้อมูลผู้ใช้และเกรดที่ค้างใน `localStorage` ทันที และสลับเป็น `ผู้เยี่ยมชม (Guest)` พร้อมเพิ่มปุ่มกดออกจากระบบ (`Logout`) บนแถบเมนูขวาบน
  2. **ป้องกันระดับ Backend API (`page/manpower/api/api_learning.php`):** บล็อกการเรียกดูรายชื่อพนักงาน (`get_employees`), สมุดพกสมรรถนะและเกรด 4 มิติ (`get_employee_passport`), ตารางออดิท (`get_audit_matrix`) และการบันทึกผลสอบลงฐานข้อมูล (`save_course_progress`) ทันทีหากไม่มี `$_SESSION['user']`
  3. **แยกสิทธิ์การเข้าถึงระดับ Frontend (`AuthRequiredGate.jsx`, `App.jsx`, `Catalog.jsx`):**
     - เปิดให้เข้าอ่าน **หลักสูตรมาตรฐาน (`/` และ `/course/:courseId`)** ได้อิสระในโหมดผู้เยี่ยมชม พร้อมแบนเนอร์แจ้งสถานะและปุ่มลัดเข้าสู่ระบบ MES
     - ล็อกหน้าข้อมูลภายในทั้งหมด (`/community*`, `/ranks`, `/audit`, `/profile*`, `/admin/course-builder`) ด้วยหน้าต่าง `AuthRequiredGate` ที่แจ้งเตือนให้ยืนยันตัวตนผ่านระบบ MES ก่อนเข้าถึง
- **ผลลัพธ์ (Result)**: เมื่อออกจากระบบหลัก MES ระบบ Learning Hub จะตัดเซสชันเป็นโหมดผู้เยี่ยมชมทันที ข้อมูลพนักงานและตารางออดิทถูกปกป้องทั้งฝั่ง Frontend และ Backend ในขณะที่ผู้เยี่ยมชมยังสามารถอ่านหลักสูตรมาตรฐานทั่วไปได้อย่างปลอดภัย
