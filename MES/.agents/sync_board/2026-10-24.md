### LearningHub (Fix SQL Error: Invalid Column 'description' in SKILL_DEFINITIONS & Smart Reconcile)
- **เวลาทำงาน (Time)**: 08:40 - 08:48 24/10/26
- **ปัญหา / สิ่งที่ต้องทำ (Why)**:
  - ผู้ใช้งานพบ Error 400 Bad Request จำนวน 4 ครั้ง เมื่อเข้าสู่ระบบที่ Endpoint `api_learning.php?action=save_course_progress`
  - ข้อความข้อผิดพลาด: `SQLSTATE[42S22]: [Microsoft][ODBC Driver 17 for SQL Server][SQL Server]Invalid column name 'description'.`
  - สาเหตุ:
    1. ในฟังก์ชัน `save_course_progress` ของ `page/manpower/api/api_learning.php` เมื่อบันทึกคอร์สที่ยังไม่มีรหัสทักษะใน `dbo.SKILL_DEFINITIONS` มีการเรียก `INSERT INTO dbo.SKILL_DEFINITIONS` โดยระบุคอลัมน์ `description` ซึ่งไม่มีอยู่ในโครงสร้างจริงของตาราง (โครงสร้างจริงใช้ `line`)
    2. ในฝั่ง Frontend `communityStore.js` มีฟังก์ชัน `reconcileLocalLiveRecordsWithBackend` ที่สั่งบันทึกผลการเรียนที่ค้างอยู่ในเครื่องขึ้น Server แต่เดิมไม่ได้เช็กว่าคอร์สไหนมีอยู่บนฐานข้อมูลแล้ว ทำให้ส่งคำขอซ้ำ
- **สิ่งที่แก้ไขไป (What)**:
  - **Schema Alignment:** แก้ไขคำสั่ง SQL ใน `api_learning.php` ตัดคอลัมน์ `description` ออกและใส่ค่า `line = 'ALL'` พร้อมเพิ่ม Fallback คิวรี `skill_id` จาก `dbo.SKILL_DEFINITIONS`
  - **Pre-register Skills:** นำรายชื่อทักษะของ 7 หลักสูตร Industry 4.0 เข้าสู่ `dbo.SKILL_DEFINITIONS` (skill_id 15 ถึง 21) ครบถ้วน
  - **Frontend Smart Reconcile:** อัปเดต `reconcileLocalLiveRecordsWithBackend` ใน `communityStore.js` ให้ตรวจสอบกับ `backendCourses` ล่วงหน้า หากมีอยู่ในระบบแล้วให้แปลงสถานะเป็น `rec-db-*` ทันที และเมื่อส่งสำเร็จให้ปรับเป็น `rec-db-*` เพื่อป้องกันการยิง Request ซ้ำซ้อน
  - **Build & Deploy:** บิลด์ Vite สำเร็จ 100% และอัปโหลดไฟล์ `api_learning.php` และ `dist` ขึ้น Production FTP Server
- **ผลลัพธ์ (Result)**:
  - ข้อผิดพลาด Bad Request 400 หายขาด 100% ระบบสามารถซิงค์และบันทึกประวัติการอบรมเข้าสู่ SQL Server และ Matrix ทักษะได้อย่างราบรื่น
