  3. **ปรับแท็บใน Modal ให้กระชับ:** ย่อข้อความแท็บเป็น `Chrome Kiosk`, `Direct ZPL`, และ `ตัวอย่างฉลาก` ทำให้วางเรียงกันในแถวเดียวได้อย่างสวยงาม ไม่กินพื้นที่แนวตั้งและไม่ล้นจอ
  4. **ระบบ Auto-reconnect USB:** เพิ่มฟังก์ชัน `tryAutoReconnectUsb()` ใน `thermalPrinter.js` ตรวจจับและกู้คืนการเชื่อมต่อพอร์ต USB อัตโนมัติเมื่อเปิดหน้าเว็บ

- **สิ่งที่แก้ไขไป (What)**:

  2. **สถาปัตยกรรมพิมพ์แท็กแบบรวมศูนย์ (`executePrintTags`):** ปรับปรุง `rmReceiving.js` ให้ตรวจสอบการเชื่อมต่อ Web Serial USB หากเชื่อมต่อจะส่งคำสั่ง ZPL ตรงเข้าหัวพิมพ์ Honeywell PC42E-T ทันที แต่หากไม่มี USB จะสลับไปใช้ `renderPrintTags()` ร่วมกับ `window.print()` (รองรับโหมด Silent ผ่าน Chrome `--kiosk-printing` หรือ Browser Print Dialog ปกติ) ป้องกันผลกระทบต่อผู้ใช้งานเดิม 100%
  3. **ครอบคลุมทุกจุดพิมพ์ของสโตร์:** ใช้งานฟังก์ชันกลางทั้งในการพิมพ์เดี่ยว (`printSingleTag`), พิมพ์ที่เลือก (`printSelectedTags`), จัดพาเลทรวม (`groupToMasterPallet`), พิมพ์พาเลทซ้ำในสแกนเนอร์ (`reprintMasterPallet`), และการสร้างแท็กจาก Manual Add / Import Excel
  4. **ปรับปรุง UI Toolbar & Modal:** เพิ่มปุ่มกะทัดรัด `[ ⚡ พิมพ์ด่วน ]` บน Toolbar (แสดงเป็นไอคอน ⚡ บนมือถือ ไม่เบียดช่องค้นหา) พร้อมจุดเขียว USB และเมนูใน 3 จุด พร้อมหน้าต่าง `#thermalPrinterModal` 3 แท็บ (Chrome Kiosk, Direct ZPL, ตัวอย่างฉลาก RM)
  5. **Auto-Reconnect USB:** ตรวจสอบและกู้คืนการเชื่อมต่อ USB Serial อัตโนมัติเมื่อเปิดหน้าเว็บ
