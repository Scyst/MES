  3. เพิ่มแถบเลือกทั้งหมดบนมือถือ (`#mobileSelectAllBar`) พร้อม Checkbox และป้ายนับจำนวนรายการ (`X รายการ (เลือก Y)`) ซึ่งรองรับสถานะ Indeterminate (`[-]`) เมื่อเลือกบางส่วน

### Production Tag Printer (เชื่อมต่อ Thermal Printer ZPL/Kiosk เข้าจอจริง + ปรับ UI กะทัดรัด)
- **เวลาทำงาน (Time)**: 08:35 - 08:45
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: ผู้ใช้งานต้องการเชื่อมต่อโมดูล Thermal Label Printer เข้ากับหน้าจอจริง และสอบถามถึงผลกระทบต่อระบบการพิมพ์เดิม พร้อมทั้งขอปรับลดข้อความของปุ่ม "โหมดพิมพ์ด่วน" ที่ยาวเกินไปบน Card Header และปรับข้อความในแท็บของ Modal ให้สั้นลงเพื่อประหยัดพื้นที่หน้าจอ
- **สิ่งที่แก้ไขไป (What)**:
  1. **สถาปัตยกรรม Fallback Hierarchy ไม่กระทบการพิมพ์เดิม 100%:** ปรับปรุง `executeHiddenPrint()` ใน `label_printer.js` ให้ตรวจสอบสถานะการเชื่อมต่อ USB ZPL ก่อน หากเชื่อมต่ออยู่จะรวมชุดคำสั่ง ZPL ส่งตรงเข้าเครื่องพิมพ์ USB แบบ Batch ทันที แต่หากไม่ได้ต่อ USB หรือมีข้อผิดพลาด ระบบจะสลับไปใช้การพิมพ์มาตรฐานของเบราว์เซอร์ (`window.print()`) เหมือนเดิมทุกประการ (รองรับทั้งโหมด Silent ผ่าน Chrome Kiosk และ Print Dialog ปกติ)
  2. **ปรับปุ่ม Header กะทัดรัด:** เปลี่ยนข้อความปุ่มจาก "โหมดพิมพ์ด่วน (ZPL/Kiosk)" เป็น `"⚡ พิมพ์ด่วน"` พร้อม Badge จุดแสดงสถานะ USB สีเขียวเมื่อตรวจพบการเชื่อมต่อ
  3. **ปรับแท็บใน Modal ให้กระชับ:** ย่อข้อความแท็บเป็น `Chrome Kiosk`, `Direct ZPL`, และ `ตัวอย่างฉลาก` ทำให้วางเรียงกันในแถวเดียวได้อย่างสวยงาม ไม่กินพื้นที่แนวตั้งและไม่ล้นจอ
  4. **ระบบ Auto-reconnect USB:** เพิ่มฟังก์ชัน `tryAutoReconnectUsb()` ใน `thermalPrinter.js` ตรวจจับและกู้คืนการเชื่อมต่อพอร์ต USB อัตโนมัติเมื่อเปิดหน้าเว็บ
- **ผลลัพธ์ (Result)**: หน้าจอสร้างแท็กมีความสะอาด สบายตา ฟังก์ชันพิมพ์ด่วนเชื่อมต่อเข้ากับระบบจริงโดยสมบูรณ์ และไม่มีผลกระทบต่อผู้ใช้งานที่ใช้การพิมพ์แบบเดิม
- **ไฟล์ที่แก้ไข (Files Modified)**:
  - `page/production/label_printer.php`
  - `page/production/script/label_printer.js`
  - `page/production/script/thermalPrinter.js`
