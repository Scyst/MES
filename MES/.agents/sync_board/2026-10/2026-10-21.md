### Core_Auth (Bug Fix - Logout Redirect 404 & Base URL Resolution)
- **เวลาทำงาน (Time)**: 19:30 - 19:45 21/10/26
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: ตรวจสอบพบหน้าเว็บอย่าง `label_printer.php` เมื่อกด Logout หรือเซสชันหมดอายุ จะถูกเปลี่ยนเส้นทางไปยัง `https://oem.sncformer.com/MES/MES/auth/login_form.php?redirect=...` ซึ่งติด 404 Not Found เนื่องจากสภาพแวดล้อม Production ทำงานอยู่ภายใต้ Subpath `/iot-toolbox/sandbox-b9/MES/MES` ไม่ใช่ `/MES/MES` ที่ Root โดเมน และบางหน้าไม่ได้เรียกใช้ `config.php` ทำให้ `BASE_URL` ไม่ถูกนิยามแล้วตกไปใช้ค่า Fallback ผิดพลาด
- **สิ่งที่แก้ไขไป (What)**:
  1. เพิ่มฟังก์ชัน `getMesBaseUrl()` ใน `auth/check_auth.php`, `auth/logout.php`, และ `page/components/common_head.php` พร้อมโหลด `config.php` อัตโนมัติหาก `BASE_URL` ยังไม่ถูกนิยาม และคำนวณ Path ไดนามิกจาก `$_SERVER['SCRIPT_NAME']`
  2. แก้ไข `appCore.js` ในฟังก์ชัน `resolveMesBaseUrl()` ให้ดึง Base URL จริงจาก `window.location.pathname` อัตโนมัติ (รองรับ Subpath ทุกประเภท) และอัปเดต Event Listener ของปุ่ม `.logout-action` ให้ยิงไปยัง Base URL ที่ถูกต้องแทนการอ้างอิง Href ดิบ
  3. แก้ไขจุดดักจับ 401 ใน `common_head.php`, `sendRequest.js`, และ `apiClient.js` ให้มี Fallback Redirect ที่คำนวณ Base URL ถูกต้องเสมอ แม้ในขณะที่สคริปต์หลักยังโหลดไม่เสร็จ
  4. ปรับปรุง `top_header.php` และ `nav_dropdown.php` ให้ใช้ `getMesBaseUrl()` แทนฮาร์ดโค้ด `/MES/MES`
  5. อัปโหลดไฟล์ที่แก้ไขทั้งหมดขึ้น Remote Production FTP และทดสอบ HTTP Request ยืนยันการทำงานจริง
- **ผลลัพธ์ (Result)**: การ Logout และการดีดออกจากระบบเมื่อเซสชันหมดอายุทำงานได้ถูกต้อง 100% เปลี่ยนเส้นทางไปยังหน้า Login Form พร้อมเก็บบันทึก Redirect กลับมายังหน้าเดิมอย่างสมบูรณ์ ไร้ปัญหา 404
