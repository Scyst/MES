### PE_Request (UI Layout Fix & Tab Renaming)
- **เวลาทำงาน (Time)**: 08:30 - 17:00
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: หน้าต่างแท็บ Hazard ในมือถือขยายไม่เต็มจอ (มีพื้นที่ว่างด้านล่าง) และปุ่ม "แตะถ่ายรูป" เล็กเกินไป รวมถึงชื่อแท็บยาวเกินไปจนตกขอบ
- **สิ่งที่แก้ไขไป (What)**: 
  - แก้ไขปัญหา CSS Flexbox โดยปรับให้ `.app-card` สำหรับ `hazardForm` มี `min-height: calc(100vh - 270px)` เพื่อให้ยืดเต็มพื้นที่พอดีโดยไม่ดันปุ่ม Submit ตกขอบล่าง
  - สั่งให้ปุ่ม "แตะถ่ายรูป" (`.camera-btn`) ยืดตัว (`flex-grow: 1`) เพื่อเติมเต็มพื้นที่ว่างทั้งหมด ทำให้ปุ่มมีขนาดใหญ่ขึ้นและกดง่ายบนมือถือ
  - เปลี่ยนชื่อแท็บใน Bottom Navigation จาก "Pre-Op" เป็น "ก่อนเริ่ม" และ "Hazard" เป็น "จุดเสี่ยง" เพื่อความกระชับและเข้าใจง่าย
- **ผลลัพธ์ (Result)**: หน้าจอแสดงผลเต็มหน้าจอโดยไม่มีพื้นที่ว่างเปล่าด้านล่าง ปุ่มกล้องขยายใหญ่กดง่ายขึ้น และเมนูด้านล่างแสดงชื่อแท็บภาษาไทยได้พอดี ไม่ล้นจอ
- **ไฟล์ที่แก้ไข (Files Modified)**: `peRequest.php`, `peRequest.css`

### Store Management (Material Request Modal UX)
- **เวลาทำงาน (Time)**: 12:00 - 12:15
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: ผู้ใช้งานต้องการให้แสดงเลขพาเลท (Pallet) และเลขกล่อง (CTN) ใน Modal เลือกแท็กสินค้าคงคลังของหน้าเบิกจ่าย โดยให้ข้อมูลดูเป็นระเบียบ ไม่เบียดกัน
- **สิ่งที่แก้ไขไป (What)**: 
  - ดึงข้อมูล `pallet_no` และ `ctn_number` มาจาก API และนำมาแสดงผลร่วมกับ `location_name` และวันที่รับเข้า
  - ขยายความกว้าง Modal จาก 500px เป็น 650px เพื่อเพิ่มพื้นที่แสดงผล
  - ปรับใช้ Flexbox จัดเลย์เอาต์ข้อความแยกเป็น 2 บรรทัด (เลข Serial ด้านบน และส่วนรายละเอียดมี Icon คั่นด้านล่าง) เพื่อให้อ่านง่าย
- **ผลลัพธ์ (Result)**: ผู้ใช้งานสามารถมองเห็นเลขพาเลทและกล่องได้ทันทีตอนจะเบิกของ ทำให้ทำงานง่ายขึ้นและ UI ดูเป็นระเบียบมากขึ้น
- **ไฟล์ที่แก้ไข (Files Modified)**: `api_store.php`, `materialReq.js`
