### PaintChem UI (Bug Fix: Table View Hover Glitch)
- **เวลาทำงาน (Time)**: 16:39 - 16:50
- **ปัญหา / สิ่งที่ต้องทำ (Why)**: ผู้ใช้พบปัญหาใน Table View เมื่อคลิกเลือกช่วงเวลาใหม่ (Column) ช่วงเวลาเก่าที่เคยเลือกไว้ยังมีสีพื้นหลังสีน้ำเงินค้างอยู่ เหมือนลืมปิด Hover
- **สิ่งที่แก้ไขไป (What)**: 
  1. วิเคราะห์พบว่าเป็นปัญหา Browser Repaint / CSS Transition ของ Tailwind บน Table Header เมื่อลบ Class สีน้ำเงินออกแต่ไม่ได้กำหนดสีพื้นฐานกลับ เบราว์เซอร์บางตัว (รวมถึง Text Selection) จะค้างสีเดิมไว้
  2. บังคับใส่ Class `bg-transparent text-gray-700 dark:text-gray-200` สำหรับสถานะที่ไม่ได้ถูกเลือก เพื่อล้างสีเก่าออกอย่างเด็ดขาด
  3. ถอด `transition-colors` ออกจากหัวตารางเพื่อแก้ปัญหาแอนิเมชันสีค้าง และลบโอกาสการเกิดบัคของ Webkit/Blink
  4. เพิ่ม `select-none` ควบคุมเพื่อไม่ให้เกิดการเผลอคลุมดำตัวอักษรแล้วเข้าใจผิดว่าเป็นสีพื้นหลัง
- **ผลลัพธ์ (Result)**: สีพื้นหลังแสดงผลได้ถูกต้องและ Active เฉพาะ Column ที่เลือกอยู่จริงๆ อาการสีค้างหายไป
