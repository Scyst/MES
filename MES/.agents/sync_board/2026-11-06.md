### AI Copilot (External Web Search & Multimodal Industrial Vision Integration)
- **เวลาทำงาน (Time)**: 08:00 - 08:25
- **ปัญหา / สิ่งที่ต้องทำ (Why)**:
  1. ผู้ใช้ต้องการให้ระบบ MES AI Copilot สามารถ "ท่องเน็ต" เพื่อดึงข้อมูลสดจากภายนอกโรงงานได้ (เช่น ราคากลางสินค้าโภคภัณฑ์ เหล็ก HRC, อลูมิเนียม, ก๊าซ LPG, อัตราแลกเปลี่ยน, และคู่มือแก้ Alarm/Error Code เครื่องจักร)
  2. ต้องการระบบวิเคราะห์ภาพถ่าย (AI Vision & Multimodal) สำหรับส่งภาพชิ้นงานเสีย (Defects), รอยเชื่อม, งานพ่นสี หรือภาพหน้าจอ Error ของเครื่องจักรเข้าช่องแชท ให้ AI วินิจฉัยประเภท Defect และวิเคราะห์หาสาเหตุรากเหง้า (Root Cause)
  3. ให้ความกระจ่างเกี่ยวกับระบบแจ้งเตือนผ่าน LINE: อธิบายว่า LINE Notify ยุติให้บริการแล้ว (มีนาคม 2025) แต่ LINE Official Account (LINE OA) Messaging API ยังมี Free Tier (ฟรี 300-500 ข้อความ/เดือน) หรือเทคนิค Webhook Reply ฟรีไม่จำกัด รวมถึงทางเลือกฟรี 100% อื่นๆ เช่น Telegram Bot API, Discord Webhook และ Email
- **สิ่งที่แก้ไขไป (What)**:
  1. **External Web Search Engine (`morningBriefTools.php`)**:
     - สร้างฟังก์ชัน `queryExternalWebSearch(string $query, ?string $category)` ดึงข้อมูลสดผ่าน HTTPS cURL พร้อม Sanitization กรองคำค้นหาเพื่อป้องกัน Data Leakage และ SSRF
     - ประกาศเครื่องมือ `search_external_web` ใน Function Calling ให้ AI สามารถตัดสินใจค้นหาเว็บภายนอกได้โดยอัตโนมัติเมื่อผู้ใช้ถามเรื่องราคาตลาด หรือ Alarm เครื่องจักร
  2. **Multimodal Vision Engine (`morningBriefAi.php`)**:
     - เพิ่มตัวจัดการรับข้อมูลภาพถ่าย Base64 (JPEG, PNG, WebP) ขนาดสูงสุด 8MB
     - ผสาน `inlineData` ส่งตรงเข้า Gemini Vision พร้อม System Instruction เจาะลึกการวิเคราะห์ข้อบกพร่องทางวิศวกรรมการผลิต (Welding, Surface, Paint, Machine Screens)
  3. **Interactive Camera & Image Upload UI (`GlobalAiAssistant.jsx` & `aiCopilotApi.js`)**:
     - เพิ่มปุ่มกล้อง/แนบภาพถ่าย (📷 Camera Button) ข้างกล่องข้อความ
     - รองรับการกด **Ctrl+V (Paste)** วางภาพจาก Clipboard ลงในช่องแชทได้ทันที
     - เพิ่มแถบแสดงรูปขนาดย่อ (Image Preview Thumbnail) พร้อมปุ่มลบ (X) ก่อนส่ง
     - แสดงรูปภาพที่ผู้ใช้แนบภายใน Bubble แชท พร้อมคลิกเปิดดูภาพขนาดเต็มได้
     - เพิ่มชิปคำแนะนำด่วนด้านการท่องเน็ตและวิเคราะห์ภาพถ่าย
