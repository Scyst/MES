### Learning_Hub (UI Polish - Teaching Kit Header High-Contrast Light/Dark Adaptive Colors)
- **เวลาทำงาน (Time)**: 13:35 - 14:15
- **ปัญหา / สิ่งที่ต้องทำ (Why)**:
  - ในหน้าต่างคู่มือวิทยากร 4 วัน (TrainerGuideModal / EnterpriseTeachingKitHub) เมื่อเปิดในโหมดสว่าง (Light Mode) ตัวอักษรหัวข้อ "การออกแบบ พัฒนา และบูรณาการแอปพลิเคชันระดับองค์กร (Enterprise Application)" กลืนเป็นสีดำเข้มบนพื้นหลังสีม่วงเข้ม/มารูน ทำให้มองไม่เห็นข้อความ รวมถึงข้อความเมตาดาต้าและแท็กหัวข้อย่อยมีคอนทราสต์ต่ำ
- **สิ่งที่แก้ไขไป (What)**:
  1. วิเคราะห์ Root Cause พบว่า `index.css` บังคับให้หัวข้อ `h2` ใน `.theme-light` มีสี `#0f172a !important` และแปลง `.text-slate-300` เป็นสีเข้ม แต่ตัวกล่อง Banner ใช้คลาสพื้นหลังแบบ Deep Palette Gradient (`from-rose-950`) ซึ่งไม่อยู่ในรายการแปลงเป็น Light Theme ของ CSS
  2. ปรับปรุง `EnterpriseTeachingKitHub.jsx`: เชื่อมต่อกับ `useTheme()` และปรับกล่อง Banner ด้านบนให้เป็น Theme-Adaptive Card
     - **ในโหมดสว่าง (Light Mode):** ใช้พื้นหลังเกรเดียนต์โทนสว่างนุ่มนวล (`from-rose-50 via-purple-50 to-indigo-50`), ตัวหนังสือหัวข้อสีดำเข้มคมชัด (`text-slate-900 font-black`), เมตาดาต้าสีเทาเข้ม (`text-slate-700`), และป้ายแท็กแบบ Light Pills คอนทราสต์สูง
     - **ในโหมดมืด (Dark Mode):** ใช้เกรเดียนต์นีออนอุตสาหกรรม (`from-rose-950/90 via-slate-900 to-indigo-950/90`), ตัวหนังสือหัวข้อสีขาวสว่าง (`text-white`), และป้ายแท็กสีเรืองแสง
  3. ปรับ `index.css`: เพิ่ม `[class*="from-rose-950"]` ในรายการแปลงสี Light Theme และเพิ่มคลาสคุ้มครองความคมชัด `.teaching-kit-banner` ป้องกันไม่ให้ตัวหนังสือกลืนกับพื้นหลัง 100%
  4. บิลด์โปรดักชัน (`npm run build`), อัปโหลดขึ้น FTP (`/LearningHub`), และรันการทดสอบภาพถ่ายหน้าจออัตโนมัติผ่าน Puppeteer ทั้งโหมดสว่างและโหมดมืด
- **ผลลัพธ์ (Result)**:
  - แบนเนอร์หัวข้อคู่มือวิทยากรอ่านง่าย คมชัด 100% สวยงามทั้งในโหมดสว่างและโหมดมืด ไร้ปัญหาตัวหนังสือมืดกลืนกับพื้นหลัง
