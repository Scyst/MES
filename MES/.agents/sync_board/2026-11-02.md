- **สิ่งที่แก้ไขไป (What)**:
  1. **Smart Multi-Tab Targeting (`tools/ai-tester/browser.mjs`, `tester.mjs`)**: เพิ่มคำสั่ง `tabs` แสดงรายการแท็บทั้งหมดพร้อม Index/URL และระบบเจาะจงแท็บเป้าหมาย (`--target="keyword"` หรือ `--tab=N`) ป้องกันไม่ให้ Agent แตะโดนแท็บอื่นในขณะที่ผู้ใช้งานทำงานขนานกันหลายหน้าต่าง
  2. **Hardware Barcode Simulator**: เพิ่มคำสั่ง `barcode` จำลองการยิงบาร์โค้ดแบบ Keystroke Stream (หน่วงเวลา ~15ms ต่อตัวอักษร) พร้อมส่ง Suffix `Enter`/`Tab` เข้าสู่หน้าจออัตโนมัติ
  3. **Factory Network Throttling / Offline**: คำสั่ง `network` จำลองสภาวะเครือข่ายโรงงาน (Offline, Slow 3G, Fast 3G, Online) ผ่าน CDP เพื่อทดสอบตามมาตรฐาน Offline Resilience
  4. **Multi-Device Responsive Matrix**: คำสั่ง `matrix` บันทึกภาพหน้าจอ 3 ขนาดพร้อมกันในคลิกเดียว (Smartphone 375px, Factory Tablet 768px, Industrial Terminal 1920px) ตรวจสอบการล้นจอและขนาดปุ่ม Touch target
  5. **SQL Server 2016 Lock Inspector (`tools/sql-inspector/inspector.mjs`)**: เครื่องมือตรวจจับ Query เสี่ยง Table Lock, ตรวจสอบ NOLOCK, SELECT *, และการจำกัดผลลัพธ์ Pagination เพื่อป้องกันฐานข้อมูลโรงงานค้าง
