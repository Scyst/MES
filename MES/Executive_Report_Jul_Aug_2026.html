⚙️ 1. PE Enterprise & IIoT Systems (ระบบซ่อมบำรุงและโรงงานอัจฉริยะ)

📅 Jul 1 – Jul 25 Major Update

🎯 ปัญหา & เป้าหมาย

ระบบ PE ขาดแผนผังโรงงาน Digital, การบริหารอะไหล่ที่ใช้งานง่าย, และ UX สำหรับช่างเทคนิคหน้างาน

✨ สิ่งที่พัฒนาสำเร็จ

  • สร้าง Interactive Factory Map Builder (Phase 1 & 2): Drag & Drop, Pan/Zoom, Crop/Rotate ก่อน Upload, บันทึกตำแหน่งเครื่องลง DB
  • เพิ่ม Advanced Map Filtering กรองตามประเภทและสถานะ พร้อม Visual Asset Placement
  • ปรับปรุง IIoT Telemetry: แยก ERP Output จาก IIoT Strokes, Hourly Snapshot, Unassigned Line Tracking
  • แก้ไข OEE Quality Calculation ให้ Map Transactions ตาม machine_id ถูกต้อง
  • รีดีไซน์ Spare Parts เป็น Shopping-app Style พร้อมรูปภาพ, Grid/Table Toggle, Multi-item Cart, Image Compression, Lazy Loading
  • เพิ่ม Image Preview Modal บน Tech Mobile พร้อม Before Image ใน Job Summary
  • เพิ่ม Downtime Logging API & Modal บันทึกเหตุหยุดเครื่อง
  • Link Machine ถึง Work Order จาก Map Registry โดยตรง
📈 Business Impact:

ฝ่าย PE มี Digital Twin โรงงาน Real-time, ช่างเทคนิคทำงานเร็วขึ้น, ต้นทุนอะไหล่ Track ได้แม่นยำระดับ Machine

📋 4. Team Planner – Trior (ระบบบริหารงานทีม)

📅 Jul 9 – Aug 8 New System

🎯 ปัญหา & เป้าหมาย

Team Planner เดิมขาด Project Management ที่ครบ, ไม่มีระบบสื่อสารในทีม, และไม่มี File Management

✨ สิ่งที่พัฒนาสำเร็จ

  • ย้ายมาใช้ Trior UI Aesthetic: Sidebar ใหม่, Dashboard, Dark Mode ด้วย View Transitions API
  • พัฒนา Spaces & Projects System: Checklist, Subtasks, Assignees, Priority, Tags, Recurring Tasks
  • เพิ่ม Timeline View พร้อม PDF Export ภาษาไทย (THSarabunNew Font)
  • พัฒนา Chat System: Private Rooms, Group Channels, Attachments, Inbox Filtering
  • เพิ่ม Resources / Files Tab: Upload, List, Categories, DB Tracking, Delete, Metadata Edit
  • เพิ่ม Auto Cover Images: ดึงรูปจาก Attachment มาเป็น Cover Task/Project อัตโนมัติ
  • เพิ่ม Gantt Chart CSV Export พร้อม Dropdown Toolbar
  • เพิ่ม RBAC ป้องกัน Space, Project, Task ตาม Role
  • เพิ่ม Export & Report Module Filter ตาม Assignee และ Date Range
  • Lazy Load ทุก Component + dynamic import ลด Bundle จาก 1.52MB → 409KB (-73%)
📈 Business Impact:

ทีมมีเครื่องมือบริหารงาน Enterprise ครบภายใน Toolbox OS ลดต้นทุน Tool ภายนอก App โหลดเร็วขึ้น 73%

  • อัปเดต Label แสดง "ขาด/ลา" ให้ถูกต้องทั้ง Legacy และ MES v2

HR ลดเวลาตรวจสอบและแก้ไขข้อมูลกะลงมาก ตัวเลข OT/DL ถูกต้อง 100% Batch Reset ช่วยประหยัดเวลาเมื่อมีปัญหาข้อมูลสแกนเป็นกลุ่ม

🖥️ 11. System Monitor – Desktop App (โปรแกรม Monitor เครื่อง)

📅 Aug 8 – Aug 10 New App

🎯 ปัญหา & เป้าหมาย

ทีมพัฒนาต้องการ Desktop Widget ติดตาม CPU, RAM, Disk IO ของเครื่อง Server/Dev โดยไม่ต้องเปิด Task Manager

✨ สิ่งที่พัฒนาสำเร็จ

  • สร้างด้วย Python (psutil) และ Tauri + React + Tailwind
  • รองรับ 3 modes: Window / Widget / Mini สลับได้ผ่าน Settings Modal
  • Desktop Mode: ใช้ Progman เป็น Parent เพื่อ Bypass Win+D minimize
  • แสดง CPU, RAM, Disk IO, GPU, Process Table แบบ Real-time
  • เพิ่ม 4 History Area Charts (CPU, RAM, Disk, Network)
  • เพิ่ม OS Notifications ผ่าน Web API เมื่อ Resource สูงเกิน Threshold
  • Optimize CPU Usage: แยก Heavy WMI Process Iteration ไปยัง Separate Thread
  • Modern Theme ด้วย Glassmorphism, 5-tier Vertical Layout
📈 Business Impact:

ทีม IT มี Tool Monitor เครื่อง Server ที่ Lightweight และ Customizable เตือนเมื่อ Resource ใกล้เต็มก่อนที่ระบบจะมีปัญหา
