# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การจัดการข้อร้องเรียน (Complaints Management)
**รหัสเอกสาร:** SP-LAB-001 (Rev.00)
**วันที่ประกาศใช้:** 07/07/2021
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 7.9 ข้อร้องเรียน

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนในการรับ พิสูจน์ข้อเท็จจริง สอบสวน ตอบสนอง ติดตาม และแจ้งผลการจัดการข้อร้องเรียนจากลูกค้าอย่างเป็นระบบและเป็นธรรม
- **ขอบเขต:** ครอบคลุมข้อร้องเรียนทุกประเภทจากลูกค้าทั้งภายในและภายนอกที่เกี่ยวข้องกับการดำเนินงานและผลการทดสอบของศูนย์ทดสอบ SNC

## 2. ขั้นตอนการจัดการข้อร้องเรียน (Complaints Workflow)
1. **การรับเรื่อง:** เจ้าหน้าที่ทุกคนสามารถรับข้อร้องเรียนได้ทุกช่องทาง (โทรศัพท์, อีเมล, วาจา, หนังสือ) โดยต้องบันทึกรายละเอียดลงใน **"ใบรับข้อร้องเรียน" (FM-LAB-064) ส่วนที่ 1** และส่งต่อให้ผู้จัดการคุณภาพทันที
2. **การออกรหัสข้อร้องเรียนและการแจ้งรับเรื่อง:**
   - ผู้จัดการคุณภาพแจ้งให้ผู้ร้องเรียนทราบว่าได้รับเรื่องแล้ว และออกรหัสในรูปแบบ `A/B` (เช่น `01/21` โดย `A` คือลำดับข้อร้องเรียน และ `B` คือปี ค.ศ.)
3. **การสอบสวนข้อเท็จจริง:**
   - **กรณีไม่เกี่ยวกับระบบคุณภาพ/ผลทดสอบ:** ตอบชี้แจงลูกค้าและบันทึกปิดเรื่อง
   - **กรณีเกี่ยวกับผลทดสอบแต่ไม่มีผลกระทบต่อความถูกต้อง:** ดำเนินการตามระเบียบ **การปฏิบัติการแก้ไข (SP-LAB-007)**
   - **กรณีมีผลกระทบต่อความถูกต้องของผลทดสอบ:** เข้าสู่ระเบียบ **การควบคุมงานทดสอบที่ไม่เป็นไปตามกำหนด (SP-LAB-002)** ทันที
4. **การสื่อสารผลการดำเนินงาน:**
   - **กฎเหล็กเรื่องความเป็นกลาง:** ผู้จัดการคุณภาพต้อง **มอบหมายให้ผู้ที่ไม่มีส่วนเกี่ยวข้องกับกิจกรรมที่ถูกร้องเรียน เป็นผู้แจ้งผลการสอบสวนแก่ผู้ร้องเรียน** เพื่อความโปร่งใส
   - แจ้งความคืบหน้าเป็นระยะ และทำหนังสือแจ้งผลสรุปเมื่อการแก้ไขเสร็จสมบูรณ์
5. **การรายงานฝ่ายบริหาร:** รวบรวมข้อร้องเรียนทั้งหมดเพื่อรายงานต่อที่ประชุมการทบทวนโดยฝ่ายบริหาร (Management Review - SP-LAB-009)

## 3. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบรับข้อร้องเรียน (FM-LAB-064), ใบสรุปบันทึกข้อร้องเรียน (FM-LAB-065)
- **ระยะเวลาการจัดเก็บ:** เอกสารการจัดการข้อร้องเรียนทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
