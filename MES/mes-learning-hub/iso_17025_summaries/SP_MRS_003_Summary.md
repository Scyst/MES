# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมเอกสารและข้อมูล (Document and Data Control)
**รหัสเอกสาร:** SP-MRS-003 (Rev.04)
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 8.3 การควบคุมเอกสารระบบการบริหารงาน (Control of Management System Documents)

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อสร้างความมั่นใจว่าเอกสารและข้อมูลทั้งหมดที่นำมาใช้ในการปฏิบัติงาน เป็นฉบับที่ได้รับการทบทวน อนุมัติ และเป็นฉบับล่าสุด (Current Revision) เสมอ เพื่อป้องกันความผิดพลาดในการผลิต บริการ และการทดสอบ
- **ขอบเขต:** ครอบคลุมเอกสารภายในทุกระดับ (ระดับ 1 ถึง 4), เอกสารภายนอก (มาตรฐานสากล, กฎหมาย, คู่มือเครื่องจักร), และแบบแปลน (Drawings)

## 2. ลำดับชั้นเอกสารและโครงสร้างรหัสเอกสาร (Document Hierarchy & Coding)
| ระดับเอกสาร | ประเภทเอกสาร | ตัวอย่างรหัส | ผู้จัดทำ / ผู้ทบทวน / ผู้อนุมัติ (สำหรับ ISO 17025) |
| :---: | :--- | :--- | :--- |
| **ระดับ 1** | **คู่มือคุณภาพ (Quality Manual - QM)** | `QM-MRS-001` | จัดทำ: ผู้จัดการคุณภาพ / ทบทวน: ผู้จัดการวิชาการ / อนุมัติ: ผู้บริหารสูงสุด (MD) |
| **ระดับ 2** | **ระเบียบปฏิบัติ (Standard Procedures - SP)** | `SP-LAB-xxx` | **ด้านระบบบริหาร:** เจ้าหน้าที่คุณภาพ / ทบทวน: QM / อนุมัติ: MD<br>**ด้านวิชาการ:** เจ้าหน้าที่ทดสอบ / ทบทวน: TM / อนุมัติ: MD |

## 3. ขั้นตอนการควบคุมเอกสาร (Document Lifecycle Management)

### 3.1 การจัดทำ ขอแก้ไข หรือยกเลิกเอกสาร (DAR Workflow)
1. หน่วยงานผู้ขอจัดทำ/แก้ไข ยื่น **"ใบขอการเปลี่ยนแปลง แก้ไข ยกเลิก เอกสารควบคุม" (DAR - FM-MRS-006)**
2. เจ้าหน้าที่ควบคุมเอกสาร (DCC) และผู้จัดการคุณภาพ (QMR/QM) ตรวจสอบความสมบูรณ์
3. เสนอผู้บริหารสูงสุดลงนามอนุมัติ

### 3.2 การประทับตราควบคุมและการแจกจ่าย (Stamping & Distribution)
- **"ORIGINAL" (สีแดง):** ประทับบนเอกสารต้นฉบับ จัดเก็บในตู้ควบคุมเอกสารของ DCC
- **"CONTROLLED COPY" (สีแดง):** ประทับบนสำเนาที่แจกจ่ายไปยังจุดใช้งานจริง โดยบันทึกลงใน **"แบบฟอร์มการควบคุมแจกจ่ายเรียกคืนเอกสาร" (FM-MRS-011)**
- **"CANCELLED" (สีน้ำเงิน):** ประทับตรงกลางทุกหน้าของเอกสารฉบับเก่าที่ถูกยกเลิก เพื่อป้องกันการนำไปใช้สับสน
- **"CONFIDENTIAL / เอกสารความลับ" (สีแดง):** ประทับบนเอกสารสำคัญหรือ Drawing ของลูกค้า ห้ามแจกจ่ายภายนอก

### 3.3 การควบคุมเอกสารอิเล็กทรอนิกส์ (Electronic Document Control)
- แปลงไฟล์เป็น **PDF พร้อมลายน้ำเอกสารควบคุม** วางในระบบเซิร์ฟเวอร์ที่จำกัดสิทธิ์เข้าถึง (Access Rights)
- กำหนดให้ระบบเซิร์ฟเวอร์ทำการ **Auto-Backup ทุกวันเวลา 01:00 น.**

### 3.4 การทบทวนความทันสมัยประจำปี (Annual Document Review)
- แม้ไม่มีการแก้ไข ทุกหน่วยงานต้องดำเนินการทบทวนเอกสารในความรับผิดชอบอย่างน้อย **ปีละ 1 ครั้ง** โดยใช้แบบฟอร์ม **FM-MRS-026** เพื่อยืนยันว่าเอกสารยังคงสอดคล้องกับหน้างานจริง

### 3.5 การจัดเก็บและทำลายเอกสาร
- **เอกสารยกเลิก (ฉบับต้นฉบับ):** จัดเก็บไว้เป็นประวัติอย่างน้อย **5 ปี** ประทับตรา CANCELLED
- **เอกสารยกเลิก (ฉบับสำเนา):** เรียกคืนกลับมาทำลายทิ้ง หรือใช้ปากกาแดงขีดฆ่าก่อนนำไป Recycle
- **เอกสารภายนอก (External Documents):** จัดเก็บรักษาไว้เป็นเวลา **15 ปี**

## 4. แบบฟอร์มและบันทึกคุณภาพที่เกี่ยวข้อง
- ใบขอขึ้นทะเบียน/เปลี่ยนแปลง/ยกเลิกเอกสาร (DAR - FM-MRS-006)
- บัญชีรายชื่อเอกสารแม่บท (Master List - FM-MRS-010)
- ทะเบียนควบคุมการแจกจ่ายและเรียกคืนเอกสาร (FM-MRS-011)
- แบบฟอร์มการทบทวนเอกสารประจำปี (FM-MRS-026)
- **การจัดเก็บ:** แผนก DCC จัดเก็บ 5 ปี (เอกสารภายนอกเก็บ 15 ปี) ในระบบ Save Folder
