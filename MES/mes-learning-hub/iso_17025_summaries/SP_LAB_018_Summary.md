# สรุประเบียบปฏิบัติการ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมบันทึก ข้อมูล และสารสนเทศ (Control of Records, Data and Information Management)
**รหัสเอกสาร:** SP-LAB-018 (Rev.00)
**มาตรฐานอ้างอิง:** ISO/IEC 17025:2017 ข้อ 7.5 บันทึกด้านวิชาการ, ข้อ 7.11 การควบคุมการจัดการข้อมูลและสารสนเทศ, ข้อ 8.4 การควบคุมบันทึก

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อให้มั่นใจว่าบันทึกด้านวิชาการ ข้อมูลดิบ (Raw Data) และสารสนเทศทั้งหมดของห้องปฏิบัติการ ได้รับการควบคุมอย่างถูกต้อง ครบถ้วน อ่านออกได้ สามารถสืบย้อนกลับได้ มีความปลอดภัย มีการสำรองข้อมูล และรักษาความลับอย่างเคร่งครัด
- **ขอบเขต:** ครอบคลุมการบันทึก การชี้บ่ง การจัดเก็บ การแก้ไข การทวนสอบการคำนวณและการถ่ายโอนข้อมูล การตรวจสอบความใช้ได้ของโปรแกรมคำนวณ (Excel Spreadsheets / Testing Software) การควบคุมคอมพิวเตอร์ และการทำลายบันทึก

## 2. กฎเหล็กการบันทึกข้อมูล (Good Documentation Practices - GDP)
1. **การบันทึกทันที (Real-time Recording):** ต้องจดบันทึกค่าที่อ่านได้ ข้อมูลดิบ และการคำนวณลงในแบบฟอร์มทันทีขณะปฏิบัติงาน ห้ามจดลงเศษกระดาษแล้วมาลอกลงฟอร์มในภายหลัง
2. **เครื่องมือเขียน:** ใช้ปากกาน้ำหมึกเท่านั้น **ห้ามใช้ดินสอหรือน้ำยาลบคำผิด (Liquid Paper) เด็ดขาด**
3. **การแก้ไขข้อผิดพลาด:** ให้ใช้ปากกา **ขีดฆ่า 1 เส้น** บนข้อความที่ผิด แล้วเขียนข้อความที่ถูกต้องไว้ด้านข้าง พร้อมลงลายมือชื่อกำกับและลงวันที่
4. **ช่องว่าง:** หากช่องใดไม่มีข้อมูล ให้ใส่เครื่องหมายยัติภังค์ `"-"` ห้ามปล่อยว่าง
5. **ลายมือชื่อกำกับ:** บันทึกด้านเทคนิคต้องมีลายมือชื่อ 2 ส่วนเสมอ คือ **ผู้บันทึก (Recorder)** และ **ผู้ตรวจสอบ (Checker / Technical Manager)**

## 3. การทวนสอบการคำนวณและตรวจสอบความใช้ได้ของซอฟต์แวร์ (Software & Excel Validation)
ห้องปฏิบัติการใช้โปรแกรม Microsoft Excel ในการคำนวณผลและออกรายงานผลทดสอบ ซึ่งต้องมีมาตรการควบคุมเข้มงวดตาม ISO 17025:
1. **การพิสูจน์ความถูกต้องของสูตร (Spreadsheet Validation):**
   - ผู้จัดการวิชาการต้องทวนสอบสูตรคำนวณใน Excel โดยเปรียบเทียบผลลัพธ์กับการกดเครื่องคิดเลขคำนวณด้วยตนเอง
2. **การป้องกันการแก้ไขสูตร (File Protection):**
   - ต้องล็อกเซลล์สูตรคำนวณ (Lock Cells)
   - ป้องกันชีตและสมุดงานด้วยรหัสผ่าน (Protect Sheet & Workbook)
   - กำหนดเงื่อนไขการป้อนข้อมูล (Data Validation) เพื่อป้องกันการกรอกค่าที่ผิดพลาด
3. **การควบคุมเวอร์ชันและความถี่ในการทวนสอบ (FM-LAB-038):**
   - ระบุ Version Template และวันที่เริ่มใช้อย่างชัดเจน
   - ผู้จัดการวิชาการต้องตรวจสอบความถูกต้องของไฟล์ Excel และ Testing Software **ซ้ำทุกๆ 3 เดือน** หรือทุกครั้งที่มีการแก้ไขสูตรหรืออัปเดตเวอร์ชัน และบันทึกลงใน **"บันทึกการตรวจสอบความใช้ได้ของ Testing Software / Excel Spreadsheets" (FM-LAB-038)**

## 4. การควบคุมคอมพิวเตอร์และระบบเครือข่าย (Computer & Network Security)
1. **การควบคุมการเข้าถึง:** กำหนดสิทธิ์ผู้ใช้งาน (Access Rights) และตั้งรหัสผ่านเฉพาะบุคคลตามระเบียบ SP-MIS-001
2. **การสำรองข้อมูล (Data Backup):** กำหนดรอบการสำรองข้อมูลอัตโนมัติและจัดเก็บในพื้นที่ปลอดภัย
3. **บันทึกอิเล็กทรอนิกส์:** หากมีการแก้ไขไฟล์ข้อมูลดิบอิเล็กทรอนิกส์ ให้บันทึกไฟล์เป็นชื่อใหม่โดยระบุ Revision ชัดเจน (เช่น `File_Rev01`) และต้องจัดเก็บไฟล์เดิมไว้เป็นประวัติ ห้ามบันทึกทับ (Overwrite) เด็ดขาด

## 5. การจัดเก็บและการทำลายบันทึก
- **อายุการจัดเก็บทั่วไป:** จัดเก็บอย่างน้อย **5 ปี** ในสภาวะแวดล้อมที่ปลอดภัย ป้องกันการสูญหายหรือเสียหาย
- **บันทึกเฉพาะ:** ประวัติเครื่องมือทดสอบ และประวัติบุคลากร จัดเก็บตลอดอายุการใช้งาน/การเป็นพนักงาน และเก็บต่อไปอีก **5 ปี** หลังปลดระวางหรือลาออก
- **การทำลาย:** ทำลายด้วยเครื่องย่อยเอกสาร (Shredder) หรือลบทำลายถาวร

## 6. แบบฟอร์มและบันทึกคุณภาพที่เกี่ยวข้อง
- บันทึกการตรวจสอบความใช้ได้ของ Testing Software / Excel Spreadsheets (FM-LAB-038)
- รายงานผลการคำนวณและการถ่ายโอนข้อมูลดิบ (Raw Data Sheets)
- **การจัดเก็บ:** จัดเก็บ ณ Office MIS และห้องปฏิบัติการ เป็นเวลา 5 ปี
