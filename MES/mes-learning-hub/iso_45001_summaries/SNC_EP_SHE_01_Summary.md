# สรุปขั้นตอนปฏิบัติ (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมเอกสารและข้อมูล (Document Control)
**รหัสเอกสาร:** SNC-EP-SHE-01 (Rev.04)
**วันที่ประกาศใช้:** 15/09/2025

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการควบคุมเอกสาร ข้อมูลสารสนเทศ ซอฟต์แวร์ และบันทึกคุณภาพ เพื่อป้องกันไม่ให้เกิดความสับสนหรือนำเอกสารที่ล้าสมัยมาใช้งาน
- **ขอบเขต:** ครอบคลุมเอกสารและบันทึกข้อมูลทั้งหมดทั้งภายในและภายนอกบริษัท

## 2. ลำดับชั้นของเอกสารในระบบ (Document Hierarchy)
แบ่งเอกสารออกเป็น 5 ลำดับชั้น:
1. **คู่มือระบบ (Manual - EM / SM):** อธิบายภาพรวม นโยบาย และโครงสร้างการบริหาร (สูงสุด)
2. **ขั้นตอนปฏิบัติงาน (Procedure - EP / SP):** อธิบายขั้นตอนการทำงานระหว่างแผนก
3. **วิธีปฏิบัติงาน (Work Instruction - WI):** อธิบายรายละเอียดการทำงานเฉพาะจุด
4. **แบบฟอร์ม (Form - FM):** เอกสารสำหรับบันทึกผลการทำงาน
5. **เอกสารสนับสนุน (Supporting Document - SD):** กฎหมาย, คู่มือเครื่องจักร, มาตรฐาน ISO

## 3. ระบบการประทับตราควบคุม (Document Stamps)
- **ตรา "ORIGINAL" (หมึกสีแดง):** ประทับบนหน้าแรกของเอกสารต้นฉบับตัวจริง
- **ตรา "CONTROLLED COPY" (หมึกสีแดง):** ประทับบนเอกสารสำเนาที่แจกจ่ายให้แผนกต่างๆ ใช้งาน (เอกสารควบคุม)
- **ตรา "CANCELLED" (หมึกสีแดง):** ประทับบนเอกสารฉบับเก่าที่ถูกยกเลิกแล้ว เพื่อนำไปทำลายหรือเก็บเป็นประวัติ
- **ตรา "External Support Document" (หมึกสีน้ำเงิน):** ประทับบนเอกสารที่รับมาจากภายนอก เช่น กฎหมาย หรือคู่มือเครื่องจักร

## 4. ขั้นตอนการขอจัดทำ / แก้ไข / ยกเลิกเอกสาร (DAR Workflow)
1. **ยื่นคำร้อง:** ผู้ขอเขียนแบบฟอร์ม **DAR (Document Action Request - SNC-FM-SHE-01)** พร้อมแนบเอกสารฉบับร่าง
2. **การอนุมัติ:** เสนอให้ผู้จัดการแผนก และตัวแทนฝ่ายบริหาร (EMR/SMR) เซ็นอนุมัติ
3. **การแจกจ่ายและเรียกคืน:** 
   - เจ้าหน้าที่ DCC/SHE จะแจกจ่ายเอกสารฉบับใหม่ (ประทับตรา CONTROLLED COPY) ให้ผู้ถือครอง
   - **กฎเหล็ก:** เจ้าหน้าที่ต้อง **ตามเก็บเอกสารฉบับเก่ากลับมาทำลายทันที** เพื่อป้องกันไม่ให้พนักงานหยิบเวอร์ชันเก่าไปใช้งาน

## 5. กฎระเบียบในการกรอกบันทึก (Good Documentation Practice)
- **ห้าม** ใช้ดินสอเขียนบันทึกโดยเด็ดขาด (ต้องใช้ปากกาเท่านั้น)
- หากเขียนผิด **ห้ามใช้น้ำยาลบคำผิด (ลิควิด)** ให้ใช้วิธี **ขีดฆ่า 1 เส้น -> เขียนข้อมูลที่ถูกต้อง -> เซ็นชื่อกำกับ**
- ช่องว่างที่ไม่ได้กรอกข้อมูล ให้ขีดละ (-) เสมอ

## 6. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบ DAR (SNC-FM-SHE-01), DAR Log (SNC-FM-SHE-02), Master List (SNC-FM-SHE-03), ทะเบียนการแจกจ่าย/เรียกคืน (SNC-FM-SHE-04)
- **ระยะเวลาการจัดเก็บ:** เอกสารควบคุมทั้งหมดเก็บรักษาไว้เป็นเวลา **2 ปี**
