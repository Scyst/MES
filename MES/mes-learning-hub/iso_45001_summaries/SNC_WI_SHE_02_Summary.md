# สรุปวิธีปฏิบัติ (Work Instruction)
**ชื่อเอกสาร:** แผนฉุกเฉินกรณีสารเคมีหกหรือรั่วไหล (Chemical Spill Emergency Plan)
**รหัสเอกสาร:** SNC-WI-SHE-02 (Rev.04)
**วันที่ประกาศใช้:** 15/09/2025

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการระงับเหตุสารเคมีรั่วไหล ป้องกันไม่ให้สารเคมีปนเปื้อนลงสู่พื้นดินหรือแหล่งน้ำ และลดความสูญเสียต่อพนักงานและสิ่งแวดล้อม
- **ขอบเขต:** ครอบคลุมการควบคุมเมื่อเกิดเหตุสารเคมีรั่วไหลภายในพื้นที่บริษัท และระหว่างการขนส่งภายในบริษัท

## 2. อุปกรณ์ที่ต้องเตรียมความพร้อม (Spill Kit)
พื้นที่ที่มีการใช้หรือจัดเก็บสารเคมี ต้องมีอุปกรณ์เหล่านี้เตรียมพร้อมไว้เสมอ:
- **วัสดุดูดซับ:** เศษผ้า, ทราย, ขี้เลื่อย
- **อุปกรณ์ทำความสะอาด:** พลั่ว, ไม้กวาดทางมะพร้าว, ถังหรือถุงขยะสำหรับใส่ขยะอันตราย, เทปกั้นเขต
- **อุปกรณ์ป้องกันส่วนบุคคล (PPE):** ผ้าปิดจมูก/หน้ากากกันสารเคมี, ถุงมือยาง, แว่นตานิรภัย, รองเท้าเซฟตี้ หรือรองเท้าบู๊ทยาง

## 3. ขั้นตอนการระงับเหตุ (Emergency Response)

### 3.1 กรณีรั่วไหลเล็กน้อย (Minor Spill)
1. พนักงานที่พบเห็นต้องตะโกนบอกเพื่อนร่วมงานให้ระวัง และแจ้งหัวหน้างาน / จป.วิชาชีพ ทันที
2. **หยุดการรั่วไหลก่อน:** หัวหน้างานหรือผู้พบเห็นต้องพยายามอุดรอยรั่ว ปิดวาล์ว หรือจับถังตั้งขึ้น (ห้ามข้ามขั้นตอนนี้เด็ดขาด)
3. **กั้นไม่ให้ลาม:** นำทรายหรือขี้เลื่อยมาโรยล้อมกรอบบริเวณที่สารเคมีหก เพื่อไม่ให้ไหลกระจายเป็นวงกว้าง 
   - *ข้อควรระวัง:* หากใกล้ท่อระบายน้ำ ต้องรีบเอาทรายไปกั้นขอบท่อระบายน้ำก่อนเป็นอันดับแรก เพื่อป้องกันสารเคมีไหลลงสู่แหล่งน้ำสาธารณะ
4. **ดูดซับและทำความสะอาด:** สวม PPE ให้ครบถ้วน โรยทราย/ขี้เลื่อยทับสารเคมีให้ซับน้ำจนแห้ง ใช้พลั่วตักใส่ถัง/ถุงขยะอันตราย ปิดปากถุงให้สนิทและติดฉลากให้ชัดเจน
5. **ข้อห้ามเด็ดขาด:** ห้ามใช้น้ำฉีดล้างสารเคมีลงท่อระบายน้ำโดยตรงเด็ดขาด!

### 3.2 กรณีรั่วไหลปริมาณมาก (Major Spill - มากกว่า 20 ลิตร)
1. ให้อพยพพนักงานที่ไม่เกี่ยวข้องออกจากพื้นที่ และกั้นเขตพื้นที่อันตราย
2. แจ้งทีมระงับเหตุฉุกเฉิน (Emergency Team) เข้าจัดการ โดยทีมต้องใส่ PPE เต็มรูปแบบเข้าไประงับเหตุและดูดซับสารเคมี
3. หากมีผู้บาดเจ็บ ให้ปฐมพยาบาลเบื้องต้นตามที่ระบุไว้ในเอกสาร SDS และรีบนำส่งแพทย์
4. ต้องมีการเขียนรายงานสอบสวนอุบัติเหตุ (SNC-WI-SHE-04) เพื่อหาสาเหตุและป้องกันไม่ให้เกิดซ้ำ

## 4. การฝึกซ้อมและการเก็บบันทึก
- **การฝึกซ้อม:** ต้องจัดให้มีการฝึกซ้อมแผนระงับเหตุสารเคมีรั่วไหล **อย่างน้อยปีละ 1 ครั้ง**
- **เอกสารที่เกี่ยวข้อง:** แบบประเมินการฝึกซ้อม (SNC-FM-SHE-20), แบบรายงานการสอบสวนอุบัติเหตุ (SNC-FM-SHE-28)
- **ระยะเวลาการจัดเก็บ:** เอกสารเก็บรักษาไว้ **2 ปี**
