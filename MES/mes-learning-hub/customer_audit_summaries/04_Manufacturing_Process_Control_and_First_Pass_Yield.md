# การควบคุมกระบวนการผลิตและอัตราของเสียรอบแรก (Manufacturing Control & FPY)
**มาตรฐานอ้างอิง:** ISO 9001:2015 ข้อ 8.5.1, Lowe's QA Criteria หมวด 5 (Q5.1 - Q5.22)  
**ระเบียบปฏิบัติและแบบฟอร์มที่เกี่ยวข้อง:**
- `Generic Quality Control Plan (QCP)`: แผนควบคุมคุณภาพกระบวนการผลิตรวม
- `SP-PRD-xxx`: ระเบียบปฏิบัติการควบคุมกระบวนการผลิต (Production Process Control Procedure)
- `WI-PRD-xxx`: มาตรฐานการปฏิบัติงานประจำสถานี (Work Instructions)
- `CH-QCS-xxx`: แบบฟอร์มบันทึกการตรวจสอบชิ้นงานแรก (First Piece Inspection Sheet)
- `FM-HRD-004`: ทะเบียนทักษะพนักงาน (Skill Matrix) และใบรับรองช่างเฉพาะทาง (Special Process Certification)

---

## 1. วัตถุประสงค์และขอบเขต (Purpose & Scope)

ในระหว่างการเดินตรวจโรงงาน (Plant Tour Walk-Path) ของผู้ตรวจประเมินจากลูกค้าสากล แผนกผลิตเป็นพื้นที่ที่ถูกตรวจสอบอย่างละเอียดที่สุด ทั้งด้านระเบียบวินัย, การปฏิบัติตามมาตรฐาน, และความสามารถในการควบคุมคุณภาพ เอกสารฉบับนี้มีวัตถุประสงค์เพื่อ:
1. **มาตรฐานหน้างานที่เป็นรูปธรรม:** มีแผนควบคุม (Control Plan) และคู่มือปฏิบัติงาน (WI) ภาษาไทยพร้อมรูปภาพประจำทุกสถานีงาน
2. **การรับรองช่างฝีมือเฉพาะทาง (Special Process Qualification):** ควบคุมให้เฉพาะพนักงานที่ผ่านการฝึกอบรมและมีใบรับรองเท่านั้นเป็นผู้ปฏิบัติงานในจุดวิกฤต (เชื่อม, บัดกรีเตา, ตรวจรั่วฮีเลียม)
3. **การตรวจสอบชิ้นงานแรกอย่างเคร่งครัด (First Piece Inspection):** ตัดวงจรของเสียตั้งแต่เริ่มต้นกะหรือการเปลี่ยนรุ่น
4. **การคำนวณและติดตาม First Pass Yield (FPY) และ Order Fulfillment Rate:** ตรวจวัดผลิตภาพและของเสียรายวัน พร้อมระบบออกใบสั่งแก้ไข (CAR) เมื่อผลการดำเนินงานต่ำกว่าเป้าหมาย

## 2. การควบคุมเอกสารและสภาพแวดล้อมประจำสถานีงาน (Workstation Standards & 5S)

ทุกสถานีงานในสายการผลิตต้องปฏิบัติตามมาตรฐานการจัดวางและการแสดงผลข้อมูลดังนี้:

| องค์ประกอบหน้างาน (Workstation Element) | มาตรฐานที่ต้องมี (Required Standard) | เกณฑ์การตรวจประเมินของผู้ตรวจ (Audit Checklist) |
| :--- | :--- | :--- |
| **1. Work Instruction (WI)** | ติดตั้งในระดับสายตาของพนักงาน เป็นภาษาไทย มีรูปภาพขั้นตอนการทำงาน ค่าพิกัดความเผื่อ (Tolerances) และจุดที่ต้องระวัง | ผู้ตรวจจะถามพนักงานว่า: *"ขั้นตอนใน WI ข้อที่ 3 ทำอย่างไร?"* พนักงานต้องอธิบายได้ตรงตามคู่มือ 100% |
| **2. Q-Point Control Board** | ป้ายจุดควบคุมคุณภาพวิกฤต (Q-Points 030 - 035) แสดงภาพของดี (OK) เทียบกับของเสีย (NG) อย่างชัดเจน | พนักงานต้องชี้ได้ว่าจุดที่ตนเองรับผิดชอบ มีลักษณะของเสียอะไรบ้างที่ห้ามปล่อยผ่าน |
| **3. Bill of Materials (BOM)** | ใบรายการชิ้นส่วนและสเปกรุ่นที่กำลังผลิต (Active Work Order & BOM) | ตรวจสอบว่าชิ้นส่วนที่วางอยู่บนไลน์ มีรหัส Part Number ตรงกับในใบสั่งผลิตหรือไม่ |
| **4. การจัดการ 5ส และบอร์ดเงา (5S & Tool Shadow Board)** | เครื่องมือช่าง (คีม, ประแจ, ไขควงลม) ต้องแขวนบนบอร์ดเงาที่มีสัญลักษณ์กำกับ | ห้ามวางเครื่องมือระเกะระกะบนโต๊ะงาน หรือมีอุปกรณ์ที่ไม่เกี่ยวข้องกับการผลิตวางอยู่ |
| **5. การแยกชิ้นงาน (Part Segregation)** | แยกพื้นที่วางชิ้นส่วนรอประกอบ (WIP), ชิ้นงานดี (OK) ในกล่องสีน้ำเงิน/เขียว และชิ้นงานเสีย (NG) ในถังสีแดง | ห้ามวางชิ้นงานสัมผัสกับพื้นโรงงานโดยตรง ต้องมีพาเลทหรือชั้นวางรองรับเสมอ |

## 3. ทะเบียนทักษะและการรับรองช่างเฉพาะทาง (Skill Matrix & Special Process Qualification)

โรงงานต้องบริหารจัดการทักษะของพนักงานสายการผลิตผ่าน **ระบบประเมินทักษะ 4 ระดับ (Skill Matrix 4 Levels)**:

```
[ระดับ 1: พนักงานฝึกหัด (Trainee)]  -> อยู่ระหว่างการเรียนรู้ ทำงานภายใต้การดูแลใกล้ชิดของพี่เลี้ยง
[ระดับ 2: ปฏิบัติงานได้ (Basic)]    -> สามารถทำงานตาม WI ได้อย่างถูกต้อง แต่ยังแก้ปัญหาเฉพาะหน้าไม่ได้
[ระดับ 3: ช่างชำนาญการ (Qualified)] -> ทำงานได้คล่องแคล่ว มีใบรับรอง ผ่านการทดสอบคุณภาพ 100%
[ระดับ 4: หัวหน้า/ครูฝึก (Master)]  -> สามารถสอนงาน ตรวจสอบความถูกต้อง และประเมินทักษะผู้อื่นได้
```

### การรับรองกระบวนการพิเศษ (Special Process Certification)
พนักงานที่ปฏิบัติงานใน 4 กระบวนการวิกฤตต่อไปนี้ **ต้องมีบัตรประจำตัวช่างผู้ผ่านการรับรอง (Certification Badge)** ติดที่หน้าอกเสื้อ:
1. **พนักงานควบคุมเตาบัดกรีสุญญากาศ/บรรยากาศไนโตรเจน (CAB Brazing Furnace Operator):**
   - ผ่านการอบรมด้านโปรไฟล์อุณหภูมิเตา (Furnace Thermal Profiling), การควบคุมความเข้มข้นของไนโตรเจน ($O_2 < 100\text{ ppm}$), และอัตราการพ่นฟลักซ์
2. **พนักงานเชื่อม Spot Weld และเชื่อมต่อท่อทองแดง/อลูมิเนียม (Certified Welder):**
   - ผ่านการทดสอบรอยเชื่อม (Weld Penetration Test) และทดสอบแรงดึงตามมาตรฐาน
3. **พนักงานทดสอบการรั่วไหลด้วยก๊าซฮีเลียม (Helium Leak Test Operator):**
   - ผ่านการอบรมการใช้เครื่องตรวจวัดสุญญากาศ และการทดสอบยืนยันด้วย Golden Master Leak ประจำวัน
4. **พนักงานเตรียมผิวเคมีและพ่นสี (Pretreatment & Coating Operator):**
   - ผ่านการอบรมการไทเทรตหาความเข้มข้นของบ่อสารเคมี และการวัดความหนาชั้นฟิล์มสี (Coating Thickness)
- **รอบการประเมิน:** ทบทวนและทดสอบทักษะซ้ำทุกๆ **1 ปี (Annual Re-certification)**

## 4. ขั้นตอนการตรวจสอบชิ้นงานแรก (First Piece Inspection: FPI Routine)

การตรวจสอบชิ้นงานแรกมีขึ้นเพื่อรับประกันว่า เครื่องจักร, แม่พิมพ์, จิ๊กฟิกซ์เจอร์, และพารามิเตอร์การตั้งค่ามีความถูกต้องสมบูรณ์ก่อนเริ่มเดินไลน์ผลิต:

```
[จุดทริกเกอร์ให้ทำ FPI (Mandatory Triggers)]
  ├── เริ่มต้นกะการทำงานใหม่ (Start of Shift)
  ├── มีการเปลี่ยนรุ่นสินค้า (Model Changeover)
  ├── มีการเปลี่ยนหรือเจียรแต่งใบมีด/แม่พิมพ์ (Tooling/Blade Replacement)
  └── หลังการซ่อมบำรุงเครื่องจักรจากเหตุเสียฉุกเฉิน (Post-Maintenance Restart)
  │
  ▼
[การผลิตและตรวจสอบเบื้องต้นโดยพนักงาน (Operator 1st Check)]
  │  - ผลิตชิ้นงานตัวอย่าง 1 ชิ้น
  │  - ตรวจสอบขนาดและลักษณะทางกายภาพตาม Check Sheet เบื้องต้น
  ▼
[การตรวจสอบยืนยันโดย QC Inspector (QC 2-Piece Verification)]
  │  - สุ่มชิ้นงานเพิ่มเติมอีก 2 ชิ้น (รวมเป็น 3 ชิ้น)
  │  - ใช้เครื่องมือวัดที่สอบเทียบแล้ว (Vernier, Micrometer, Height Gauge, Projector)
  │  - บันทึกค่าที่วัดได้จริงลงใน "ใบตรวจสอบชิ้นงานแรก (FM-QCS-xxx)"
  ▼
[การตัดสินผลและการอนุญาตให้เดินสายการผลิต (Decision & Line Release)]
  ├── ผ่านเกณฑ์ 100%: ติดป้ายสีเขียว "FIRST PIECE APPROVED" พร้อมเซ็นชื่ออนุมัติ
  └── หลุดสเปกแม้แต่ค่าเดียว: สั่งหยุดไลน์ (Line Stop) และปรับตั้งเครื่องจักรใหม่จนกว่าจะผ่าน
```

## 5. การคำนวณและติดตาม First Pass Yield (FPY) และ Order Fulfillment Rate

### 1) การคำนวณอัตราของเสียรอบแรก (First Pass Yield - FPY)
First Pass Yield คือ ดัชนีวัดประสิทธิภาพการผลิตที่แท้จริง โดยนับเฉพาะชิ้นงานที่ผ่านการตรวจสอบในครั้งแรกโดย **ไม่มีการซ่อมงาน (No Rework)**:

$$Y_i = \frac{\text{Input}_i - \text{Defect}_i}{\text{Input}_i}$$

สำหรับสายการผลิตที่มีกระบวนการย่อยต่อเนื่องกัน $n$ กระบวนการ (เช่น ตัดท่อ $\rightarrow$ ปั๊ม $\rightarrow$ รีดฟิน $\rightarrow$ ประกอบ $\rightarrow$ บัดกรี $\rightarrow$ ตรวจรั่ว):
$$\text{Overall FPY} = Y_1 \times Y_2 \times Y_3 \times \dots \times Y_n$$

- **เป้าหมายโรงงาน (Plant Target):** Overall FPY $\ge 98.5\%$
- **การดำเนินการเมื่อ FPY หลุดเป้าหมาย:** หาก FPY ในวันใดต่ำกว่า $97.0\%$ หัวหน้าแผนกผลิตและวิศวกรต้องร่วมกันจัดทำรายงานวิเคราะห์สาเหตุ (Defect Pareto Analysis) ภายใน 24 ชั่วโมง

### 2) การคำนวณอัตราการบรรลุคำสั่งผลิตรายวัน (Daily Production Fulfillment Rate)
$$\text{Production Fulfillment Rate} = \left( \frac{\text{จำนวนชิ้นงานดีที่ผลิตได้จริง}}{\text{เป้าหมายตามแผนการผลิตรายวัน}} \right) \times 100\%$$

- **เป้าหมายโรงงาน:** Fulfillment Rate $\ge 95.0\%$
- **การออกใบสั่งแก้ไข (CAR Production):** ตามข้อกำหนด Lowe's Audit หาก Fulfillment Rate ต่ำกว่า $90\%$ ฝ่ายผลิตต้องออกใบ CAR เพื่อสอบสวนสาเหตุ เช่น เครื่องจักรขัดข้อง, รอวัตถุดิบ, หรือของเสียสะสม และกำหนดมาตรการป้องกันการเกิดซ้ำ

## 6. การบำรุงรักษาเชิงป้องกันและการควบคุมอายุแม่พิมพ์ (PM & Tooling Life Control)

```
[ระดับการบำรุงรักษาในสายการผลิต]
┌─────────────────────────────────────────────────────────────┐
│ 1. การบำรุงรักษาด้วยตนเองประจำวัน (Autonomous Maintenance: AM)│
│    - พนักงานตรวจเช็คก่อนเริ่มงาน 10 นาที (ความสะอาด, รอยรั่ว, │
│      แรงดันลม, ระดับน้ำมันหล่อลื่น, ปุ่มหยุดฉุกเฉิน Emergency)  │
├─────────────────────────────────────────────────────────────┤
│ 2. การบำรุงรักษาเชิงป้องกันประจำเดือน (Monthly Preventive PM)  │
│    - ช่างซ่อมบำรุงตรวจสอบตามแผน PM Master Plan: สายพาน,     │
│      แบริ่ง, มอเตอร์, เซ็นเซอร์, และปรับตั้งค่าความเที่ยงตรง    │
├─────────────────────────────────────────────────────────────┤
│ 3. การควบคุมอายุการปั๊มของแม่พิมพ์ (Tooling Stroke Life)      │
│    - ติดตั้งตัวนับสโตรก (Stroke Counter) บนแม่พิมพ์ปั๊มทุกชุด     │
│    - กำหนดรอบเจียรแต่งคมใบมีด (Regrinding) ทุก 50,000 สโตรก    │
│    - บันทึกประวัติการซ่อมและเปลี่ยนอะไหล่ลงใน Tool History Card│
└─────────────────────────────────────────────────────────────┘
```

## 7. กลยุทธ์การตอบคำถามผู้ตรวจประเมินหมวดกระบวนการผลิต (Audit FAQs)

> **คำถามผู้ตรวจ 1:** *\"หากช่างประจำสถานีบัดกรีเตาลาหยุดกะทันหัน หัวหน้างานสามารถนำพนักงานจากแผนกแพ็คกิ้งมาทำหน้าที่แทนชั่วคราวได้หรือไม่?\"*  
> **คำตอบที่ถูกต้อง:** *\"ไม่ได้เด็ดขาดครับ กระบวนการบัดกรีเตาเป็นกระบวนการพิเศษ (Special Process) พนักงานที่ทำหน้าที่แทนจะต้องเป็นผู้ที่มีชื่ออยู่ในทะเบียน Skill Matrix ระดับ 3 ขึ้นไป และมีบัตรรับรองช่างบัดกรีเตาที่ยังไม่หมดอายุเท่านั้นครับ หากไม่มีช่างสำรองที่ผ่านการรับรอง จะต้องระงับการเดินเตาจนกว่าจะมีช่างที่ถูกต้องครับ\"*

> **คำถามผู้ตรวจ 2:** *\"โรงงานทราบได้อย่างไรว่า ชิ้นงานที่กองอยู่ตรงนี้เป็นงานที่ผลิตเสร็จแล้ว หรือเป็นงานที่รอการตรวจสอบ?\"*  
> **คำตอบที่ถูกต้อง:** *\"เราสังเกตได้จากป้ายชี้บ่งสถานะประจำกล่องและตำแหน่งการจัดวางครับ กล่องนี้มีป้ายสีเขียวระบุรหัสชิ้นงาน หมายเลขล็อต จำนวน และมีตราประทับ 'INSPECTED & PASSED' พร้อมวางอยู่ในช่องตารางสีเขียวสำหรับงานดีครับ ส่วนงานรอตรวจจะมีป้ายสีเหลืองวางในช่องรอตรวจอย่างชัดเจน ไม่มีการปะปนกันครับ\"*
