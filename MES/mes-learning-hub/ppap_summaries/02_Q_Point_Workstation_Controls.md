# คู่มือจุดควบคุมคุณภาพวิกฤตหน้างาน (Shopfloor Q-Points & Quality Station Controls)
**สายการผลิต:** คอนเดนเซอร์อลูมิเนียม (Aluminium Condenser Line)
**รหัสเอกสารอ้างอิง:** เอกสารจุดควบคุมคุณภาพ Q-Point 030 - 035 (P:\ISO\PPAP\Q-Point)
**มาตรฐานสากลอ้างอิง:** IATF 16949 / ISO 9001:2015 ข้อ 8.5.1 การควบคุมการผลิตและบริการ

---

## 1. ความหมายและความสำคัญของ "Q-Point" (Quality Point)
**Q-Point (จุดควบคุมคุณภาพหน้างาน):** คือป้ายเตือนและมาตรฐานการตรวจสอบด้วยสายตา (Visual Control) ที่ติดตั้งอยู่ ณ ตำแหน่งสายตาของพนักงานประจำสถานีงาน เพื่อเน้นย้ำ **"จุดวิกฤตที่ห้ามผิดพลาดเด็ดขาด"** โดยอ้างอิงจากบทเรียนข้อผิดพลาดในอดีต (Lessons Learned) และผลการประเมิน PFMEA

---

## 2. กฎเหล็กคุณภาพ 3 ประการ (The 3-No Quality Principles)
พนักงานผู้ปฏิบัติงานทุกคนต้องยึดถือหลักการ:
1. **ไม่รับของเสีย (Do NOT Accept Defective Parts):** ตรวจสอบวัตถุดิบและชิ้นส่วนจากกระบวนการก่อนหน้าก่อนนำมาประกอบ หากพบตำหนิหรือขนาดผิดเพี้ยน ให้ปฏิเสธและแยกใส่กรงแดง (Red Bin) ทันที
2. **ไม่สร้างของเสีย (Do NOT Make Defective Parts):** ปฏิบัติตามขั้นตอนในคู่มือการทำงาน (WI) อย่างเคร่งครัด ใช้อุปกรณ์ จิ๊ก และแรงดันตามที่กำหนด ห้ามลัดขั้นตอนโดยเด็ดขาด
3. **ไม่ส่งของเสีย (Do NOT Pass Defective Parts):** ตรวจสอบชิ้นงานของตนเอง 100% ตามจุด Q-Point ก่อนส่งมอบให้สถานีถัดไป หากไม่แน่ใจให้ใช้หลักการ **"หยุด - เรียก - รอ (Stop - Call - Wait)"** ทันที

## 3. รายละเอียดจุดตรวจ Q-Point ประจำสถานีงาน (Station Q-Points)

### Q-Point 030: Partition & Header Cap Assembly (สถานีประกอบพาร์ติชันและฝาปิดเฮดเดอร์)
- **จุดตรวจสอบวิกฤต:**
  1. *การลงสนิทของ End Cap:* ฝาปิดปลายท่อ End Cap ทั้ง 4 จุด ต้องสวมลงสนิทแนบกับท่อ Header Pipe ห้ามเผยอหรือเอียง
  2. *ตำแหน่ง Partition:* แผ่นกั้นวงจรน้ำยา (Partition) ทั้ง 3 จุด ต้องประกอบตรงตำแหน่งร่องสลิตและลงสนิท
  3. *การมาร์กสี:* ตรวจสอบการทำเครื่องหมายสี (Color Mark) เพื่อยืนยันว่าใส่พาร์ติชันครบถ้วนตามแบบวงจร

### Q-Point 031: Header & Tube Assembly (สถานีประกอบท่อแบนและเฮดเดอร์)
- **จุดตรวจสอบวิกฤต:**
  1. *ความลึกในการสวม Tube เข้า Header:* ท่อแบน (Flat Tube) ต้องสอดเข้าไปในร่องเฮดเดอร์ถึงระยะบ่า Stopper ทุกเส้น ห้ามสอดตื้นหรือเอียง
  2. *รอยบิดเบี้ยวของร่อง Tube:* ร่องรับท่อต้องไม่ฉีกขาด ไม่บี้แบน และไม่มีเศษเสี้ยนโลหะขวางทางเดินท่อ
  3. *ความขนานและความฉาก:* โครงสร้างแกนคอยล์ต้องได้ฉาก ไม่บิดเป็นรูปสี่เหลี่ยมด้านขนาน

### Q-Point 032: Press Forming (สถานีปั๊มขึ้นรูปพาร์ติชันและชิ้นส่วนย่อย)
- **จุดตรวจสอบวิกฤต:**
  1. *ความสมบูรณ์ของขอบชิ้นงาน:* ขอบต้องเรียบ ไม่มีเศษครีบคม (Burrs) เกินค่ามาตรฐาน
  2. *ความลึกและการโค้งงอ:* ตรวจสอบขนาดความลึกด้วยเกจวัด (Go/No-Go Gauge)
  3. *รอยแตกร้าว (Cracks):* บริเวณมุมโค้งต้องไม่มีรอยร้าวขนาดเล็กที่อาจทำให้เกิดการรั่วซึมภายหลัง

### Q-Point 033: Piercing (สถานีเจาะรูท่อเฮดเดอร์)
- **จุดตรวจสอบวิกฤต:**
  1. *เศษอลูมิเนียมขอบรูเจาะ:* ขอบรูทางเข้าน้ำยาต้องผ่านการลบคม (Chamfer) 100% ไม่มีเศษครีบติดค้าง
  2. *ระยะห่างระหว่างรู:* ระยะจากปลายท่อถึงจุดศูนย์กลางรูเจาะต้องตรงตาม Drawing (สุ่มตรวจด้วยเวอร์เนียร์คาลิปเปอร์)
  3. *ความกลมและผิวสัมผัส:* รูต้องกลม ไม่เป็นวงรี เพื่อให้สวมกับท่อต่อ (Joint Pipe) ได้แนบสนิท

### Q-Point 034: Slit Forming (สถานีผ่าร่องสลิตท่อเฮดเดอร์)
- **จุดตรวจสอบวิกฤต:**
  1. *ความลึกของร่องสลิต (Slit Depth):* ต้องผ่าถึงระยะที่กำหนดเพื่อรับแผ่นกั้นวงจร หากตื้นเกินไปพาร์ติชันจะลงไม่สุด หากลึกเกินไปท่อจะขาดความแข็งแรง
  2. *ทิศทางการผ่า (Left vs Right):* ตรวจสอบมาร์กสีที่ปลายท่อเพื่อยืนยันว่าผ่าถูกด้าน (ฝั่ง L หรือ R) ห้ามสลับข้างเด็ดขาด
  3. *ความสะอาดของร่อง:* ร่องต้องปราศจากเศษผงโลหะอุดตัน

### Q-Point 035: Fin Forming (สถานีขึ้นรูปลอนฟิน)
- **จุดตรวจสอบวิกฤต:**
  1. *ระยะพิตช์ของฟิน (Fin Pitch):* จำนวนลอนฟินต่อระยะ 1 นิ้ว (Fins Per Inch - FPI) ต้องตรงตามมาตรฐาน
  2. *ความสูงของฟิน (Fin Height):* ต้องสม่ำเสมอตลอดแนวม้วนฟิน
  3. *สภาพผิวฟิน:* ห้ามมีรอยพับ รอยย่น หรือรอยล้มของลอนระบายความร้อน (Louver)

## 4. มาตรการควบคุมเมื่อเกิดความผิดปกติ (Abnormal Response Protocol)
เมื่อพนักงานพบชิ้นงานที่ไม่สอดคล้องตามจุด Q-Point:
```
[พบชิ้นงานผิดปกติ/มีตำหนิ]
           │
           ▼
1. หยุด (STOP)       --> หยุดเครื่องจักรและหยุดการทำงานทันที
           │
           ▼
2. เรียก (CALL)      --> แจ้งหัวหน้างาน (Leader/Supervisor) และ QC ทันที
           │
           ▼
3. รอ (WAIT)        --> คัดแยกชิ้นงานเสียลง Red Bin รอการตัดสินใจและห้ามส่งต่อ
           │
           ▼
[ตรวจสอบสาเหตุ 4M1E + ออกใบ NC/CAR + ปรับปรุงก่อนเดินเครื่องต่อ]
```
