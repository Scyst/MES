# คู่มือมาตรฐานการบรรจุหีบห่อและการจัดส่ง (Standard Packaging and Shipping Specification)
**สายการผลิต:** คอนเดนเซอร์อลูมิเนียม (Aluminium Micro Channel Condenser Line)
**รหัสเอกสารอ้างอิง:** STD. Packing -Condensor.pdf (P:\ISO\PPAP)
**มาตรฐานสากลอ้างอิง:** ISO 9001:2015 ข้อ 8.5.4 การสงวนรักษา (Preservation) / มาตรฐานบรรจุภัณฑ์สำหรับชิ้นส่วนปรับอากาศและยานยนต์

---

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนและข้อกำหนดมาตรฐานในการบรรจุหีบห่อ การเรียงซ้อน การรัดตรึง และการติดป้ายชี้บ่งสินค้าสำเร็จรูปบนพาเลท เพื่อป้องกันความเสียหาย การบิดเบี้ยว การล้มของครีบฟิน และการปนเปื้อนความชื้นหรือฝุ่นละอองระหว่างการจัดเก็บและการขนส่ง
- **ขอบเขต:** ครอบคลุมผลิตภัณฑ์คอนเดนเซอร์ไมโครแชนแนลทุกรุ่น (เช่น รหัสโมเดล `SC10G-HE01130` / `S200-0021-0183-00` ขนาด 9K, 12K, 16K) ตั้งแต่สิ้นสุดสายการผลิตจนถึงการส่งมอบ ณ โรงงานลูกค้า

## 2. ข้อมูลจำเพาะของบรรจุภัณฑ์และพาเลท (Packaging & Pallet Specifications)
| รายการ | ข้อมูลจำเพาะตามมาตรฐาน (Standard Specification) |
| :--- | :--- |
| **ชนิดของพาเลท (Pallet Type)** | พาเลทพลาสติก (Plastic Pallet) หรือ พาเลทไม้รมยามาตรฐาน IPPC (ISPM 15) |
| **ขนาดของพาเลท (Dimension)** | กว้าง $1,100\text{ mm} \times$ ยาว $1,200\text{ mm} \times$ สูง $130\text{ mm}$ |
| **จำนวนบรรจุต่อพาเลท (Quantity)** | **30 ชิ้น / พาเลท (30 Pcs / Pallet)** |
| **น้ำหนักชิ้นงานต่อชิ้น (Unit Weight)** | ประมาณ $2.6\text{ kg} / \text{ชิ้น}$ |
| **น้ำหนักรวมต่อพาเลท (Gross Weight)** | ประมาณ **$93\text{ kg}$** (รวมชิ้นงาน 30 ชิ้น + กล่อง + พาเลท) |
| **วัสดุป้องกันภายใน (Protection)** | กระดาษลูกฟูกรองฟิน, กระดาษรองท่อเฮดเดอร์, กระดาษฉากกันกระแทกมุม |
| **การรัดตรึง (Securing Method)** | สายรัดพลาสติก PP Band ด้วยเครื่องรัดอัตโนมัติ และฟิล์มยืดพันพาเลท (Stretch Film) |

## 3. ลำดับขั้นตอนการบรรจุหีบห่อมาตรฐาน (Packaging Step-by-Step)

```
[วางกระดาษลูกฟูกรองพื้นพาเลท]
               │
               ▼
[จัดเรียงคอนเดนเซอร์เป็นชั้นๆ สลับกระดาษรองฟิน & รอง Header]
               │
               ▼
[บรรจุครบ 30 ชิ้น ตรวจสอบความเรียบตรงและจำนวน]
               │
               ▼
[ติดตั้งกระดาษฉากกันกระแทกทั้ง 4 มุม + ปิดฝาครอบด้านบน]
               │
               ▼
[รัดสายรัดพลาสติก PP Band แน่นหนา ไม่ให้ขยับ]
               │
               ▼
[พันฟิล์มยืด (Stretch Film) รอบพาเลทอย่างน้อย 3-5 รอบ ป้องกันฝุ่นและความชื้น]
               │
               ▼
[ติดป้าย Delivery Tag Card / Shipping Label ที่ตำแหน่งด้านบนสุด]
```

### 3.1 รายละเอียดการป้องกันชิ้นงานแต่ละชั้น (Layer Protection)
1. **กระดาษรองฟิน (Fin Separator):** วางแผ่นกระดาษลูกฟูกคั่นระหว่างแถว เพื่อป้องกันไม่ให้ครีบฟินระบายความร้อนสัมผัสและกระแทกกันจนล้ม
2. **กระดาษรองเฮดเดอร์ (Header Support):** รองรับส่วนท่อเฮดเดอร์และท่อเชื่อมต่อเพื่อป้องกันการรับน้ำหนักกดทับโดยตรง
3. **กระดาษฉากมุม (Corner Edge Protectors):** ติดตั้งกระดาษฉากแข็งทั้ง 4 มุม เพื่อกระจายแรงกดของสายรัด ไม่ให้สายรัดบาดเข้าเนื้อชิ้นงานอลูมิเนียม

## 4. มาตรฐานป้ายชี้บ่งสินค้าและการจัดส่ง (Delivery Tag Card & Labeling)
ป้ายชี้บ่งที่ติดบนพาเลท ต้องมีข้อมูลครบถ้วน ชัดเจน และอ่านออกได้ง่าย โดยมีรายละเอียดดังนี้:
1. **CUSTOMER (ชื่อลูกค้า):** ระบุชื่อบริษัทลูกค้า เช่น SNC / Fujitsu / Daikin
2. **PART NAME (ชื่อชิ้นส่วน):** COND MICRO CHANEL (ขนาด BTU)
3. **PART NUMBER SCAN / CUSTOMER:** รหัสชิ้นส่วนของบริษัทและรหัสของลูกค้า (เช่น `SC10G-HE01130` / `S200-0021-0183-00`)
4. **Q'TY (จำนวนบรรจุ):** 30 PCS.
5. **PO NO. (เลขที่ใบสั่งซื้อ):** ระบุหมายเลข PO ชัดเจน
6. **LOT NUMBER (หมายเลขล็อต):** รหัสล็อตการผลิตตามมาตรฐาน `HVAC-QA-FM-047` (เช่น `CD10-01 --> A001`)
7. **INSPECTOR (ผู้ตรวจสอบ):** ลงชื่อหรือรหัสพนักงาน QC ผู้ตรวจสอบขั้นสุดท้าย
8. **DELIVERY DATE & TIME:** วันที่และเวลาส่งมอบตามแผน
9. **ตำแหน่งการติดป้าย:** ติดที่ตำแหน่ง **ด้านบนกึ่งกลางพาเลท (หันออกด้านนอก)** เพื่อให้พนักงานขับโฟล์คลิฟต์และเจ้าหน้าที่ตรวจรับสามารถสแกนบาร์โค้ดได้ทันทีโดยไม่ต้องปีนหรือรื้อค้น

## 5. กฎระเบียบในการจัดเก็บและการเคลื่อนย้าย (Storage & Handling Guidelines)
- **การใช้รถยก (Forklift / Pallet Jack):** สอดงาให้สุดความลึกของพาเลท ยกขึ้นอย่างนุ่มนวล ห้ามกระแทกหรือลากพาเลทไปกับพื้น
- **การวางซ้อนในคลังสินค้า (Stacking Limit):**
  - อนุญาตให้วางซ้อนได้สูงสุด **ไม่เกิน 2 ชั้น (Max 2 High)** บนพื้นราบเรียบในคลังสินค้าที่แห้งและมีหลังคาคลุม
  - **ห้ามวางซ้อนระหว่างการขนส่งบนรถบรรทุกเด็ดขาด (Single Layer in Transit)**
- **การป้องกันสภาวะแวดล้อม:** ต้องจัดเก็บในพื้นที่ที่ไม่มีละอองฝน ความชื้นสูง หรือสารเคมีที่มีฤทธิ์กัดกร่อนอลูมิเนียม
