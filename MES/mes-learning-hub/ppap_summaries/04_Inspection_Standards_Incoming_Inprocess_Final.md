# คู่มือมาตรฐานการตรวจสอบคุณภาพชิ้นงาน (Inspection Quality Standards: Incoming, In-process, Final)
**สายการผลิต:** คอนเดนเซอร์อลูมิเนียม (Aluminium Condenser Line)
**รหัสเอกสารอ้างอิง:** CH-QCS-052, CH-QCS-056, CH-QCS-057, CH-QCS-062, FM-QCS-017 (P:\ISO\PPAP)
**มาตรฐานสากลอ้างอิง:** ISO 9001:2015 ข้อ 8.6 การปล่อยผลิตภัณฑ์และบริการ / MIL-STD-105E / ANSI ASQ Z1.4

---

## 1. โครงสร้างระบบการตรวจสอบคุณภาพ 3 ด่านหลัก (3-Tier Inspection System)
การควบคุมคุณภาพการผลิตคอนเดนเซอร์ไมโครแชนแนล แบ่งออกเป็น 3 ด่านเข้มงวดเพื่อสกัดกั้นของเสีย:
1. **การตรวจสอบวัตถุดิบและชิ้นส่วนรับเข้า (Incoming Inspection - IQC):** ตรวจม้วนฟอยล์, ท่อ, แผ่นประกบ, สารเคมี
2. **การตรวจสอบระหว่างกระบวนการผลิต (In-Process Inspection - IPQC):** บันทึกลง Inspection Quality Sheet (IQS) ในแต่ละสถานี
3. **การตรวจสอบผลิตภัณฑ์สำเร็จรูปขั้นสุดท้าย (Final Inspection - FQC):** ตรวจสอบ 100% Visual และ Full Layout Dimension ก่อนบรรจุหีบห่อ

---

## 2. การตรวจสอบระหว่างกระบวนการผลิต (In-Process Inspection Sheets - IQS)

### 2.1 งานตัดท่อเฮดเดอร์ (Cutting Header Pipe — CH-QCS-052)
- **เครื่องมือวัด:** เวอร์เนียร์คาลิปเปอร์ (Vernier Caliper), โปรแทรกเตอร์วัดมุม (Protractor)
- **พารามิเตอร์ที่ต้องตรวจและบันทึก:**
  - ความยาวท่อ (Length): ต้องตรงตามค่าใน Drawing พร้อมค่าพิกัดความเผื่อ (Tolerance)
  - ความตั้งฉากของรอยตัด (Squareness): มุมตัดต้องได้ 90° ± 0.5°
  - สภาพขอบตัด: ต้องไม่มีเศษเสี้ยนคม และท่อต้องไม่บี้แบน
- **ความถี่ในการสุ่มตรวจ:** ชิ้นแรกของการเปิดกะ (First Piece), ทุกๆ 2 ชั่วโมง, และชิ้นสุดท้ายก่อนเลิกงาน (Last Piece)

### 2.2 งานขึ้นรูปครีบฟิน (Fin Forming — CH-QCS-056)
- **เครื่องมือวัด:** บรรทัดวัดพิตช์ (Pitch Gauge), ไมโครมิเตอร์วัดความหนา, ไฮต์เกจ (Height Gauge)
- **พารามิเตอร์ที่ต้องตรวจและบันทึก:**
  - จำนวนลอนฟินต่อระยะ (Fin Pitch / FPI): สุ่มนับความหนาแน่นของลอนให้ตรงตาม Drawing
  - ความสูงของครีบฟิน (Fin Height): ควบคุมไม่ให้เกินพิกัด ± 0.1 mm
  - ความสะอาดและคราบน้ำมัน: ตรวจเช็คว่าไม่มีสิ่งแปลกปลอมเกาะติด

### 2.3 งานปั๊มขึ้นรูปพาร์ติชัน (Partition Forming — CH-QCS-057)
- **เครื่องมือวัด:** เกจวัดความหนา (Thickness Gauge), เกจวัดขนาด (Plug / Snap Gauge)
- **พารามิเตอร์ที่ต้องตรวจและบันทึก:**
  - ความกว้างและความหนาของแผ่นพาร์ติชัน
  - ความโค้งงอและการขึ้นรูปบ่าล็อก: ต้องประกอบเข้ากับร่องสลิตของท่อเฮดเดอร์ได้พอดี ไม่หลวมและไม่คับเกินไป

## 3. มาตรฐานการตรวจสอบผลิตภัณฑ์สำเร็จรูป (Final Inspection Standard — CH-QCS-062 / FM-QCS-017)
ผลิตภัณฑ์คอนเดนเซอร์สำเร็จรูป (CONDENSER ASSY รหัสโมเดล เช่น `SC10G-HE01150`) ทุกชิ้นต้องผ่านเกณฑ์การตรวจสอบดังนี้:

### 3.1 การตรวจสอบทางกายภาพด้วยสายตา 9 รายการ (Appearance & Visual Check 100%)
| ลำดับ | จุดตรวจสอบ | เกณฑ์มาตรฐานการตัดสิน (Standard & Criteria) | เครื่องมือตรวจ |
| :---: | :--- | :--- | :---: |
| **1.1** | **ฝาปิดปลายท่อ (End Cap)** | ต้องมี End Cap ครบทั้ง 4 จุด และต้องสวมลงสนิทแนบกับ Header Pipe | สายตา (Visual) |
| **1.2** | **แผ่นกั้นวงจร (Partition)** | ต้องมี Partition ครบทั้ง 3 จุด และลงสนิทในร่องสลิตอย่างสมบูรณ์ | สายตา (Visual) |
| **1.3** | **ครีบระบายความร้อน (Fin)** | ลอนฟินต้องเรียบสวยงาม ไม่เอียง ไม่นูน ไม่ล้ม ไม่มีรอยไหม้ และไม่มีคราบฟลักซ์ตกค้าง | สายตา (Visual) |
| **1.4** | **ข้อต่อท่อ (Joint Pipe)** | รอยแล่นประสาน (Brazing) ต้องเชื่อมประสานสนิทรอบท่อ Header Pipe ไม่มีตามด (Pinhole) | สายตา (Visual) |
| **1.5** | **คราบน้ำยาฟลักซ์ (Flux Residue)** | คราบฟลักซ์ต้องไม่เกาะหนา เลอะเทอะ หรือเป็นแผ่นสะเก็ด | สายตา (Visual) |
| **1.6** | **ฝาครอบพลาสติกกันฝุ่น (Cap Pipe)** | ฝาพลาสติกปิดปลายท่อต้องไม่มีรอยไหม้จากเตาอบ และไม่มีรอยฉีกขาด | สายตา (Visual) |
| **1.7** | **ระยะห่างพาร์ติชัน (Partition Pitch)** | ระยะพิตช์ตำแหน่งแผ่นกั้นต้องตรงตามที่กำหนดไว้ใน Drawing | สายตา (Visual) |
| **1.8** | **การมาร์กสีแผ่นข้าง (Side Plate Mark)** | **ต้องมี MARK สีน้ำเงินจากกระบวนการผลิต ครบทุกจุด (รวม 9 จุด)** | สายตา (Visual) |
| **1.9** | **ป้ายสินค้า (Label)** | ต้องมีป้าย Label ระบุ Part No., Lot No. ชัดเจน และติดแน่นไม่หลุดลอก | สายตา (Visual) |

### 3.2 การตรวจสอบขนาดและมิติวิกฤต (Critical Dimension Check)
- **มิติที่ 1 (ความยาวรวม):** พิกัดสูงสุดไม่เกิน **505.00 mm (MAX)**
- **มิติที่ 2 (ความกว้าง/ความสูงของแผง):** พิกัด **501.00 ± 2.00 mm**
- **มิติที่ 3 (ระยะกึ่งกลางรูยึดโครงสร้าง):** พิกัด **480.20 ± 1.50 mm**

## 4. เกณฑ์การตัดสินคุณภาพและการจัดการชิ้นงานเสีย (Quality Judgment & Disposition)
- **เกณฑ์การตัดสิน (Acceptance Criteria):**
  - ข้อบกพร่องด้านมิติวิกฤตและรอยรั่ว: **เกณฑ์ $Ac = 0, Re = 1$ (Zero Defects)** หากพบของเสียเพียง 1 ชิ้น ให้ตัดสินว่ารุ่นการผลิตนั้น **"ไม่ผ่าน (REJECT)"** ทันที
- **ขั้นตอนเมื่อพบของเสีย (NG Disposition):**
  1. กักแยกชิ้นงานเสียลงใน **พื้นที่กักกันสีแดง (Red Quarantine Zone)**
  2. พ่นสีหรือติดป้ายสีแดง "REJECT / NG" ชัดเจน ห้ามปะปนกับสินค้าดี
  3. บันทึกรายละเอียดลงในระบบและแจ้งฝ่ายผลิตเพื่อเปิดการสอบสวนข้อบกพร่อง (NC/CAR) ตามระเบียบ SP-LAB-002
