# คู่มือการควบคุมล็อตสินค้าและการสืบย้อนกลับ (Lot Control and Traceability System)
**สายการผลิต:** คอนเดนเซอร์อลูมิเนียม (Aluminium Condenser Line)
**รหัสเอกสารอ้างอิง:** HVAC-QA-FM-047 Rev.00 (P:\ISO\PPAP\Lot Control.xlsx) และ STD. Packing -Condensor.pdf
**มาตรฐานสากลอ้างอิง:** ISO 9001:2015 ข้อ 8.5.2 การชี้บ่งและการสืบย้อนกลับ (Identification and Traceability) / IATF 16949

---

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดระบบการให้รหัสรุ่นการผลิต (Lot Numbering) การติดป้ายชี้บ่งสถานะ และการเก็บบันทึกประวัติคุณภาพในทุกขั้นตอนการผลิต เพื่อสร้างความมั่นใจว่าสามารถสืบย้อนกลับ (Traceability) ได้อย่างสมบูรณ์แบบ 100% ทั้งแบบย้อนรอยหาวัตถุดิบ (Backward Traceability) และตามรอยสินค้าสำเร็จรูป (Forward Traceability) เมื่อเกิดข้อร้องเรียนหรือพบความผิดปกติ
- **ขอบเขต:** ครอบคลุมตั้งแต่การรับวัตถุดิบ (ม้วนฟอยล์อลูมิเนียม, ท่อ, แผ่นประกบ), ชิ้นส่วนกึ่งสำเร็จรูป (WIP), จนถึงพาเลทสินค้าสำเร็จรูปส่งออก

## 2. โครงสร้างการถอดรหัสหมายเลขล็อต (Lot Number Decoding Structure)
หมายเลขล็อตผลิตภัณฑ์คอนเดนเซอร์ถูกกำหนดขึ้นตามหลักมาตรฐานสากล โดยมีโครงสร้างดังนี้:

$$\mathbf{C}\quad\mathbf{D}\quad\mathbf{10}-\mathbf{01}\quad\rightarrow\quad\mathbf{A}\quad\mathbf{001}$$

| รหัส | ความหมาย | รายละเอียดและตัวอย่างการแปลงค่า |
| :---: | :--- | :--- |
| **C** | **ประเภทผลิตภัณฑ์ (Product Type)** | `C` = Condenser (คอนเดนเซอร์ไมโครแชนแนล) |
| **D** | **ปีที่ทำการผลิต (Production Year)** | ใช้ตัวอักษรแทนปี ค.ศ. เช่น:<br>• `D` = 2020<br>• `E` = 2021<br>• `F` = 2022<br>• `G` = 2023<br>• `H` = 2024<br>• `J` = 2025<br>• `K` = 2026 |
| **10** | **เดือนที่ทำการผลิต (Month)** | `01` ถึง `12` (เช่น `10` = เดือนตุลาคม) |
| **01** | **วันที่ทำการผลิต (Date)** | `01` ถึง `31` (เช่น `01` = วันที่ 1 ของเดือน) |
| **A** | **ชนิดของวัตถุดิบ (Material Code)** | `A` = Aluminium (อลูมิเนียมเกรดพิเศษ) |
| **001** | **ลำดับล็อตการผลิตประจำวัน (Daily Running Lot)** | เริ่มต้นนับจาก `001`, `002`, `003`... ในแต่ละวัน |

> **ตัวอย่าง:** รหัสล็อต `CK10-14 --> A002` หมายถึง: ผลิตภัณฑ์คอนเดนเซอร์ (C) ผลิตในปี 2026 (K) เดือนตุลาคม (10) วันที่ 14 (14) วัตถุดิบทำจากอลูมิเนียม (A) เป็นล็อตการผลิตลำดับที่ 2 ของวัน

## 3. ห่วงโซ่การสืบย้อนกลับ 2 ทิศทาง (Two-Way Traceability Chain)

### 3.1 การสืบย้อนกลับแบบย้อนรอย (Backward Traceability / Root Cause Hunting)
เมื่อลูกค้าตรวจพบปัญหาการรั่วไหล หรือ Claim ผลิตภัณฑ์ในตลาด:
1. **อ่านรหัส Serial No. / Lot No. จากป้ายบาร์โค้ดบนตัวคอนเดนเซอร์**
2. ค้นหาประวัติบันทึกการผลิตในระบบ MES / แบบฟอร์มการตรวจสอบคุณภาพ:
   - ตรวจสอบผลการทดสอบการรั่วด้วยก๊าซฮีเลียม (Helium Leak Test Data Sheet)
   - ตรวจสอบรอบเวลาและกราฟอุณหภูมิของเตาอบแล่นประสาน (CAB Brazing Furnace Temperature Log)
   - ตรวจสอบกะการผลิต รหัสเครื่องจักร และรายชื่อพนักงานผู้ประกอบ (Core Assembly Operator ID)
   - ตรวจสอบใบ Inspection Quality Sheet (IQS) ในแต่ละกระบวนการตัด ขึ้นรูป และล้างทำความสะอาด
3. สืบย้อนกลับถึง **"ล็อตของวัตถุดิบตั้งต้น (Raw Material Coil Lot No.)"** จาก Supplier ผู้จัดส่ง เพื่อวิเคราะห์ความผิดปกติของเกรดสารเคมีหรือเนื้อโลหะ

### 3.2 การสืบย้อนกลับแบบตามรอย (Forward Traceability / Containment & Recall)
เมื่อหน่วยงาน QC ตรวจพบว่าวัตถุดิบล็อตใดล็อตหนึ่ง หรือการปรับตั้งพารามิเตอร์เตาอบในช่วงเวลาใดเวลาหนึ่งมีความผิดปกติ:
1. ดึงข้อมูลประวัติการใช้วัตถุดิบล็อตดังกล่าวจากระบบ
2. ชี้บ่งสินค้าทุกชิ้นที่ใช้วัตถุดิบหรือผ่านกระบวนการที่มีปัญหาทันที
3. ตรวจสอบสถานะสต็อกในคลังสินค้า (Visual Warehouse Map / Onhand Inventory):
   - หากยังอยู่ในคลัง: ออกคำสั่งอายัด (Hold) และติดป้ายสีแดงห้ามส่งมอบ
   - หากอยู่ระหว่างขนส่งหรือส่งถึงลูกค้าแล้ว: แจ้งลูกค้าพร้อมระบุหมายเลขพาเลทและหมายเลขกล่องที่ต้องเรียกคืน (Containment & Recall) ได้อย่างแม่นยำ ไม่ต้องเรียกรวมทั้งหมด
