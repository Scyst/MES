# มาตรฐานโรงงานเชิงนิเวศ อุตสาหกรรมสีเขียว และคาร์บอนฟุตพริ้นท์ (Eco Factory & ESG)
**มาตรฐานอ้างอิง:** 
- ใบรับรองโรงงานเชิงนิเวศ (Eco Factory Certificate - การนิคมอุตสาหกรรมแห่งประเทศไทย / สภาอุตสาหกรรมฯ)
- ใบรับรองอุตสาหกรรมสีเขียว ระดับที่ 3: ระบบสีเขียว (Green Industry Level 3 - GI3 กระทรวงอุตสาหกรรม)
- ระบบการจัดการก๊าซเรือนกระจกและคาร์บอนเครดิต (GHG Inventory & iCarbon Credit Program)
- รายงานผลการตรวจวัดคุณภาพสิ่งแวดล้อมตามกฎหมาย: คุณภาพอากาศจากปล่อง และคุณภาพน้ำทิ้งอุตสาหกรรม (`ผลตรวจวัด 30.06.69`)
- ระเบียบปฏิบัติการจัดการของเสียและกากอุตสาหกรรม (`SNC-EP-SHE-05 Rev.03`)

---

## 1. วัตถุประสงค์และขอบเขต (Purpose & Strategic Value)

ในยุคปัจจุบัน ลูกค้าระดับโลก (Global Brands & Retailers) ให้ความสำคัญอย่างยิ่งยวดกับประเด็นด้าน **ESG (Environmental, Social, and Governance)** และการลดการปล่อยก๊าซเรือนกระจก (Decarbonization) โรงงานผู้ผลิตที่ต้องการรักษาคำสั่งซื้อระยะยาวจะต้องพิสูจน์ให้เห็นถึง:
1. **ความเป็นมิตรต่อสิ่งแวดล้อมที่จับต้องได้:** ผ่านการรับรองระดับประเทศ เช่น **Eco Factory** และ **Green Industry ระดับ 3**
2. **ความโปร่งใสของข้อมูลการปล่อยคาร์บอน (Carbon Transparency):** มีการจัดทำบัญชีก๊าซเรือนกระจก (GHG Inventory) ครอบคลุม Scope 1, Scope 2, และ Scope 3
3. **การปฏิบัติตามกฎหมายสิ่งแวดล้อมไทย 100%:** มีผลตรวจวัดมลพิษทางอากาศจากปล่องระบาย และคุณภาพน้ำทิ้งจากห้องแล็บที่ขึ้นทะเบียนอย่างเป็นทางการ

## 2. การรับรองโรงงานเชิงนิเวศ (Eco Factory Certification)

บริษัท อินฟินิตี้ พาร์ท จำกัด (IPC / SNC Group) ได้รับการรับรองมาตรฐาน **Eco Factory (โรงงานเชิงนิเวศ)** จากการนิคมอุตสาหกรรมแห่งประเทศไทย (กนอ.) และสถาบันน้ำและสิ่งแวดล้อมเพื่อความยั่งยืน สภาอุตสาหกรรมแห่งประเทศไทย โดยผ่านเกณฑ์การประเมิน 5 มิติหลัก:

```
[5 มิติหลักของการเป็นโรงงานเชิงนิเวศ (Eco Factory Pillars)]
┌────────────────────────────────────────────────────────────────────────┐
│ 1. มิติด้านกายภาพ (Physical Dimension)                                  │
│    - ผังโรงงานมีความเป็นระเบียบ มีพื้นที่สีเขียว (Green Area) ไม่น้อยกว่า 10% │
│    - การใช้ประโยชน์จากที่ดินอย่างคุ้มค่า และการป้องกันกลิ่น/เสียงรบกวน      │
├────────────────────────────────────────────────────────────────────────┤
│ 2. มิติด้านเศรษฐกิจ (Economic Dimension)                               │
│    - การใช้วัตถุดิบและพลังงานอย่างมีประสิทธิภาพสูงสุด (Resource Efficiency)  │
│    - การลดต้นทุนการผลิตผ่านโครงการอนุรักษ์พลังงานและนวัตกรรมอัตโนมัติ      │
├────────────────────────────────────────────────────────────────────────┤
│ 3. มิติด้านสิ่งแวดล้อม (Environmental Dimension)                        │
│    - การทำสมดุลมวลสาร (Mass Balance) และสมดุลน้ำ (Water Balance)       │
│    - ของเสียจากกระบวนการผลิตต้องนำกลับมาใช้ประโยชน์ใหม่ (Zero Waste to Landfill)│
├────────────────────────────────────────────────────────────────────────┤
│ 4. มิติด้านสังคม (Social Dimension)                                    │
│    - การดูแลสุขอนามัยและความปลอดภัยของพนักงาน 100%                     │
│    - การสร้างความสัมพันธ์อันดีและส่งเสริมคุณภาพชีวิตของชุมชนรอบข้าง (CSR)   │
├────────────────────────────────────────────────────────────────────────┤
│ 5. มิติด้านการบริหารจัดการ (Management Dimension)                      │
│    - ระบบการบริหารที่โปร่งใส มีรายงานการตรวจประเมินสิ่งแวดล้อมสม่ำเสมอ │
│    - มีแผนบริหารความต่อเนื่องทางธุรกิจ (Business Continuity Plan - BCP) │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. อุตสาหกรรมสีเขียว ระดับที่ 3: ระบบสีเขียว (Green Industry Level 3 - GI3)

โรงงานได้รับการรับรอง **Green Industry ระดับที่ 3 (ระบบสีเขียว - Green System)** จากกระทรวงอุตสาหกรรม:
* **ความหมายของระดับที่ 3:** โรงงานมีการบริหารจัดการสิ่งแวดล้อมอย่างเป็นระบบ (Systematic Environmental Management) มีการติดตาม ตรวจสอบ และประเมินผลอย่างต่อเนื่อง เสมือนระบบ ISO 14001 แต่มีการเชื่อมโยงกับการปฏิบัติตามกฎหมายโรงงานของไทยอย่างเคร่งครัด
* **หลักฐานสำคัญที่ต้องรักษาไว้:**
  * ทะเบียนประเมินความสอดคล้องกับกฎหมายสิ่งแวดล้อม (`SNC-EP-SHE-04`) อัปเดตทุกปี
  * แผนปฏิบัติการลดการใช้พลังงานไฟฟ้าและน้ำประปา พร้อมบันทึกผลการติดตามรายเดือน
  * บันทึกการตรวจสอบภายในด้านสิ่งแวดล้อม (Internal Environmental Audit)

## 4. บัญชีก๊าซเรือนกระจกและการชดเชยคาร์บอน (GHG Inventory & iCarbon Credit)

เพื่อเตรียมความพร้อมสู่เป้าหมาย **ความเป็นกลางทางคาร์บอน (Carbon Neutrality)** โรงงานได้จัดทำระบบตรวจวัดและบริหารจัดการก๊าซเรือนกระจกผ่านโปรแกรม **iCarbon Credit**:

### การจัดหมวดหมู่การปล่อยก๊าซเรือนกระจก 3 ขอบเขต (The 3 GHG Scopes)
1. **ขอบเขตที่ 1: การปล่อยก๊าซเรือนกระจกทางตรง (Scope 1 - Direct Emissions):**
   - การเผาไหม้ก๊าซ LPG / ก๊าซธรรมชาติในเตาอบสีและเตาบัดกรีโลหะ
   - การใช้น้ำมันดีเซลในเครื่องกำเนิดไฟฟ้าสำรอง (Emergency Generator)
   - การรั่วไหลของสารทำความเย็น (Refrigerant Leakage: R32, R410A) จากกระบวนการทดสอบและเติมน้ำยา
2. **ขอบเขตที่ 2: การปล่อยก๊าซเรือนกระจกทางอ้อมจากการใช้พลังงาน (Scope 2 - Energy Indirect):**
   - ปริมาณการใช้พลังงานไฟฟ้าที่ซื้อจากการไฟฟ้าส่วนภูมิภาค (กฟภ.) ซึ่งเป็นแหล่งปล่อยคาร์บอนหลักของโรงงาน
   - *มาตรการลดคาร์บอน:* การติดตั้งระบบโซลาร์เซลล์บนหลังคาโรงงาน (Solar Rooftop) เพื่อผลิตไฟฟ้าพลังงานสะอาด
3. **ขอบเขตที่ 3: การปล่อยก๊าซเรือนกระจกทางอ้อมอื่นๆ (Scope 3 - Other Indirect):**
   - การขนส่งวัตถุดิบจากซัพพลายเออร์ และการขนส่งสินค้าสำเร็จรูปไปยังท่าเรือแหลมฉบัง

## 5. การตรวจสอบมลพิษทางกายภาพตามกฎหมาย (Statutory Compliance Monitoring)

ผู้ตรวจประเมินของลูกค้าสากลจะสุ่มตรวจ **รายงานผลการทดสอบจากห้องแล็บเอกชนที่ขึ้นทะเบียนกับกรมโรงงานอุตสาหกรรม** เพื่อพิสูจน์ว่าโรงงานไม่ปล่อยมลพิษเกินค่ามาตรฐาน:

| ประเภทมลพิษ (Pollution Type) | จุดตรวจวัด (Measurement Location) | พารามิเตอร์ที่ตรวจวัด (Parameters) | ค่ามาตรฐานตามกฎหมาย (Statutory Limit) |
| :--- | :--- | :--- | :--- |
| **1. คุณภาพอากาศจากปล่อง (Air Stack Emission)** | ปล่องระบายอากาศจากห้องพ่นสี และปล่องเตาอบความร้อน | • ฝุ่นละอองรวม (Total Suspended Particulate - TSP)<br>• ก๊าซซัลเฟอร์ไดออกไซด์ ($SO_2$)<br>• ก๊าซออกไซด์ของไนโตรเจน ($NO_x$)<br>• สารอินทรีย์ระเหยง่ายรวม (Total VOCs) | • TSP $< 320\text{ mg/m}^3$<br>• $SO_2 < 60\text{ ppm}$<br>• $NO_x < 200\text{ ppm}$<br>• ควบคุมระบบดักจับละอองสี (Wet Scrubber / Dry Filter) สม่ำเสมอ |
| **2. คุณภาพน้ำทิ้ง (Industrial Wastewater Effluent)** | บ่อบำบัดน้ำเสียรวม และจุดระบายน้ำทิ้งขั้นสุดท้ายก่อนปล่อยสู่ท่อสาธารณะ | • ค่าความเป็นกรด-ด่าง (pH: 5.5 - 9.0)<br>• บีโอดี (BOD $< 20\text{ mg/L}$)<br>• ซีโอดี (COD $< 120\text{ mg/L}$)<br>• ของแข็งแขวนลอย (TSS $< 50\text{ mg/L}$)<br>• โลหะหนัก (Heavy Metals: Cu, Ni, Cr, Zn) | ผลตรวจวิเคราะห์ล่าสุด ณ วันที่ **30.06.69** ผ่านเกณฑ์มาตรฐานน้ำทิ้งทุกรายการ 100% |
| **3. กากอุตสาหกรรมและของเสีย (Hazardous Waste Disposal)** | ลานกองขยะอุตสาหกรรมและบ่อกักสารเคมี | • การคัดแยกขยะตามรหัสของเสียกรมโรงงาน (Waste Codes)<br>• การว่าจ้างบริษัทรับกำจัดขยะที่ได้รับอนุญาต (ผู้รับกำจัดประเภท 101, 105, 106) | มีเอกสารใบกำกับการขนส่งของเสียอันตราย (**แบบ กอ.1 / สก.2**) บันทึกในระบบอิเล็กทรอนิกส์ครบทุกเที่ยว |

## 6. แนวทางการตอบคำถามผู้ตรวจประเมินหมวดสิ่งแวดล้อม (Audit FAQs)

> **คำถามผู้ตรวจ 1:** *\"โรงงานพิสูจน์ได้อย่างไรว่า กิจกรรมการผลิตไม่ปล่อยมลพิษทางอากาศเกินมาตรฐานที่กฎหมายกำหนด?\"*  
> **คำตอบที่ถูกต้อง:** *\"เรามีการตรวจวัดคุณภาพอากาศจากปล่องระบายอากาศเป็นประจำทุกปีโดยห้องปฏิบัติการที่ได้รับการขึ้นทะเบียนกับกรมโรงงานอุตสาหกรรมครับ โดยในรายงานผลตรวจวัดฉบับล่าสุด ค่าฝุ่นละออง (TSP) และค่าสารอินทรีย์ระเหยง่าย (VOCs) อยู่ในเกณฑ์มาตรฐาน และระบบบำบัดอากาศ Wet Scrubber มีการตรวจสอบบำรุงรักษาทุกสัปดาห์ตามแผน PM ครับ\"*

> **คำถามผู้ตรวจ 2:** *\"โรงงานจัดการกับกากตะกอนเคมีจากบ่อพ่นสีและน้ำเสียอย่างไร เพื่อป้องกันการลักลอบทิ้ง?\"*  
> **คำตอบที่ถูกต้อง:** *\"กากตะกอนเคมีทั้งหมดถูกจัดเก็บในถังปิดมิดชิดบนลานคอนกรีตที่มีเขื่อนกักกัน และส่งกำจัดผ่านบริษัทรับบำบัดกากอุตสาหกรรมที่ได้รับอนุญาตจากกรมโรงงานฯ เท่านั้นครับ โดยเรามีเอกสารใบกำกับการขนส่งอิเล็กทรอนิกส์ (Manifest กอ.1) ยืนยันการรับเข้าเตาเผาทำลายทุกเที่ยวอย่างโปร่งใสครับ\"*
