# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การควบคุมและการจัดเก็บบันทึกสิ่งแวดล้อม (Control of Records)
**รหัสเอกสาร:** ESP-EMR-007 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดวิธีรวบรวม ทำดัชนี จัดเรียงแฟ้ม จัดเก็บ ค้นหา บำรุงรักษา และทำลายบันทึกข้อมูลด้านสิ่งแวดล้อมให้เป็นระบบและตรวจสอบย้อนหลังได้
- **ขอบเขต:** ครอบคลุมบันทึกคุณภาพสิ่งแวดล้อมทุกประเภท ทั้งในรูปแบบเอกสารกระดาษและไฟล์อิเล็กทรอนิกส์

## 2. การขึ้นทะเบียนและการจัดเก็บบันทึก
1. **การชี้บ่งและขึ้นทะเบียน:** เจ้าของแบบฟอร์มต้องนำบันทึกมาขึ้นทะเบียนใน **"บัญชีรายชื่อบันทึกสิ่งแวดล้อม" (EF-DCO-018)** โดยระบุชื่อบันทึก รหัส วิธีจัดเก็บ สถานที่จัดเก็บ และระยะเวลาจัดเก็บขั้นต่ำ
2. **การจัดเรียงแฟ้ม (Filing):** แยกตามรหัสเอกสาร เรียงตามลำดับวันที่ปฏิบัติงาน และมีดัชนีคั่นหน้าเพื่อให้ค้นหาได้ง่าย
3. **การจัดเก็บ 2 ขั้นตอน (Storage):**
   - *จุดปฏิบัติงาน:* จัดเก็บเอกสารฉบับล่าสุดไว้ที่แผนก เพื่อความสะดวกในการหยิบใช้งาน
   - *สถานที่จัดเก็บถาวร:* เมื่อพ้นระยะเวลาใช้งานประจำวัน ให้ย้ายไปจัดเก็บบรรจุกล่องเอกสารที่ระบุชื่อแผนกและวันหมดอายุการจัดเก็บอย่างชัดเจน
4. **บันทึกอิเล็กทรอนิกส์ (Electronic Records):** กำหนดให้ต้องมีการ **สำรองข้อมูล (Back up) สำรองไว้อย่างน้อย 1 ชุดเสมอ** (ผ่านระบบ Cloud หรือ Server กลาง)

## 3. ขั้นตอนการทำลายเอกสารหมดอายุ (Record Disposal)
- เมื่อบันทึกครบกำหนดอายุการจัดเก็บตามที่ระบุในทะเบียน (ส่วนใหญ่คือ 5 ปี) ให้เขียน **"ใบขอทำลายเอกสาร" (EF-DCO-019)** เสนอผู้จัดการฝ่ายอนุมัติ
- วิธีการทำลาย: นำกลับมาใช้เป็นกระดาษรีไซเคิล, ฉีกทำลาย, เข้าเครื่องย่อยสลายเอกสาร หรือลบข้อมูลทิ้ง (กรณีไฟล์ดิจิทัล)

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** บัญชีรายชื่อบันทึกสิ่งแวดล้อม (EF-DCO-018), แบบฟอร์มการขอทำลายเอกสาร (EF-DCO-019)
- **ระยะเวลาการจัดเก็บ:** เอกสารทะเบียนและใบขอทำลายเก็บรักษาไว้เป็นเวลา **5 ปี**
