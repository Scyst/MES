# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การประเมินลักษณะปัญหาสิ่งแวดล้อม (Environmental Aspects Identification & Evaluation)
**รหัสเอกสาร:** ESP-EMR-002 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดกระบวนการชี้บ่งลักษณะปัญหาสิ่งแวดล้อม (Aspects) และผลกระทบต่อสิ่งแวดล้อม (Impacts) จากกระบวนการผลิต กิจกรรม และการบริการ เพื่อนำไปสู่การกำหนดวัตถุประสงค์และเป้าหมายในการลดมลพิษ
- **ขอบเขต:** ครอบคลุมทุกกิจกรรมใน 3 สภาวะ: **สภาวะปกติ (Normal - N)**, **สภาวะผิดปกติ (Abnormal - AB)**, และ **สภาวะฉุกเฉิน (Emergency - E)**

## 2. คำจำกัดความที่สำคัญ
- **ลักษณะปัญหาสิ่งแวดล้อม (Aspects):** สิ่งที่เกิดขึ้นจากการทำงานแล้วส่งผลต่อสิ่งแวดล้อม เช่น การใช้น้ำ, การใช้ไฟฟ้า, การปล่อยน้ำเสีย, การปล่อยควัน, การเกิดขยะอันตราย
- **ผลกระทบสิ่งแวดล้อม (Impacts):** ผลลัพธ์ที่ตามมาจากการเกิด Aspect นั้นๆ เช่น แหล่งน้ำเน่าเสีย, ทรัพยากรหมดไป, ดินปนเปื้อน
- **ลักษณะปัญหาสิ่งแวดล้อมที่มีนัยสำคัญ (Significant Aspects):** ประเด็นที่มีความรุนแรงสูง มีความเสี่ยงผิดกฎหมาย หรือกระทบต่อชุมชนอย่างมาก ซึ่งบริษัท **ต้องมีมาตรการจัดการเป็นพิเศษ**

## 3. ขั้นตอนการประเมินและการให้คะแนน (Evaluation Criteria)
หัวหน้าแผนกและตัวแทนสิ่งแวดล้อมจะร่วมกันประเมิน Aspect โดยใช้สูตร:
`ระดับคะแนน = (กฎหมาย + อากาศ + น้ำ + ดิน + การใช้ทรัพยากร) x ความถี่ในการเกิด`

### 🚩 เกณฑ์การตัดสินว่าเป็น "ปัญหามีนัยสำคัญ (Significant)"
หากเข้าข่ายข้อใดข้อหนึ่งต่อไปนี้ จะถือเป็นปัญหามีนัยสำคัญทันที:
1. **เรื่องที่ผิดกฎหมาย หรือมีค่าเกินมาตรฐาน:** (คะแนนกฎหมาย = 2) 
2. **สภาวะปกติ (N):** ที่คำนวณคะแนนรวมได้ **ตั้งแต่ 25 คะแนนขึ้นไป**
3. **สภาวะผิดปกติ (AB):** เช่น เครื่องจักรขัดข้องจนมีน้ำมันรั่ว
4. **สภาวะฉุกเฉิน (E):** เช่น ไฟไหม้, สารเคมีหกรั่วไหลปริมาณมาก

## 4. มาตรการจัดการปัญหาสิ่งแวดล้อมที่มีนัยสำคัญ
เมื่อได้รายชื่อประเด็นที่มีนัยสำคัญ จะต้องขึ้นทะเบียนใน **EF-DCO-004** และดำเนินการจัดการดังนี้:
- **กรณีต้องลงทุนหรือใช้เวลา:** ให้จัดทำเป็น **"โครงการสิ่งแวดล้อม (Environmental Project)"** เพื่อปรับปรุงแก้ไข
- **กรณีควบคุมได้ด้วยระเบียบปฏิบัติ:** ให้จัดทำหรือบังคับใช้ตาม Procedure / WI อย่างเคร่งครัด
- **กรณีเหตุฉุกเฉิน:** ให้เตรียมพร้อมตามแผนฉุกเฉิน (ESP-HRD-001)

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ตารางประเมินลักษณะปัญหาสิ่งแวดล้อม (EF-DCO-003), ทะเบียนปัญหาสิ่งแวดล้อมที่มีนัยสำคัญ (EF-DCO-004)
- **ระยะเวลาการจัดเก็บ:** เก็บรักษาไว้เป็นเวลา **5 ปี**
