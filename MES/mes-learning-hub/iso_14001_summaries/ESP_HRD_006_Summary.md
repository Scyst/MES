# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การขออนุญาตเข้าทำงานสำหรับผู้รับเหมา (Contractor Work Permit)
**รหัสเอกสาร:** ESP-HRD-006 (Rev.01)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อกำหนดขั้นตอนและข้อควรปฏิบัติในการขออนุญาตเข้าทำงานของผู้รับเหมาและพนักงาน เพื่อให้เกิดความปลอดภัย อาชีวอนามัย และรักษาสิ่งแวดล้อม
- **ขอบเขต:** ครอบคลุมการขออนุญาต, การตรวจสอบขณะปฏิบัติงาน, และการตรวจรับมอบงานของผู้รับเหมาภายนอกทั้งหมด

## 2. ประเภทของใบอนุญาตทำงาน (6 Types of Work Permits)
บริษัทจำแนกใบอนุญาตทำงานออกเป็น 6 ประเภทตามลักษณะความเสี่ยง:
1. **Hot Work Permit:** งานที่ก่อให้เกิดความร้อนและประกายไฟ (เชื่อม, ตัดแก๊ส, เจียร)
2. **Cold Work Permit:** งานทั่วไปที่ไม่มีความร้อน (ซ่อมท่อทั่วไป, ประกอบตู้)
3. **High Level Work Permit:** งานบนที่สูง (นั่งร้าน, หลังคา, ที่สูงเกิน 2 เมตร)
4. **Confined Space Entry Permit:** งานในสถานที่อับอากาศ (บ่อ, ถัง, อุโมงค์, ท่อ)
5. **Electrical Work Permit:** งานเกี่ยวกับระบบไฟฟ้ากำลังและหม้อแปลง
6. **Chemicals Work Permit:** งานเกี่ยวกับสารเคมีและก๊าซอันตราย

## 3. ขั้นตอนการขออนุญาตเข้าทำงาน (Workflow)
1. **ยื่นเอกสารล่วงหน้า:** ผู้รับเหมาต้องประสานงานกับผู้ควบคุมงานของบริษัท และส่งใบขออนุญาตทำงาน (Work Permit) ให้ จป.วิชาชีพ ตรวจสอบ **ล่วงหน้าอย่างน้อย 3 วัน**
2. **การอบรมก่อนเข้าทำงาน:** ผู้รับเหมาทุกคน **ต้องผ่านการอบรมกฎระเบียบความปลอดภัยและสิ่งแวดล้อม** ของโรงงาน (บันทึกใน EF-DCO-041) และติดบัตร Supplier ตลอดเวลา
3. **การตรวจสอบหน้างานจริง:** จป.วิชาชีพ หรือผู้ควบคุมงานจะลงตรวจหน้างานทุกวัน หากพบว่าสภาพแวดล้อมไม่ปลอดภัย หรือไม่สวมใส่ PPE มีสิทธิ์ **สั่งหยุดงานได้ทันที!**
4. **การส่งมอบงานและการปิดใบอนุญาต:** เมื่อทำงานเสร็จ ผู้รับเหมาต้องเก็บกวาดขยะและทำความสะอาดพื้นที่คืนสภาพเดิม ผู้ควบคุมงานและ จป. จึงจะเซ็นตรวจรับมอบงาน

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ใบอนุญาตให้ทำงาน (EF-DCO-039), บัญชีรายชื่อผู้รับเหมา (EF-DCO-040), ใบบันทึกการอบรม (EF-DCO-041)
- **ระยะเวลาการจัดเก็บ:** เอกสาร Work Permit และการอบรมทั้งหมดเก็บรักษาไว้เป็นเวลา **2 ปี**
