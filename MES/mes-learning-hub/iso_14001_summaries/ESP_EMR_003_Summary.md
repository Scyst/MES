# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** กฎหมายและข้อกำหนดอื่นๆ ด้านสิ่งแวดล้อม (Environmental Legal and Other Requirements)
**รหัสเอกสาร:** ESP-EMR-003 (Rev.06)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางในการค้นหา รวบรวม ทบทวน และขึ้นทะเบียนกฎหมายสิ่งแวดล้อม ข้อกำหนดของนิคมฯ และข้อกำหนดของลูกค้า ให้มั่นใจว่าโรงงานดำเนินการถูกต้องตามกฎหมายอย่างสม่ำเสมอ
- **ขอบเขต:** ครอบคลุมกฎหมายและระเบียบข้อบังคับด้านสิ่งแวดล้อมทั้งหมดที่เกี่ยวข้องกับการดำเนินงานของบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน) และบริษัทในเครือ

## 2. แหล่งข้อมูลในการรวบรวมกฎหมาย
เจ้าหน้าที่สิ่งแวดล้อมและฝ่ายบุคคลจะติดตามรวบรวมกฎหมายจากแหล่งต่างๆ ดังนี้:
1. **กรมโรงงานอุตสาหกรรม (กรอ.) / สำนักงานอุตสาหกรรมจังหวัด:** ใบอนุญาตประกอบกิจการโรงงาน (รง.4), กฎหมายกากของเสียอันตราย
2. **กรมควบคุมมลพิษ / กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม:** มาตรฐานน้ำทิ้ง, มลพิษทางอากาศ, การปล่อยควัน
3. **ราชกิจจานุเบกษา:** พระราชบัญญัติและกฎกระทรวงสิ่งแวดล้อมฉบับใหม่
4. **องค์กรปกครองส่วนท้องถิ่น (อบต. / เทศบาล):** เทศบัญญัติการจัดการขยะมูลฝอย
5. **ข้อกำหนดของลูกค้า:** ข้อกำหนดด้านสารต้องห้ามในผลิตภัณฑ์ (เช่น มาตรฐาน RoHS, REACH)

## 3. ขั้นตอนการดำเนินงาน (Workflow)
1. **การขึ้นทะเบียนกฎหมาย:** รวบรวมและวิเคราะห์สาระสำคัญของกฎหมายที่เกี่ยวข้อง บันทึกลงใน **"ทะเบียนกฎหมายและข้อกำหนดด้านสิ่งแวดล้อม" (EF-DCO-005)**
2. **การทบทวนและอนุมัติ:** ผู้จัดการฝ่ายบุคคลทบทวนความถูกต้อง และเสนอให้ตัวแทนฝ่ายบริหาร (EMR) ลงนามอนุมัติ
3. **การแจกจ่าย:** แจกจ่ายสำเนาทะเบียนกฎหมายไปยังแผนกที่เกี่ยวข้อง (EF-DCO-006) เพื่อนำไปปฏิบัติหน้างานจริง
4. **การติดตามกฎหมายใหม่:** เจ้าหน้าที่ต้องติดตามความเคลื่อนไหวของกฎหมายสิ่งแวดล้อมใหม่ๆ **ทุกๆ 6 เดือน** เพื่ออัปเดตทะเบียนให้ทันสมัยเสมอ

## 4. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** ทะเบียนกฎหมายและข้อกำหนดด้านสิ่งแวดล้อม (EF-DCO-005), บันทึกการแจกจ่ายเอกสาร (EF-DCO-006)
- **ระยะเวลาการจัดเก็บ:** เอกสารทะเบียนกฎหมายเก็บรักษาไว้เป็นเวลา **5 ปี**
