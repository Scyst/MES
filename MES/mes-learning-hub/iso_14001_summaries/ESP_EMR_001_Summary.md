# สรุประเบียบการปฏิบัติงาน (Standard Procedure)
**ชื่อเอกสาร:** การทบทวนโดยผู้บริหาร (Management Review)
**รหัสเอกสาร:** ESP-EMR-001 (Rev.07)
**วันที่ประกาศใช้:** 26/03/2564

## 1. วัตถุประสงค์และขอบเขต
- **วัตถุประสงค์:** เพื่อเป็นแนวทางให้ฝ่ายบริหารระดับสูงทบทวนผลการดำเนินงานและประสิทธิผลของระบบการจัดการสิ่งแวดล้อม (ISO 14001) ให้มั่นใจว่ายังคงเหมาะสม เพียงพอ และมีการปรับปรุงอย่างต่อเนื่อง
- **ขอบเขต:** ครอบคลุมการทบทวนระบบการจัดการสิ่งแวดล้อมของบริษัท เอส เอ็น ซี ฟอร์เมอร์ จำกัด (มหาชน) และบริษัทในเครือทั้งหมด

## 2. กำหนดการและองค์ประชุม (Meeting Schedule)
- **ความถี่:** จัดประชุมอย่างน้อย **ปีละ 1 ครั้ง ภายในเดือนกรกฎาคมของทุกปี** (หรือจัดประชุมเป็นกรณีพิเศษหากมีปัญหาเร่งด่วน)
- **องค์ประชุม:** ประธานบริษัท, กรรมการผู้จัดการ (MD), ผู้จัดการแผนกต่างๆ, ตัวแทนฝ่ายบริหาร (EMR), และคณะกรรมการสิ่งแวดล้อม

## 3. วาระการประชุมทบทวน (Review Inputs)
วาระสำคัญที่ต้องนำเสนอต่อผู้บริหาร ประกอบด้วย:
1. การติดตามผลการดำเนินการจากการประชุมทบทวนครั้งก่อน
2. สรุปผลการดำเนินงานตามนโยบายและเป้าหมายสิ่งแวดล้อม (Environmental Objectives & KPIs)
3. สรุปผลการตรวจติดตามภายใน (Internal Audit) และการตรวจรับรองจากหน่วยงานภายนอก (CB)
4. สรุปสถานะการแก้ไขใบ CAR และ NC Report
5. ความเพียงพอของทรัพยากร (งบประมาณ, บุคลากร, เครื่องมือ)
6. การเปลี่ยนแปลงของปัจจัยภายใน-ภายนอก และกฎหมายสิ่งแวดล้อมใหม่
7. ข้อเสนอแนะและการร้องเรียนด้านสิ่งแวดล้อมจากชุมชนภายนอก

## 4. ผลลัพธ์จากการประชุมและการสื่อสาร (Review Outputs)
- EMR จัดทำรายงานสรุปผลการทบทวน (EF-DCO-002) 
- หากผู้บริหารพบจุดที่ต้องแก้ไข จะสั่งการให้ออก **ใบรายงานข้อบกพร่อง (NC Report - EF-DCO-022)** ไปยังแผนกที่รับผิดชอบทันที
- **การสื่อสารพนักงาน:** นำสรุปมติที่ประชุมไปปิดประกาศที่บอร์ดประชาสัมพันธ์ภายใน 1 เดือน เพื่อให้พนักงานทุกคนรับทราบทิศทางสิ่งแวดล้อมของบริษัท

## 5. การเก็บบันทึก
- **เอกสารที่เกี่ยวข้อง:** กำหนดการและวาระการประชุม (EF-DCO-001), รายงานผลการทบทวน (EF-DCO-002)
- **ระยะเวลาการจัดเก็บ:** เอกสารการประชุมทบทวนฝ่ายบริหารทั้งหมดเก็บรักษาไว้เป็นเวลา **5 ปี**
